# 12 十六位像素 RPG（`pixel-rpg`）做片笔记

> 整支片子是一局游戏。先放街机的「演示模式」：大地图上赶路、Boss 战一击、升级。然后标题画面《一句话 RPG》，按开始、选「新游戏」。她的房间一开始是褪色的，AI 编程助手（戴尖帽的小机器人法师）从电脑里出来入队，颜色从电脑那里一圈圈涨回来。她在输入框里打出那句话，它先问三件事，宝箱里「获得了免费开源库」，39 种风格的列表滚到第 12 种。遭遇 Boss「视频生成费」：写代码、配音、配乐、逐帧绘制，最后「全都交给它」，打到 ¥0。大地图上三座城是适合拍的三类片子，路牌指向白板那一期；升级「学会：一句话做动画」；存档 = 先收藏；片尾 ▶ CONTINUE。

## 1. 构思

- 这个风格的本事是「游戏自己的系统就是叙事」（STYLE §2）：对话框就是字幕、选单、存档、战报、升级、调色板。所以这期不另起讲解画面，把「一句话做一支视频」本身写成一局 RPG：
  - 用什么：AI 编程助手是入队的队友；免费开源库是宝箱里的道具，39 种风格是一张能滚的列表；
  - 怎么说：那句话在输入框里一个字一个字打出来；它回的三个问题是一个选单，一项项打勾；
  - 剩下的交给它：Boss 战的四个指令（写代码、配音、配乐、逐帧绘制），最后「全都交给它」；Boss 的名字就叫「视频生成费」，打到 ¥0 = 不花钱生成视频；
  - 适合拍什么：大地图上的三座城（游戏预告、年度回顾、怀旧向），岔路口的路牌指向白板那一期。
- 系列的结尾句也有现成的游戏说法：先收藏 = 存档，下一期 = ▶ CONTINUE。
- 开头照系列规矩先给成片最好看的样子：街机的「演示模式」（右上角 DEMO 闪），三段各 3 秒：赶路、Boss 挨一击、升级光爆。
- 用到的三种原生本事：调色板 = 情绪（褪色的房间在队友入队时涨回彩色）、保护色（女主角的柠檬黄围巾，就是上一期 80 年代那位的同一条，片尾飘过一次）、游戏界面当旁白。

## 3. 关键手法

### 3.1 竖版：180×240 原生，×6 正好 1080×1440
- `px.js` 的 `W, H` 改成 180×240，其余（索引色帧缓冲、查找表、马赛克、Bayer）不用动。
- 对话框放在 y 176–224，底下 16 像素（= 96 px）留给平台按钮；站着的角色脚底线要在 176 以上，不然被对话框吃掉半个身子（第一版开场赶路就吃掉了）。

### 3.2 中文像素字（`hz.js`）
- 样片的像素字体只有英文。中文用思源黑体现做：按 4 倍超采样把字画到小画布，每 4×4 格求覆盖率，过阈值记一个像素，字形缓存。
- 试了几档（`?test=hz`）：12 像素、500 字重、阈值 0.35 最清楚；700、900 糊成一团，11 像素太小。一行 12 像素的字、行高 15，对话框里一行 9 个字，两行放得下一块字幕（≤15 字）。
- 英文、数字、符号仍用样片的像素字体（`font.js`），缺的 ¥ ✓ < > { } ; ★ 自己补。
- 要先 `document.fonts.load` 所有会画的字（思源黑体按字切片，没加载的字会掉到系统字体）。

### 3.3 那句话：输入框，字跟着念
- 字幕块按标点断成 ≤15 字，每个字在念到它的时候出现（逐字时间来自 `words.json`，「16」对「十、六」，一个字一个单元）。
- 那句话（L04）不用对话框，换成整宽的输入框（抬头「对 AI 编程助手说：」、有闪的输入光标），被标点断开的两块要合回一个框。
- 坑：每块的逐字时间里含它末尾那个被去掉的逗号，合并时不要再补一个，结尾也别再加句号（第一版出现了「。。」）。

### 3.4 褪色的房间，从电脑那里涨回彩色
- 队友入队前整帧用褪色表（7 阶蓝灰）；入队那一下按到电脑的距离 + 8×8 Bayer 抖动的边，一圈圈换成全彩表（`out.present(fb, LUT.faded, LUT.full, pick)`）。
- 声音跟着：房间的八音盒入队前是单声道、低通 1.4 kHz，涨回彩色时交叉到立体声 + 回声。

### 3.5 两个新角色（样片骨架 + 新头部）
- 样片 `sprites.js` 的骨架（胶囊肢体、三阶明暗、自动描边）照用；新加的角色只要一行定义：女主角（栗红长发、玫瑰色裙装、柠檬黄围巾）、AI 小法师（尖帽 + 金属脸 + 青色光眼、深蓝长袍、金属手脚、法杖顶端是一个光标）。
- 骨架里有几处写死了样片主角（手的材质、腿、靴、围巾、法杖顶端、头部高度），改成按角色取。
- 女主角的头发一开始是一个圆顶，像头盔（样片文档记过这个坑），后脑补两三绺大发尖。
- 头像 32×32 另画：女主角三种表情 + 说话时嘴一开一合（8 fps）；小法师两种（正常、笑眼）。

### 3.6 Boss「视频生成费」
- 一大坨紫色史莱姆：两阶明暗、描边、凶眼、坏笑，肚子里一颗颗金币，头上挂着米色价签「¥¥¥」。挨打时整只闪白两帧；被打倒时 12 fps 闪没、金币炸开，原地升起 3× 的金色「¥0」。
- 伤害数字写成「-¥2400」这种，钱被一块块打掉。

### 3.7 封面
`?poster=1` 单独构图：Boss 挨一击 + 「¥0」+ 队伍在右下；顶上压暗一条，放像素大字「一句话」（34 像素、900 字重、描边、金色渐变）、「让 AI 做出一段 / 像素游戏动画」、红底「不花钱生成视频」，底下一条「39 种风格 · 12 十六位像素 RPG」。封面的字也全画在帧缓冲里，放大 6 倍一样是像素字。

## 4. 声音

- **配音**：11 句。L01 气声比 −26.2 dB，换 3、5、7 号种子是 −27.3、−27.2、−25.7 dB，留 3 号；L11 跟上一期同一句，齿音多（−24.3 dB），留原版。
- **配乐**（`music/score.py`，音色沿用样片：12.5/25/50% 方波、4-bit 三角波、LFSR 噪声、SNES 式三抽头回声；编曲重写）：
  - 游戏音乐按场景切段、每段自己的速度，切得很硬，这本身就是游戏的味道：演示 132 BPM → 标题号角 → 房间 96 BPM 八音盒 → 获得物品号角 → 遭遇扫频 → 战斗 152 BPM → Boss 倒下真静 → 胜利号角 → 大地图进行曲 116 BPM → 升级琶音 → 存档点八音盒 → 片尾落回主音；
  - 一个主题动机 M（F 大调：C5 F5 A5 C6 | A5 F5）贯穿，战斗段变成 D 小调；
  - 和弦用「芯片琶音」：一个方波声道每 1/40 s 轮一个音，当三个声道用；
  - 胜利号角、获得物品号角都是自己写的，不碰任何现成游戏的旋律。
- **拟音**（`mix.py`，全部现合成、压低位深 + 采样保持）：光标、确认、选中、打字、宝箱、入队闪光、遭遇漩涡、施法（四个指令各一个音高）、命中（小 / 大）、蓄力、Boss 闪没、金币、存档嘀嗒、系统消息的「嘀嘀」（AI 没有配音，只有字的声音）。
- **电平**：旁白 −18 dB；配乐 −26 dB，说话时按分轨压（主旋律 −22、和声 −14、音效 −16、鼓 −15、其余 −12 dB）；拟音说话时压 11 dB；胜利号角 +4 dB。每句「人声 − 底子」14.4–25.4 dB。

## 5. 返工记录

1. **开场赶路的人被对话框挡了一半**：地面、土路、人整体上移 36 像素。
2. **Boss 太小、像个紫色面包**：放大到约 80×40 像素，金币一颗颗分开，加牙和高光。
3. **那句话被拆成两个输入框**、合回来后又多了一个「。」（§3.3）。
4. **大地图的山画成了一片斜线格子**：改成在山区撒一个个小山尖（受光面浅、背光面深、山顶一点雪）。
5. **路牌标签压住「怀旧向」**、**「学会了」压住列表最后一行**、**存档窗口挡住水晶**：各自挪位置（列表改成 7 行）。
6. **L07 只有 9.6 dB**：施法、命中的拟音正好压在旁白上，战斗鼓也厚；拟音调轻、说话时多压，鼓单独压 15 dB。**L06 被获得物品的号角压着**：音效轨说话时压 16 dB。
7. **一行里写了 `//` 注释把后面的代码也注释掉了**，页面报「Unexpected end of input」：一行里的注释用 `/* */`。

## 6. 下一期能直接拿走的

- **中文像素字**：`hz.js` 整个拿走（思源黑体、12 像素、500 字重、阈值 0.35），任何像素风格都能用。
- **「把做视频写成一局游戏」**：入队 = 用什么，选单 = 先问一轮，宝箱 = 开源库，Boss = 要省掉的那笔钱，大地图 = 适合拍什么，存档 = 先收藏。别的游戏类风格（HD-2D、微游戏快闪）可以换一种游戏系统来讲。
- **褪色 → 涨回彩色**：两张查找表 + 按距离的 Bayer 边，一行代码的事。
