# 30 木刻版画（`woodcut`）做片笔记

> 每个镜头都是一块刻好、印出来的版：黑 = 没刻的木面，白 = 刀刻掉的地方，只有一种颜色（铜色），只给会发光的东西。
> - 开场先给成片：一张「放映厅」版画；然后**墨辊从左滚到右，把它滚回一整块黑**——这就是这一期的「清零」；
> - 桌上的木版：第一刀是地平线，镜像刻片名和那句话（读不正）→ 滚墨、铺纸、马连一搓、揭纸，字才读正；
> - 问号三联、40 格字盘、四张快切；「都交给它」前 0.3 秒真静，放映机的光一口气刻出去；用途三联、29 期那一帧刻成木刻交棒、片尾一张新印的版。

## 1. 构思

- 风格说：光是刻出来的（亮 = 刀宽），颜色只给会发光的东西；故事从黑暗里的第一刀开始，第一张印出来的时候字从反到正；高潮是颜色版铺满画面。
- 这一期：做视频的每一步 = 一块版。「那一句话」是刻在版上的第一行字；AI 替你干活 = 放映机的光一刀一刀刻出来。铜色只用四次：成片的银幕和光束、字盘第 30 格、高潮的银幕和光束、片尾小放映机镜头上最后一点。
- 风格的招牌动作全用上：第一刀地平线、镜像刻字、拉纸翻正（墨辊、铺纸、马连、揭纸）、颜色版铺满、最后一刀回到第一刀的声音。
- 三样干货都刻成版：问号三联（话筒、鼓、三格小画）、40 格字盘（表头「开源库 Niuxue-Films · 39 种风格」，第 30 格铜色）、四张快切（代码行、话筒 + 声波、五线谱、胶片）。
- 交棒：29 期第 24 秒那一帧（楼顶和十字路口）过木刻滤镜刻出来——最彩色的玩具小城，交给只有黑白铜三色的木刻。

## 3. 关键手法

### 3.1 一帧 = 一次印刷
- 每帧先在「墨版」画布上画：黑 = 木面，白 = 刻掉的地方；颜色版画布只画铜色的地方。印刷器 `P.render(M, C, {mode})` 一次合成：墨的颗粒、套色偏移、纸纹。
- 两种帧：`printFrame`（印出来的：画面区之外是纸边）和 `blockFrame`（桌上的木版：满画幅、左右镜像、四周是木纹桌面，印刷器用 `mode: 'block'` 出湿墨的光泽）。
- 字幕是活字：写在墨版的纸边上，跟画面一起过印刷器。看木版、拉纸的镜头没有纸边，就在底部压一条同样印出来的纸条，字幕不断：

```js
function capBand(t) {                       // 看木版的时候：底部压一条纸，字幕照样活字印
  const y0 = IMG.y + IMG.h;
  m.setTransform(1, 0, 0, 1, 0, 0); m.fillStyle = '#fff'; m.fillRect(0, 0, W, H); c.clearRect(0, 0, W, H);
  caption(t);                               // 字写在空白墨版的纸边上
  const img = P.render(M, C, { seed: 3, inkSeed: 3 });
  const gr = g.createLinearGradient(0, y0 - 30, 0, y0); gr.addColorStop(0, 'rgba(0,0,0,0)'); gr.addColorStop(1, 'rgba(0,0,0,.5)');
  g.fillStyle = gr; g.fillRect(0, y0 - 30, W, 30);
  g.drawImage(img, 0, y0, W, H - y0, 0, y0, W, H - y0);
}
```

- 硬切 = 一次新的压印：切进来的第一、二帧整张抖几个像素（`jolt`），配一声压印的闷响。

### 3.2 刻字
- 一行字 → 一个区域（`fillText` 进去当遮罩）→ 顺着横向排刀痕，按 x 揭开，就是从左往右刻。
- 那句话、片尾那句跟配音逐字刻：`words.json` 的每个字的时间 → 这个字的刻刀时间。
- **小字刻完换成整块白字**：刀痕中间留黑缝，大字没关系，字盘编号、表头这种小字就读不清了：

```js
function carved(S, reveal, seed) { return { S, strokes: carveText(S, reveal, seed), t1: reveal.t1 }; }
function drawCarved(q, K, t) { if (t >= K.t1 + .12) solidText(q, K.S); else WC.drawStrokes(q, K.strokes, { t }); }
```

### 3.3 任意画面 → 木刻
- 道具（话筒、鼓、三格小画、茶壶、书、小屋 + 月亮 + 松树）先用 Canvas 画一张**灰度小画**，径向渐变当光，再过引擎的 `woodcutFilter`：亮的地方刀宽、刀顺着等亮线走，揭开方式 `'light'`（最亮的先刻）。
- 真画面也一样：交棒版是 29 期的一帧，裁掉时钟和字幕再过滤镜，外面刻一道框。构图要简单（楼顶 + 路口），满屏细节的封面刻出来是一团乱。
- 形状（`WC.shape`）的揭开函数 `reveal.key` 必须是 `(x, y) → 0..1` 的函数；字符串 `'light'` 只有 `woodcutFilter` 认。

### 3.4 放映机和高潮
- 机身 `WC.shape`（带一圈白边光晕）；片盘不用 shape（黑盘在黑底上看不见），直接刻：外圈、轴心圈、三根辐条、一根支架，两个片盘分开放。
- 光：`WC.rays` 58 道放射刀痕 + 墙上以银幕为中心的放射排线；银幕先刻白、再套铜色，光束铜色 75%。
- 高潮的镜头从 1.25 倍、对着放映机开始，一边刻一边拉回全景，左边的片盘不会被裁：

```js
const e = eio(seg(t, T.burst - .3, T.burst + 1.6));
printFrame(t, { z: lerp(1.25, 1, e), x: lerp(PW / 2 - 120, PW / 2, e), y: lerp(PH / 2 + 60, PH / 2, e) }, …);
```

### 3.5 拉纸
- 墨辊（`wetX` 让印刷器只给滚过的地方上湿墨）→ 纸从上往下铺，边缘一道影子 → 马连沿螺旋线搓（`barenPath`），搓过的地方透出字 → 揭纸用样片的纸卷曲（`trans30.js` 的 `curl` / `peelState`），背面是镜像的版，正面是印好的一张（`front()` 用印刷模式渲一次缓存）。

## 4. 声音

- **配乐**（`music/score.py`）：样片的配器，全部现合成——大提琴、低音提琴（19 期那把合成大提琴：40 个泛音按瞬时频率过琴体共鸣；低音提琴 = 共鸣往下挪、音色更暗）、拨奏（`core/audio/pluck.py`）、梆子、木鱼、框鼓、大鼓、定音鼓、大锣（30 条不成整数倍的泛音，高的后开花）、铁砧（4 条泛音 + 锤子）。D 小调 → D 大调：
  - 墨辊滚回黑的时候，和弦里的 F# 滑成 F，大调变小调；
  - 刻字一刀一个拨奏；纸落下、字读正落在 F 大调（关系大调）；
  - 字盘第 30 格亮 = 全片第一声金属；
  - 快切转 90 BPM，定音鼓滚奏越来越响，**放映机出来之前 0.3 秒全停**（混响尾巴一起清零），然后大鼓 + 定音鼓 + 大锣开花、弦乐转 D 大调，那句念完的空档里大提琴唱一句；
  - 最后一刀跟第一刀同一个声音，一挑，拨一个 D。
  - 各声部按「真在响的 400 ms 窗」量电平再配平衡（拨奏是骨架，得抬 9 dB）。
- **拟音**（`mix.py`，样片的做法，按材质合成）：刀咬进木头、刀走（按刀速调制的纤维撕裂）、刀挑、V 口刀 / U 口刀、细刻、墨辊、铺纸、马连、揭纸、纸落下、压印、光一口气刻出去（14 刀连着）、放映机的快门咔哒和马达。
- **电平**：旁白 −18 dB；配乐不说话时 −25 dB，说话时按分轨压（低音提琴 −6、大提琴 −12、高音 −14、拨奏 −6、木头 −9、大鼓 −4、大锣 −8），中频（400–3500 Hz）再挖 8 dB。**刀声就在人声那一段频率里**：拟音说话时压 8 dB、中频（500–3000 Hz）再挖 5 dB。每句 14.9–23.5 dB。

## 5. 返工记录

1. 形状的揭开函数写成字符串 `'light'`：改成 `(x, y)` 函数。
2. 写代码那块版的代码行没出来：两个点的刀痕太短，先 `WC.resample` 补点再刻。
3. 字盘编号、表头这些小字刻出来读不清：刻完换成整块白字。
4. 字盘脚注压着最后一排：网格上移、脚注下移。
5. 放映机刻得不像：机身加大 + 光晕；片盘改成白圈 + 轴心圈 + 辐条 + 支架，两个片盘分开。
6. 剪辑那块版只露了 0.6 秒就被放映机盖掉（「剪」还没念完）：放映机晚 0.4 秒起刀、一口气刻完，镜头跟着机器往外拉。
7. 交棒版用 29 期的封面刻出来一团乱：换成构图简单的一帧（楼顶 + 十字路口），裁掉时钟和字幕，加一道刻框。
8. 片尾的小放映机太小：放大、摆正中。
9. 看木版、拉纸那 12 秒没字幕：底部压一条纸，字幕照样活字印（3.1）。
10. 刀声压人声（第二句只有 11.6 dB）：拟音说话时多压、中频再挖一刀，到 14.9 dB。
11. 「民间故事」那格的树画成椭圆，像面镜子：改成三层三角的松树。
12. 封面的大字压在光束上，被铜色染得半铜半白：铜色版在标题带里挖空。
