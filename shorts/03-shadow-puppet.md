## 1. 构思

**戏中戏：百步穿杨**（养由基，《战国策·西周策》）。demo 的弓箭手皮偶 `houyi.js`、姿势 `poses.js` 原样用，开弓公式 `aimAt()` 照搬，故事换掉：demo 是九箭灭九灯，这期一箭穿一片柳叶。中箭也用风格自己的话说：靶叶换成刻了圆孔的那片，孔透光。

## 3. 关键手法

### 3.1 旁白的字就是调度
- 想要：旁白说到什么，布上同一拍就演什么。
- 做法（`film.js` 的「时间线」一段）：
  - 时刻用 `at(id, '字')` 算，或从它链出来（SHORTS.md §3）。动作要多长就提前多长：字牌压实要 0.55 s，就从字前 0.55 s 起压，落稳正好念到；推特写提前 0.25 s。`'A'` 就是「AI」，逐字时间里英文按字母拆。
  - 念到的动词都演出来：「句」片名起杆，「灯」灯亮，「刻」推特写，「从」光团出现，「压」压实，「杆」收弓，「都」灯亮，「交」数字牌抬走。
  - 每句起点从上一句结尾或上一个动作链出来（`VO.L02 = END_OF('L01') + 1.0`、`VO.L06 = T.cutBack + .45`），一句变长，后面整条跟着挪。
  - `events()` 最后 `add('cues', 0, { ...T, VO, DUR })`，整张表写进 `events.json`，`music/score.py` 按 `T['liang']`、`T['hit']` 下锣。画面、锣鼓、拟音同一张表。
```js
T.ai = at('L02', 'A') - .55; T.lib = at('L02', '开') - .55; T.name = at('L02', '名');
// …
T.lampUp = at('L04', '灯'); T.carved = at('L04', '刻') - .25;
VO.L05 = END_OF('L04') + .3;
T.glow = at('L05', '从') - .1; T.press = at('L05', '压') - .1; T.pressEnd = T.press + .55;
```

### 3.2 竖版镜头：横幅的布，竖着的框
- 想要：幕布保持 1920×1080（横幅是风格本身），竖屏里靠镜头在布上摇和推。
- 做法：
  - 镜头是一张关键帧表 `KEYS`，每行 `[时刻, cx, cy, z, 缓动]`，时刻全取自 `T`。缓动写在要到达的那一帧上：`'l'` 线性（慢漂或停住），`'o'` 缓出（亮相冲镜），默认 `'io'`。
  - 缩放在对数空间插值；平移按 `1/z` 的进度走，等于绕一个不动点缩放。又推又摇时，画面不会先甩出去再拐回来。
  - z ≥ 1 才夹 x，z ≥ 1.333 才夹 y。z 不到 1.333 时上下会露出台框，所以台框在 `cam[2] < 1.34` 时画。
- 代码：`film.js` 的 `KEYS`、`camAt()`、`camM()`。
```js
function camAt(t) {
  let i = 0; while (i < KEYS.length - 2 && t > KEYS[i + 1][0]) i++;
  const a = KEYS[i], b = KEYS[i + 1], u = clamp((t - a[0]) / (b[0] - a[0])), e = (EASE[b[4] || 'io'])(u);
  const z = Math.exp(lerp(Math.log(a[3]), Math.log(b[3]), e));
  const w = Math.abs(b[3] - a[3]) > 1e-4 ? (1 / a[3] - 1 / z) / (1 / a[3] - 1 / b[3]) : e;
  const c = [lerp(a[1], b[1], w), lerp(a[2], b[2], w), z];
  if (z >= 1) c[0] = clamp(c[0], W / 2 / z, 1920 - W / 2 / z);
  if (z >= 1.333) c[1] = clamp(c[1], H / 2 / z, 1080 - H / 2 / z);
  return c;
}
const camM = ([cx, cy, z], mir = 1) => [z * mir, 0, 0, z, W / 2 - cx * z * mir, H / 2 - cy * z];
```

### 3.3 镂空中文字牌
- 想要：片名、干货、题目、片尾、封面都做成皮牌，字刻空，灯从字里透出来。
- 做法：
  - `stage.js` 的 `plaque()` 在 demo 里不导出，印文写死「后羿 射日」。这期把它导出，加了 `sealText` 参数；字用 `destination-out` 的 `fillText` 挖掉。
  - `pieces.js` 的 `mixed()` 把一行拆成汉字段（马善政）和拉丁段（Cormorant，字号 ×0.92），在小画布上逐段量宽，排成居中的几段。马善政里的拉丁字母认不出来（SHORTS.md §4）。
  - `piece()` 创建时就把字烤进精灵图，所以 `film.js` 先 `await document.fonts.load(...)`，再 `buildPieces()`。字体没加载好就建牌，字会用后备字体刻死。
```js
const LAT = /[A-Za-z0-9][A-Za-z0-9 .\-×&']*/g;
function mixed(text, size, y, o = {}) {
  const runs = []; let i = 0, m; LAT.lastIndex = 0;
  while ((m = LAT.exec(text))) { if (m.index > i) runs.push([text.slice(i, m.index), 0]); runs.push([m[0], 1]); i = m.index + m[0].length; }
  if (i < text.length) runs.push([text.slice(i), 0]);
  const fonts = runs.map(([s, l]) => l ? CG(Math.round(size * (o.latK ?? .92)), o.latW ?? 700, o.it ?? '') : MS(size));
  const ws = runs.map(([s], k) => { mg.font = fonts[k]; return mg.measureText(s).width; });
  let x = -ws.reduce((a, b) => a + b, 0) / 2 + (o.x ?? 0);
  return runs.map(([s], k) => { const L = { text: s, font: fonts[k], y: y + (runs[k][1] ? size * .04 : 0), x: x + ws[k] / 2, size }; x += ws[k]; return L; });
}
// 用法
lib: plaque(900, 430, [...mixed('开源库', 110, -110), ...mixed('lemo-opuscar', 104, 20, { latK: 1, it: 'italic' }), ...mixed('免费 · 39 种风格', 56, 128)], 0),
```

### 3.4 离布变大变虚：压上布、抬离布
- 想要：STYLE §4 的上场和退场。上场时 2.6 倍大、虚 34 px，0.55 s 压实；退场放大到 1.9 倍、虚 30 px，0.9 s 淡出。
- 单片（字牌）：`film.js` 的 `plaque(C, t, p, x, y, t0, t1, s)` 一个函数包了上场、停留、退场，落稳后（`a > .85`）才画两根杆。模糊量乘当前缩放 `k`，镜头远近变了，看着一样虚。
```js
const a = eo(seg(t, t0, t0 + .55)), off = seg(t, t1, t1 + .9), k = kOf(C);
const sc = s * lerp(2.6, 1, a) * (1 + ei(off) * .9);
put(C, p, x, y - off * 30, sc, { blur: (34 * (1 - a) + 30 * off) * k, a: Math.min(1, .3 + a) * (1 - ei(off)) });
```
- 多片（弓箭手 11 片加铆钉）：整个皮偶先画进一张白底离屏画布 `pc`，再以腰为中心缩放，用 `multiply` 加 `blur` 贴回透射率画布 `tr`。白色等于全透，贴回去不留底色。虚的时候不画铆钉。弓箭手从 26 px 模糊、0.85 不透明起压（原来 34 px、0.55 太淡，见 §7）。山水淡入（`world()`）也用这一招。
```js
pc.setTransform(1, 0, 0, 1, 0, 0); pc.fillStyle = '#fff'; pc.fillRect(0, 0, W, H);
drawHouYi(pc, C, hp, { rivets: u > .6 });
const P = [C[0] * (HX - 150) + C[4], C[3] * (HY + 20) + C[5]], s = lerp(2.6, 1, u);
tr.save(); tr.globalCompositeOperation = 'multiply'; tr.globalAlpha = appear * lerp(.85, 1, u); tr.filter = `blur(${lerp(26, 0, u) * k}px)`;
tr.setTransform(s, 0, 0, s, P[0] - s * P[0], P[1] - s * P[1] - (1 - u) * 60 * k); tr.drawImage(pcc, 0, 0); tr.restore();
```

### 3.5 一盏灯的表演表
- 想要：全片只有一盏灯，要让它跟着戏走。
- 做法：`film.js` 的 `lampI(t)` 按 `T` 表叠几层。
  - 灯位 `LAMP = [980, 110]`，在布顶正中。`lamps` 的第 4 个数是热点强度，用 0.3。
  - 台框的溢光也乘这盏灯（`drawFrame(fr, C, .8 * clamp(lampI(t), 0, 1.4))`），划火柴之前台框是黑的。
```js
const u = t - T.lampOn; let I = u < .45 ? lerp(.1, 1, eo(u / .45)) + .35 * Math.sin(u / .45 * Math.PI) : 1;
I += .28 * Math.sin(Math.PI * seg(t, T.lampUp, T.lampUp + .9));                    // 「灯在布后头」：亮一下
I *= 1 - .15 * E(t, T.stop, T.stop + .3) * (1 - E(t, T.rel, T.rel + .05));         // 静场：暗一点
if (t > T.hit) I += .45 * Math.exp(-(t - T.hit) / .5);                             // 中了：灯一跳
I += .2 * Math.sin(Math.PI * seg(t, T.allGlow, T.allGlow + 1.2));
if (t > T.snuff) { const s = (t - T.snuff) / .35; I *= s < 1 ? (1 - s) * (.7 + .3 * Math.sin(s * 40)) : 0; }
```

### 3.6 静场：锣鼓硬停、灯暗、手更颤
- 想要：拉满弓以后全场一静，只剩灯芯噼啪和弓弦绷着，一下小锣，放箭。
- 做法：
  - `music/score.py`：先加混响，再把所有分轨在 `stop → tap` 这段清零，前面留 25 ms 淡出，混响尾巴一起切掉。跑完打印 `silence_max`，这期是 0.0。`tap` 那下小锣从清零区的终点起，不受影响。
  - `mix.py` 里拟音不切：弓弦吱呀每 0.11 s 一下，一直延到拉满后 1.2 s；灯芯噼啪的底子全程都有。
  - 画面：灯暗 15%，手颤 ×1.8（`heroPose()` 末尾的 `tens`）。
  - 时长 1.25 s（35.12 → 36.37），再过 0.18 s 撒放，0.3 s 后箭到。
```python
for k in st: st[k] = S.room(st[k], size=.42, mix=.2)
a, b = int(T['stop'] * SR), int(T['tap'] * SR); f = int(.025 * SR)
for k in st: st[k][a - f:a] *= np.linspace(1, 0, f, dtype=np.float32)[:, None]; st[k][a:b] = 0
```

### 3.7 幕后揭底：灯是笔记本，杆子没人拿
- 想要：STYLE 里的「转到幕后」本来是给观众看艺人的手和油灯。这期反着用：没有手就是没有老师傅，灯是一台电脑。
- 做法：
  - 转场照 demo：镜头在幕布坐标里右移 1500（缓入 0.55 s），虚化前景立柱一抹；回来时立柱反向再抹一次。
  - `renderBack()` 用镜像镜头（`camM(cam, -1)`）把同一块布再画一遍，`noRods` 关掉台前那种虚灰的杆。杆子改画在前景层，深色、清楚（幕后看，杆在人和布之间），起点是 `screen()` 返回的皮偶真实挂点，一直伸进台下的黑里。
  - 笔记本在台下正中：`laptopMask` 画剪影加暖色轮廓光（`silhouette()`），`laptopScreen` 画屏幕、几行彩色「代码」、闪烁光标，再用 `lighter` 加一圈暖光。布上的灯位由笔记本的视口坐标反算回幕布坐标，光就从屏幕那儿来。
  - 屏幕朝镜头，不朝布。物理上不对，但一眼认得出是电脑；只画背板剪影认不出来（见 §7）。
```js
const R = screen(t, C, { world: true, hero: true, noRods: true });
if (R) { fr.save(); fr.setTransform(1, 0, 0, 1, 0, 0); fr.strokeStyle = '#140b07'; fr.lineCap = 'round';
  R.forEach((p, j) => { fr.lineWidth = (j ? 4 : 6) * z * 1.4; fr.beginPath(); fr.moveTo(p[0], p[1]); fr.lineTo(p[0] + (j - 1) * 50 * z, H + 60); fr.stroke(); });
  fr.restore(); }
// …
const LX = 540, LY = sr[3] + 150 * z / .72;
silhouette(fr, g => laptopMask(g, LX, LY, .95 * z / .72), { dir: [0, -1], k: 4, rimA: .8, rim: '#ffcf8a' });
laptopScreen(fr, LX, LY, .95 * z / .72, t);
const lampCloth = [(LX - C[4]) / C[0], (LY - 250 * z - C[5]) / C[3]];
```

### 3.8 靶叶：挂在枝头摆，中箭换穿孔的那片
- 靶叶是一片放大的柳叶，橙红皮上刻着叶脉缝，自带一根丝，丝顶在局部坐标 (0, −150)。它挂在柳树最左那根枝头（`LEAFTOP` 由树根 `WROOT` 算出），旁边两条柳条删掉，好让叶子露出来。
- 绕丝顶转：原点 = 丝顶 + R·(0, 150)。矩阵里 x 项乘 `C[0]`，y 项乘 `C[3]`，幕后镜像时才不翻（STYLE §8）。
- 中箭时换成同一位置刻了圆孔的那片，摆幅 0.5 rad，按 e^(−t/1.1) 衰减。柳条每条是一片皮，各自绕挂点摆，中箭时再加一阵 `gust`（`pieces.js` 的 `drawWillow()`）。
- 箭穿过靶叶不停，照原速再飞 0.35 s，出布外（`arrow()`），后面拖 3 个残影。
```js
const hit = t >= T.hit, sw = hit ? .5 * Math.exp(-(t - T.hit) / 1.1) * Math.sin((t - T.hit) * 7) : .04 * Math.sin(t * 1.4);
const lp = PC.leaf[hit ? 1 : 0], ca = Math.cos(sw), sa = Math.sin(sw);
g.save(); g.globalCompositeOperation = 'multiply';
g.setTransform(C[0] * ca, C[3] * sa, -C[0] * sa, C[3] * ca, C[0] * (LEAFTOP[0] - sa * 150) + C[4], C[3] * (LEAFTOP[1] + ca * 150) + C[5]);
g.drawImage(lp.c, lp.x0, lp.y0, lp.w, lp.h); g.restore();
```

## 4. 声音

**配音**
