# 13 1920s 默片（`silent-film`）做片笔记

> 整支片子是老影院里放的一部默片。竖版画面上半是银幕，下半是乐池：钢琴师在左，说明员在右（旁白就是他在讲），前排是观众的后脑勺。银幕上：片名卡《一句话》→ 咖啡馆里她写好纸条、高高举起 → 纸条特写，那句话一个字一个字显出来 → 一阵风卷走 → 满街追、扑空 → 发条摄影机器人（= AI 编程助手）伸手接住 → 字幕卡「配音？音乐？先看分镜吗？」→ 片厂大门 NIUXUE-FILMS，39 扇门里开 13 号 → 一镜到底的连锁机关（打字机 → 留声机 → 钢琴自己弹 → 片盘滚出画面、干等 → 滚回来落到放映机上 → 光束）→ 大厅三张海报 + 一扇「等距信息图 →」的门 → 机器人把片盘交给她，她举起来 → 光圈收在她脸上，眨眼 → 剧终，幕布合上。全片唯一的颜色：她的柠檬黄围巾。

## 1. 构思

- 这个风格自带三样东西：字幕卡（不说话的人物也能「说」）、一镜到底的连锁机关（等待就是笑点）、光圈（开在主角身上，收在最后一眼）。三样干货各找一个母题：
  - 用什么：AI 编程助手是一台**发条摄影机器人**（镜头是眼睛、两只片盘是耳朵、三脚架腿、铭牌写 AI）；免费开源库是**片厂大门**，招牌 NIUXUE-FILMS，里面 39 扇门；
  - 怎么说：那句话就是她写的**纸条**，插入镜头里一个字一个字显出来；它先问的三件事是它的**对白字幕卡**；
  - 剩下的交给它：一条机关链，一个环节一句词：打字机 = 写代码，留声机 = 配音，钢琴 = 配乐，放映机 = 一帧一帧地画；
  - 适合拍什么：大厅里的三张海报（喜剧、复古广告、不说话的故事）；不适合的交给隔壁一扇门「等距信息图 →」。
- 故事照 STYLE §2 的骨架换成自己的：得意（举起纸条）→ 东西跑了（风）→ 追、扑空 → 被别人接住 → 一条机关链 → 呼应（举起片盘）→ 光圈里眨眼。
- 旁白有了身份：**说明员**。默片时代的影院里真有人站在银幕边讲片子，所以「默片 + 旁白」不冲突；字幕卡照样当字幕卡用。

## 3. 关键手法

### 3.1 竖版影院：4:3 印片 + 乐池
- 片子照样片在 1440×1080 的胶片画布上画、过 Redraw 和 FilmPost，最后缩到 1016×762 放进竖版画面的银幕（x 32、y 150，圆角 14）。
- 上面：丝绒幔帐（三个垂褶 + 金流苏）+ 铜牌「风格 13 · 1920s 默片」；两边各 32 px 窄幕；下面：台口木边 + 一排脚灯。
- 乐池（y 960 往下，彩色）：左边钢琴师的背影和琴上的小台灯（钢琴在响时头和手跟着节奏动），右边说明员站在讲台后、拿一把折扇（旁白在说时点头、抬手），最下面一排观众的后脑勺（银幕的光勾出头顶，笑点处肩膀一抖）。再加一道很淡的放映机光束从观众身后打上银幕。
- 字幕（旁白）放台口下方 y≈1008，米色思源宋体 700、52 px、深色描边；底部 96 px 只有观众剪影。
- 幕布：开场从中间拉开，散场从两边合上（`theatre13.js` 的 `curtains()`）。

### 3.2 唯一的颜色：蒙版要会被挡住
- 样片的做法是把那件东西另画进一张蒙版，FilmPost 在蒙版有透明度的地方保留颜色。问题是蒙版不知道前后：围巾被下巴、手臂、桌子挡住的地方也会变黄。
- 做法：`engine/ink.js` 的 `wash()` 末尾加一个钩子 `S.onFill`。围巾（`HER.collar`）画完以后把它设成「擦蒙版」，之后画的每一个形都在蒙版上擦掉自己那块：
  ```js
  const eraser = (g, pts) => { const m = MASK.g; m.save(); m.setTransform(g.getTransform()); m.globalCompositeOperation = 'destination-out'; pathOf(m, pts); m.fill(); m.restore(); };
  ```
  画围巾自己时先把钩子关掉。骨架按前后顺序画，所以头、近侧的手臂、桌子都会自动把被挡的部分擦掉。
- 颜色不是平涂：蒙版（柠檬黄 #f3c21c）× 墨线之后画面的亮度（`brightness(1.42)` 后按蒙版裁出来，`multiply` 叠上去），Redraw 画的排线和轮廓线就留在黄色上。光圈外面的蒙版也要一起裁掉。

### 3.3 她：样片骨架 + 1920 年代的行头
- `HER` 是样片 2.5D 骨架的一个新角色：钟形帽（帽檐往外喇叭，帽带上一朵小花）、齐下巴短发（`hairMass` 管头骨里的发，`hairBack` 管伸出来的发量）、深色落腰连衣裙（臀线上一条浅色宽带 + 腰侧一个蝴蝶结）、浅色丝袜、玛丽珍鞋。
- 第一版是浅色裙子，远看像白大褂；帽子贴着头像头盔。改成深色裙 + 喇叭帽檐以后剪影立刻对了，黄围巾也更跳。
- 侧面跑的时候，样片的 `skirt`（`front: true`）只挡在腿前面，后面露腿像围裙。给引擎加了一行 `skirtBack`（连衣裙后片，画在躯干后面，跑起来往后飘）。

### 3.4 发条摄影机器人
- 正面画（`drawAutomaton`）：深色木箱机身、铜包角、铭牌 AI；镜头是眼睛，玻璃上的高光跟着 `look` 挪，眨眼 = 光圈叶片收拢；顶上两只会转的片盘当耳朵；右边摇把、左边发条钥匙（绕水平轴转，宽窄跟着变）；三脚架腿，走路时左右两条轮流抬、机身跟着晃。
- 手臂是两节铜杆 + 夹子，用「上臂角 up（0 垂下 → π 举过头）+ 前臂往里折 bend」两个数摆姿势；`autoHand()` 用同一套算法只算手的位置（接纸条时纸条的落点要事先知道）。
- 坑：`hold(g, hands)` 回调是在机器人**自己的局部坐标系**里画的；第一版递片盘时传了世界坐标，片盘画到画面外去了。

### 3.5 桌子挡住坐着的人
- 坐在桌边写字：人要在桌子后面（腿被挡），手又要在桌面上。做法：整个人画一遍 → 画桌子 → 用 `clip` 只留桌面以上，再把人画一遍盖回去（`cafe()`）。站起来走到桌子后面时照样成立。
- 桌面画成略俯视的扁椭圆、深色木面，纸条是透视压扁的白四边形，这样看得出她在写东西。

### 3.6 一镜到底的机关链 + 干等
- 片盘的路径是一段段写死的（`reelPath`）：琴顶上跳 → 往左滚到琴边 → 掉地 → 弹一下 → 滚出左边 → （干等）→ 从左边冲回来 → 撞上放映机的脚 → 抛物线落到片轴上。转角 = 走过的距离 / 半径。
- 干等要在旁白里留出来：L07「写代码、配音、配乐，一帧一帧地画，都交给它」在「配乐，」后面切开（`SPLIT7 = 2.8 s`），前半句在片盘还在琴上时念完，后半句等片盘落定才念。`timeline.js` 的 `at()` 自动认两段。
- 墙上小银幕放的是四帧手画的「她在跑」，8 格一换，右上角写帧号：「一帧一帧地画」直接演出来。

### 3.7 光圈收在脸上
- 样片的做法是光圈中心跟着角色的脸走（胶片坐标）。竖版里整个银幕缩到 0.7 倍，脸太小，眨眼看不见。
- 抱住片盘以后镜头推近（1.06 → 1.95，同时把脸移到画面中上），光圈再从全开收到 175 px，停住等她眨眼，再合上。`herFace()` 用同一套推近换算。

### 3.8 封面
`?poster=1`：银幕停在她把片盘高高举起、机器人站在旁边那一格；乐池那块压暗，写金色大字「一句话」、「让 AI 做出一部默片」、红底「不花钱生成视频」、「39 种风格 · 13 1920s 默片」。

## 4. 声音

- **配音**：11 句，气声比 −24.3 ~ −34.3 dB。L09（−26.9）、L11（−24.3）偏高，但逐帧的中位数正常、90 分位高，是齿音不是气声，留原版。
- **配乐**（`music/score.py`）：没有下样片的 VSCO 钢琴采样包，立式钢琴是现合成的：
  - 每个音 17 个非谐泛音（系数随音高变大，第 7 泛音压低 = 琴槌打在弦长 1/7 处）、三根弦各走调 −2.2 / +0.3 / +2.6 音分（影院那台没调准的味道）、琴槌噪声、两段衰减（快的「打击」+ 慢的余音）、松键时制音器；再过一个短而暗的影院混响。
  - 照 1920 年代影院的提示单分段：Maestoso 片头 → Andante「纸条主题」（F 大调 96，跨步低音）→ 纸条特写的八音盒琶音 → 风 = 半音阶刮奏 + 减七和弦 → Hurry 追逐（A 小调 144，十六分音符）→ 接住的「当当」→ 三个问号（每个都停在没解决的音上）→ 片厂进行曲（C 大调 116）→ 机关（钢琴学打字、回车铃「叮」、留声机华尔兹、钢琴自己弹拉格泰姆、半音阶滚落、干等时的减七颤音、画外「咚」= 小臂砸最低几个键、冲回来的上行音阶、落定）→ 大厅漫步 + 三个海报的小动机（长号式「哇哇哇」、广告小调、大七和弦）→ Tenderly 慢版 → 眨眼的倚音 → 剧终。
  - 主题 M（原创）：A4 C5 F5 | E5 D5 C5 A4 | B♭4 D5 G5 F5 | E5 G5 C5 ‖ A4 C5 F5 A5 | G5 F5 E5 D5 | C5 E5 G5 B♭5 A5 | F5。开头骄傲、结尾温柔。
  - 留声机那一轨单独出（`gram`），压成 350–2600 Hz 的喇叭声。
- **放映机就是环境声**（`mix.py`）：开灯「咔」、马达转起来、过片门的嗒嗒声从每秒 4 下爬到 24 下；干等那一拍只剩它和很轻的颤音；散场时片尾在收片盘上啪啪甩、越来越慢。
- **电平**：旁白 −18 dB（加 10% 影院混响，说明员在屋子里）；钢琴 −24 dB，说话时按分轨压（旋律 −16、伴奏 −13、效果 −12、留声机 −14）；放映机 −40 dB（干等 −33），说话时再退 6 dB；追逐和剧终 +3 dB。每句「人声 − 底子」14.1–23.3 dB（L06 最低：招牌灯泡和甩镜头的刮奏）。
- 量法改了一处：只算真在说话的 50 ms 窗。L05 的音频文件开头有 0.25 s 空白，正好压着「接住」那一下和弦的尾巴，整句平均只有 11.2 dB，按说话窗算是 22.5 dB。

## 5. 返工记录

1. **连衣裙像白大褂、帽子像头盔**：裙子改深色、帽檐往外喇叭（§3.3）。
2. **咖啡馆橱窗太黑**，她的深色裙子融进背景：橱窗里改浅灰店堂 + 半截白窗帘；镜头推近 1.18，招牌下移不被裁。
3. **纸条特写的字只占上半张**：字号调到 120 px、两行居中；原来画的「手指捏着纸角」看着像一坨，换成旁边搁一支钢笔。
4. **追逐开头她手里还像拿着纸条**：纸条的起点挪到她右上方，已经飞走了。
5. **扑空以后纸条正好停在她帽子上**，像落在头上：往上、往前抛高 110 px。
6. **机器人的镜头被打字机的纸挡住**：机器人挪到书桌左边，一只手打字（找键找着打，也更好笑）。
7. **递片盘时片盘不见了**：`hold` 回调的坐标系（§3.4）。
8. **抱片盘时片盘盖住了脸**：抱的位置从下巴降到胸口。
9. **光圈里的脸太小**：推近（§3.7）。
10. **举着纸条定住 4 秒**：加了挥彩票一样的左右挥动。
11. **七段台词不够 12 dB**（L02、L05、L06、L07 两段、L08、L11）：分轨压得更深、放映机说话时也退、结尾大和弦挪到最后一句念完以后、量法只算说话窗（§4）。

## 6. 下一期能直接拿走的

- **竖版影院框**：`theatre13.js` 整个拿走（幔帐、窄幕、脚灯、乐池、观众、光束、字幕、幕布），任何「片中片」的风格（后室录像、赛璐璐片头、老电视）都能放进去。
- **会被挡住的颜色蒙版**：`S.onFill` 钩子 + 蒙版 × 亮度，任何「只留一种颜色」的做法都能用。
- **合成立式钢琴**：`music/score.py` 的 `piano(m, v, d)` 不依赖任何采样包；钢琴当音效的一整套（打字、叮、滚落、画外咚、倚音）也在里面。
- **一句话切两段放**：`timeline.js` 的 `SPLIT7` 做法，任何「干等是笑点」的地方都能用。
