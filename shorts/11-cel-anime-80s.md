# 11 八十年代赛璐璐（`cel-anime-80s`）做片笔记

> 整支片子是一盘录像带。先放成片最好看的一段：霓虹夜里开敞篷车的她。然后「倒回去看」——跟踪噪声、◀◀ REW，画面倒着飞回去，停在那天晚上：下摇到她亮着电脑绿光的窗，屏幕上一个字一个字打出那句话，AI 编程助手先问三个问题，她把一盒标签写着库名的录像带塞进录像机，按下 PLAY。电视开机的亮线之后，片头《午夜兜风 1987》开演：霓虹峡谷、高架、数码仪表、钠灯隧道，抽空一拍，冲出隧道就是黎明的海；她把墨镜拉下来，笑。最后是片尾卡和「次回予告」。

## 1. 构思

- 这个风格的底子是「1987 年的 OVA 录在录像带上、在 CRT 电视上放」（STYLE §1）。录像带本身就能讲「怎么做的」：**先放成片，再倒带回去看制作过程**。倒带用的是风格自带的跟踪噪声（STYLE §3「tracking noise at story beats that involve the tape」），画面倒着飞、右上角计数器往回跳。
- 三样干货全用录像带时代的道具演：
  - 用什么：一台绿磷光电脑（AI 编程助手）+ 一盒录像带，标签手写 `Niuxue-Films`、39 STYLES、红贴纸 No.11 80s CEL ANIME；
  - 怎么说：那句话在电脑上一个字一个字打出来，跟着念；它回三个问题，她飞快打回答；
  - 剩下的交给它：写代码（屏幕上刷刷滚本片自己的代码）、配音（话筒 + VU 表）、配乐（合成器 PRESET 11 CITY POP）、一帧一帧地画（透写台上一叠赛璐璐，8 fps 换一张）；
  - 适合拍什么：画廊卡片的 uses（MV、游戏预告、怀旧），不适合的交给 08 数据叙事。
- 片中片是一段 80 年代动画片头（OP）：STYLE §2 说把题目改成「送达、赛跑、发射」，这里是「开车穿过夜城，赶在天亮到海边」。没有障碍物，隧道就是阻碍，出口的白光就是释放。
- 人设重新画，不照搬样片：栗红散发、丁香紫垫肩西装 + 白 T 恤、柠檬黄丝巾、推到头顶的墨镜；车是薄荷绿敞篷跑车（楔形车头、翻灯、整条尾灯）。
- 结尾是动画的「次回予告」：「下一期　换一种风格」+「先收藏」，正好是系列的结尾句。

## 3. 关键手法

### 3.1 倒带 = 把前面两镜倒着再画一遍
```js
export function rewind(S, FN) {
  const src = Math.max(.15, K.rew[0] - (S.t - K.rew[0]) * 7.4);          // 1.25 s 倒回 9 s
  const shot = src < K.hook[1] ? 'hook' : 'bust';
  FN[shot]({ ...S, t: src, lt: src - t0, u: …, t0, t1 });
  return { track: .85 };                                                  // 后期里的跟踪噪声
}
```
屏显（◀◀ REW、计数器、▶ PLAY）画在字幕那一层，一起吃扫描线。配乐里把预告那段音乐倒过来、快 7 倍当倒带声，再垫一层机械声。

### 3.2 两套小节网格
- 片中片（片头）对齐 112 BPM：**片名那一下是 bar 0**，镜头按小节切（片名 2 小节，峡谷、高架、仪表各 1，隧道 2，大画 2，黎明 2，笑 2）。
- 开头的预告有自己的网格，从第一句旁白起。
- 中间「她的房间」那段跟着旁白走，配乐沿主网格往前延伸（bar −14 … −1），垫子、电钢分解、贝斯、沙锤、轻鼓一层层加上来；按下 PLAY 全停，开机亮线之后铜管齐奏砸片名。

### 3.3 录像带、电脑、透写台：道具都是「发光的」
- 透过光（STYLE §3）用在屏幕的字、录像机显示屏、VU 表、透写台、数码仪表上：发光层只画字和灯，别整块填。
- 坑：电脑屏幕和透写台整块画进发光层，辉光把整块洗成一片绿、一片白，上面的字和画都看不见。改成屏幕底色压暗、发光层只给字；台面灰一点（亮度别过 0.9，样片的彩色层辉光阈值是 0.9），只让边缘溢光。

### 3.4 竖版的侧面跟拍
- 上半是天空和远景天际线，中间是霓虹店面（竖招牌正好竖着排），车的地面线在 y≈1220，下面整块是湿路面倒影。车缩到 0.9 倍，车尾可以出画。
- 下摇在竖版里最顺：远层、近层两张长画按不同速度移，前景电线和电线杆最快。

### 3.5 人设改动（`head80.js` 的新选项）
- `loose`：散开的长发，5 条宽发束从后脑一整片出发；`shades` / `shadesDown`：墨镜从头顶滑到眼睛上（8 fps 三张）；西装：垫肩更平更宽，V 领里一块白 T 恤，两片翻领；丝巾：脖子一圈软布 + 结 + 两片短尖角。
- 丝巾第一版的两条尾巴随风飘，近景里像两条金鱼。改成两片短尖角，风大时一起往后翘。
- 光手：样片的 `hand()` 画的是手套（手背三道缝线），换成皮肤色、去掉缝线（`bare`）。

### 3.6 封面
`?poster=1` 用胸像那一镜，脸放低（`S.poster`），上半留给大字：「一句话」铬金属渐变 + 霓虹粉描边（和片名卡同一套），「让 AI 做出一段 / 80 年代动画片头」奶黄粗黑体，红底「不花钱生成视频」，左下「39 种风格 · 11 八十年代赛璐璐」。字画在字幕那一层，一起吃扫描线。

## 4. 声音

- **配音**：11 句。L08 气声比 −23.8 dB，换 5 号种子 −27.7 dB；L11 几个种子都在 −20 到 −25 dB（「先收藏、下一期、换一种风格」齿音多），留最低的 7 号（−24.8 dB）。
- **配乐**（`music/score.py`，乐器沿用样片的合成器：FM 电钢、slap 贝斯、门限混响军鼓、合成铜管、合唱吉他、弦乐垫、主旋律、FM 钟）：
  - 原创 city pop，112 BPM，F 大调，和声用「丸之内进行」（B♭M9 – A7♭13 – Dm9 – Cm7 F7♭9），跟样片的王道进行区分开；冲出隧道后在黎明那两小节升半音。
  - 副歌动机四小节；开头预告放前四小节，房间里 FM 钟轻轻预示头四个音。
  - 静场三处：倒带后、按下 PLAY 到片名、冲出隧道前一拍。`place()` 起在静场里的声音不要、跨进静场的切掉，混响和延迟按段算（尾巴只响到下一个静场），`score.py` 打印两处静场峰值，都是 −240 dBFS。
  - 次回予告：一记铜管（短 + 长）+ 嗵鼓，放在开口前 0.75 s。
- **拟音**（`mix.py`，全部现合成）：CRT 开机（咚 + 消磁嗡 + 细高的线声）、倒带机械声、城市夜声、键盘、终端蜂鸣、磁带塑料壳、进带咔哒 + 电机、按键、引擎（按转速合成：四缸点火频率的谐波 + 排气脉冲）、隧道轰鸣 + 钠灯一盏盏掠过、冲击、海浪、海鸥、墨镜咔一声。
- **电平**：
  - 旁白 −18 dB；配乐 −27 dB，说话时按分轨压：主旋律 −22、铜管 −17、电钢和吉他 −13、其余 −12 dB；
  - 片名到隧道没有旁白，配乐是主角，+6 dB；冲出隧道那一下到第 8 句之前 +2 dB。不加这一步，片头比有旁白的段落低 6–8 dB，砸片名没劲；
  - 每句「人声 − 底子」14.7–23.6 dB。

## 5. 竖版改造

- `cel.js` 的 `W, H` 改成 1080×1440，`bg.js` 的 `drawLoop` 循环宽度改成 `W`；下摇的长画、高架全景、黎明大画按 1080 宽重画（`plates.js`）。
- `post.js` 不用改（按画布尺寸算）。
- 眼睛大特写：样片 1080p 横版用 4.6 倍；竖版 1440 高，4.6 倍只是近景，要 10.5 倍、描线 0.36 倍才是「只看得到眼睛」。
- 字幕：思源黑体 900、50 px、奶黄 `#fff0a0` + 10 px 深色描边，底边离画面底 110 px；按标点断成 ≤15 字一块，同一时间只留一块。

## 6. 返工记录

1. **车背面只画出一半**：`Path2D.roundRect` 做的圆角矩形拿去 `clip()`，页面里第一次这样用时，之后这一帧画的东西全没了（第二帧才正常）。自己用 `arcTo` 画圆角（`cel.js` 的 `rrect`），不再用 `Path2D.roundRect`。
2. **次回予告下面一道发光的重影**：前面电脑那几镜把发光层的 `textBaseline` 设成了 `top`，画布状态会带到后面的帧（save/restore 只管一次绘制）。每帧开头 `ctx.reset()`。
3. **电脑屏幕、透写台过曝**（§3.3）。
4. **录像带像磁带**：窗太小、两卷带子靠太近。窗放宽到 540，带卷放大、拉开。
5. **进带的方向**：第一版带子从上面滑进仓口，正面看不对。改成带脊塞在仓口里、一点点退进黑暗。
6. **手指露在带子外面**：手往上挪，四根手指藏到带子后面，只露拇指和手掌下缘。
7. **ハーモニー大画左上角一块黑**：崖的剪影画成了一把黑伞，改成海平线上一道低低的岬角；下方公路补了湿路面映太阳和护栏立柱。
8. **片名推近时出画**：字从 236 px 改成 218 px。
9. **仪表上方多一道光**：仪表整体下移了 170 px，玻璃上掠过的光带没跟着移。
10. **声音**：抽空那一拍里留着冲击前的一声「嘶」（−6 dBFS），删掉；风和海浪在人声频段太响（L02、L08–L11 只有 9–11 dB），各降 9–11 dB，说话时再压 10 dB；主旋律、铜管按分轨多压；片头纯音乐 +6 dB。
11. **次回予告的铜管压着「先收藏」**：挪到开口前 0.75 s。

## 7. 下一期能直接拿走的

- **录像带结构**：先放成片 → 倒带（前面几镜倒着再画一遍 + 跟踪噪声 + 屏显）→ 回到开头讲怎么做的 → 按下 PLAY 放完整的。任何「成片 + 幕后」的片子都能套。
- **每帧 `ctx.reset()`**，别用 `Path2D.roundRect` 做裁剪。
- **没有旁白的段落给配乐加增益**：有旁白的地方按分轨压（主旋律压最多），纯音乐的地方 +6 dB，整片听起来才平。
- **两套网格**：开头预告一套、片中片一套（以片名那一下为 0），中间跟着旁白走的段落沿主网格往前延伸。
