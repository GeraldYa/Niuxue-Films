# 08 数据叙事（`dataviz`）做片笔记

> 一支红蓝铅笔在米色纸上画「AI 的饭量」：训练一个 AI 模型要做多少次运算。从 1950 年一只走迷宫的机械老鼠（40 次）画到 2026 年（大约 1 后面跟 27 个零）。每一级台阶是一次破纪录，每个点一个音。画完换成普通刻度，前七十多年几乎贴着地面。第二幕在图下面的空白处，用铅笔写「这张图是怎么做的」。

## 1. 构思

- 这个风格的铁律是「图就是片子，每个记号都是真数」。所以三样干货不能画成装饰，得先找一份真数据，让图本身好看、好懂，再把「怎么做」放到第二幕。
- 选题：AI 训练算力（Epoch AI 的公开数据，CC BY 4.0）。选它有三个原因：
  - 跟账号的 AI 题材对得上；
  - 数据自带这个风格要的几拍：早年稀疏、2010 以后变陡、顶破图框、最后一点单独落下；
  - 小白一眼能懂的「哇」：从 40 次涨到 1 后面 27 个零。
- 编码：对数刻度的**破纪录台阶图**。
  - 每一级台阶 = 一次破纪录（当时最费算力的模型），淡点 = 同期其他模型；
  - 纵轴刻度用中文大数：1、1万、1亿、1万亿、1亿亿……每格 ×1 万，比 10¹⁶ 好懂；
  - 招牌那一拍用「换刻度」代替样片的「点变条纹」：对数 → 普通刻度，前七十多年全趴下，最后几年竖起来。
- 人的尺度：早年两条蓝色批注是「记忆」（1950 走迷宫的机械老鼠、1957 感知机学认图形），后面两条红色批注是「纪录」（2016 AlphaGo 赢了李世石、2026 那一串零）。
- 三样干货放在第二幕，写在图下面的空白处，像图注下面的「制作说明」：
  - 用什么：「画图的笔 = AI 编程助手」，「引擎 = Niuxue-Films」（印出来，笔再圈一下）+「免费 · 开源」；
  - 怎么说：那句话照配音的逐字时间一个字一个字写出来；下一行「开工前，它先问你一轮」，三个框，念到哪个勾哪个；
  - 适合拍什么：数据新闻 · 年度报告 · 气候科普；红笔写「只讲步骤的 → 交给白板」。
- 结尾：最后一个点右边画一个空格子，写「下一个点？」；旁白「下一个点，你来画」，格子撑开变成片尾卡（片中片）。

## 3. 关键手法

### 3.1 数据先过一遍：每个说出口的数都从抽取脚本打印出来
- `tools/extract.py` 按表头取 `Training compute (FLOP)`，算出破纪录（按日期走，同一天只留最大的），写 `compute.json`，再把旁白要说的数全打印出来：
  - 起点 40 次、终点 1.0001×10²⁷；
  - 跨度 76.2 年；
  - 两段斜率：2010 前约 12 个月翻倍，2010 后约 6 个月；
  - 第一个顶破 10²¹ 和 10²⁵ 的是谁；
  - 2025 年以前最大的只有终点的 5%。
- 片子里不点名 2026 年那个模型，只说数；标题下方和片尾都写「训练算力多为估算」，因为多数是 Epoch 的估算。

### 3.2 时间全从配音推（`timeline.js`，顶层 await 读 words.json 和 compute.json）
- 每句起点 = 上一句结尾 + 间隙，往后取整到半拍（`qUp`）；关键画面挂在念到的字上，例如：
  - 「往上一格」时画双箭头；
  - 「2010」时立红虚线；
  - L07 那句话按逐字时间一个字一个字写；
  - 「配音、音乐、分镜」各在念完时打勾。
- 破纪录的点：早年手排在拍上；冲刺段按年份线性映射到 6 拍，再取整到三十二分音符（90 BPM、24 fps 下正好 2 帧），画面和音乐零漂移。
- 淡点（其余 540 个模型）按「笔扫过它的年份」冒出来：落在前后两次破纪录之间，按年份插值到笔在台面上的行程。台面走得慢，淡点就一粒一粒；冲刺时一秒几十粒。

```js
export function cloudT(y) {
  const a = REC[i - 1], b = REC[i], t1 = tap[i], t0 = t1 - TRAV[i];
  return t0 + (y - a.y) / (b.y - a.y) * (t1 - t0) * .8;     // 台面占行程的前 80%，后 20% 爬台阶
}
```

### 3.3 竖版：标题放进图框左上角
- 对数台阶是一条从左下到右上的斜线，图框左上角整片都空着，标题「AI 的饭量」和三行小字放在那里，后面垫一块纸色挡住格线。
- 这样整图视角（zoom 0.8）上下都不挤：顶上留给 2026 那串零，底下留给字幕。
- 标题那一拍单独停 3 秒（拉到 zoom 1.0，上面标题、下面第一个点），然后淡出，跟着笔走；整图时再淡回来。

### 3.4 换刻度（招牌那一拍）
- 每个点的纵坐标在对数位置和普通位置之间插值，从左往右错开扫过去；台阶线跟着点走；对数刻度淡出，普通刻度（0、250亿亿亿……1000亿亿亿）淡入。
- 批注在扫过时淡掉；2026 那两行字钉在对数位置不动，圈跟着点走，免得字压到图框线。

### 3.5 第二幕的手写跟着配音走
- `unitReveal()`：把要写的字逐个对到配音的逐字单元，标点跟前一个字一起出；返回每行写到第几个字（可以是小数），`handText` 按宽度比例揭开。
- 坑：句首的「「」在念第一个字之前就露出来了。没到时间时要返回已经确定的字数，不能返回当前下标。

### 3.6 封面：`?poster=1`
- 整张图（对数、台阶、批注）用单独的镜头压在下半，上面 DOM 排大字：「一句话」马善政 250 px、「让 AI 画出会唱歌的图表」、红标「不花钱生成视频」，系列小字放在红标右边。
- 坑：刻度标签为了不钻进字幕区，限制在屏幕 y 1150 以上；封面没有字幕，要放到底，不然最下面的「1万」「1」没了。

## 4. 声音

- **配音**：10 句，白板工具的期「2026-09-29 风格片08 数据叙事配音」，气声比 −26.6 到 −33.6 dB，都正常。
- **配乐**（`music/score.py`，照 demo 的做法全部现合成）：
  - 每次破纪录一个「咚」，音高 = 对数高度，从 D3 爬到 D6。早年吸到五声音阶，中段取半音，最近几年不取整，最后十来个音慢慢走调；硬切前最后一个音最刺耳（加小二度影子）。
  - 其余模型是很轻的一粒「嗒」，冲刺时像雨。
  - 垫底：Dmaj9 → G/D → D Bm G A → 2010 以后 Bb/D、Dm 变暗 → 半音簇；再加一条越来越高的嗡声。
  - 节奏：第三句起两拍一下底鼓，顶破后每拍一下，2010 起十六分踩镲，冲刺加采样保持的哔哔声。
  - 硬切：所有层清零 1 秒；之后最后一个点单独一个最干净的音，垫一个空五度（没有三音）。
  - 换刻度：每个音再响一次，往下滑五度，像点掉到地上。
  - 片尾再响一次 1950 那个音。
- **环境**：
  - 房间底噪；
  - 开场几声继电器咔嗒（Epoch 对那只老鼠的注释：每个继电器动作算一次运算）；
  - 2010 以后越来越响的机房嗡声，硬切时一刀断。
- **电平**：
  - 旁白 −18 dB；
  - 配乐 −28 dB，说话时数据的音压 13 dB、垫底和节奏压 10 dB，拟音压 5 dB；
  - 每句「人声 − 底子」12.0–18.1 dB。

## 5. 竖版改造

- `engine.js` 只改了三处：`W, H = 1080, 1440`；手写默认字体换成小赖字体（Xiaolai，笔记感的手写体，OFL）；排字默认字体加上思源宋体兜底中文。
- 图的几何按竖版重排：每年 14 px，图框高 960 px，横跨 1950–2026 约 1070 px，整图 zoom 0.8 刚好装下。
- 字幕是自己写的中文图注：左对齐，上面一条细线和年份小标题（1950–笔走到的年份），逐字按配音出来，≤15 字，冒号、句号后不并。

## 6. 返工记录

1. **L05 读成「一千亿……亿亿次」**：第一版台词「涨到约一千亿亿亿次」，配音在第一个「亿」后面停了 0.45 s，听着像卡壳。改成「涨到大约一后面跟二十七个零」重配，画面上把 27 个零写出来，四个零一组，正好对上纵轴「每格 ×1 万」。
2. **第一轮静帧（46 张）**：
   - 冷开场批注右边被切：镜头拉远到 zoom 2.3；
   - 标题那一拍太短、大标题没露面：单独停 3 秒；
   - 2026 那串零跟左上角标题挤在一起：标题挪进图框左上角；
   - 硬切后的特写，点在画面边上：镜头右移、退到 1.35；
   - 片尾那段左边还挂着冻结的刻度：进片尾前淡掉。
3. **「人声 − 底子」只有 5.6–10.4 dB**：拆开量——
   - 第二幕是写字的沙沙声（只比人声低 7 dB）：音量减半，说话时再压 5 dB；
   - 第 4、5 句是配乐里数据的音：数据那一轨说话时压 13 dB，2026 那个音的尾巴从 2.4 s 收到 1.5 s，第 5 句晚 0.17 s 进；
   - 第 4 句最后差 0.4 dB，是那段 D Bm G A 和弦，调轻 2.5 dB。
4. **字幕交接两句叠在一起、年份小标题印两遍**：同一时间只留一句（前一句在后一句出来前 0.2 s 退场），小标题只跟着这一句画；字幕底色在两句之间多撑 0.5 s，不透出底下的批注。

## 7. 下一期能直接拿走的

- **数据类片子的流程**：公开数据（CC0 / CC BY）→ 抽取脚本打印每个要说的数 → README 写来源和取用日期 → 片尾署名。
- **`timeline.js` 的排法**：旁白起点取整到半拍，关键画面挂在字上，冲刺段按数据映射到三十二分音符。
- **`unitReveal()` + `writeByChars()`**：任何「边说边写」的风格（白板、钢笔淡彩、一笔画）都能直接用。
- **中文大数刻度**（万、亿、万亿……）：对数轴每格 ×1 万，比科学计数法好懂。
- **竖版图表构图**：斜线型数据把标题放进空着的那个角；整图 zoom 0.8；底下 300 px 留给字幕。
