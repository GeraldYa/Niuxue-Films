# 20 浮世绘（`ukiyoe`）做片笔记

> 一条竖版手卷，五幅木版画从右往左读：一 写、二 问、三 挑、四 印、五 晾。做一支视频的五步，每一步印成一幅。
> 开场先给成片：第四幅，一道巨浪冲出画框。念完第一句，四块色版一块块从纸上揭起，手卷倒卷回第一幅，从头印起。
> 念到「都交给它」盖「AI」章，巨浪起来冲出画框、朝镜头倒下，白纸静场，四记大太鼓印出最后一幅。

| 项 | 数 |
|---|---|
| 成片 | 63.9 s，1080×1440，24 fps，−16 LUFS（CRF 21，颗粒 0，25.8 MB） |
| 渲染 | 1534 帧，`core/render/video.mjs --workers 6` 约 30 秒（Canvas 2D） |
| 配音 | 11 句，全部原版 |
| 状态 | 做完没发 |

下文只写文件名的都在 `films/20-ukiyoe/` 下。

## 1. 构思

- 这个风格的本事（STYLE §2）这期全用上了：
  - 一套连作：五幅就是做视频的五步；
  - 手卷：从右往左平移，越来越快；
  - 一版一版印出来：开场倒过来用，一版一版揭掉；
  - 纸就是白：碎浪铺满画面变回白纸；
  - 画框是个东西：巨浪冲出画框，伸进裱纸。
- 三样干货各落在一幅里：
  - 用什么：她写的题字抬头是「AI编程助手：」；版木库的扁额写 Niuxue-Films，一只手（名字签：AI编程助手）抽出「浮世绘」那块；
  - 怎么说：一句话写成画上的题字；开工前的三个问题挂成三只风铃；
  - 适合拍什么：晾绳上三张小版画（旅行、日本文化、诗词），一张黑底的「暗色科技发布」被风吹走（交棒 17）。
- 五幅的名字是五个动词：写、问、挑、印、晾，题签上方的浅红小签统一写「一句话」。
- 系列规矩「开头先给成片」：开场就是巨浪那一幅（成片最好看的一下），然后「揭版 + 倒卷」回到白纸。跟 11 期倒带、14 期倒放、19 期倒收是一个路数，这里用的是版画自己的语言：一块块色版揭起来。

## 3. 关键手法

### 3.1 竖版
- `print.js` 的 `W, H` 改成 1080×1440，墨线边框 `FR` 跟着改；和纸、胡麻摺、木纹、吃墨显现的纹理都按画幅比例生成（原来写死了 1920×1080 的格子，直接拉伸会变形）。吃墨的斜向扫改成左上 → 右下。
- `wave.js` 的巨浪几何是写死的绝对坐标：地平线 612 → 880、浪根 742 → 1250、浪高 820 → 1130；浪身三道蓝带的宽度是像素，按浪高放大（`KS = HW / 820`），不然浪身会显得条纹太细。
- 一张纸就是一屏（z = 1），手卷上五张竖纸横排，纸间 200 的裱纸空。拉远到整卷时 z ≈ 0.16，五幅在竖屏中间排成一条，上下是片尾卡。
- 字幕题签离底 96 px；画面最下面 150 px 放地面、水、榻榻米这类不要紧的东西。

### 3.2 开场：成片 → 揭版 → 倒卷
第四幅的吃墨进度分两段：念 L07 之前是「揭」，之后是「印」。

```js
function revFor(i, g, t) {
  if (i === 0) return clamp((t - T.print1[g]) / REVEAL_DUR);
  if (i === 4) return clamp((t - T.print5[g]) / REVEAL_DUR);
  if (i === 3) {
    if (t < T.print4[0] - .5) return 1 - clamp((t - T.un[3 - g]) / .26);   // 揭：红 → 绿 → 蓝 → 墨线
    return clamp((t - T.print4[g]) / REVEAL_DUR);
  }
  return 1;
}
```

- 揭的时候用同一张吃墨遮罩倒着走，再加上错位滑开，看着就是色版被一块块揭起来。
- 巨浪是每帧现画的（不在缓存的色版里），揭的时候跟着蓝版的进度一起淡掉。注意 `printTex()` 自己设 `globalAlpha`：不乘外面的透明度，浪身淡掉了木纹还留着，是一个浪形的残影。
- 巨浪的状态单独一个函数：开场 = 成片（高悬、冲出画框），印的时候平静，翻页时每页高一截，然后接起浪四拍（`waveState`）。
- 倒卷时经过的「挑」「问」两幅是印好的，一闪而过当预告；「写」是白纸，到了再一版一版印。

### 3.3 画上的中文
- 她写的那句话是画上的题字（浮世绘常在空白处题字）。四列竖排，右起第一列是抬头「AI编程助手：」，每个字按念到的时间出现（`story20.js` 的 `INSCR`）。
- 马善政里的拉丁字母认不出来，「AI」写出来像「ㄐ‖」。凡是马善政排的地方，拉丁字母一律换 Shippori 明朝体：竖排题签、印章、横排标签（`mixText` / `mixLine`），竖排里的字母立着排、字号 0.72。
- 39 块版木的标签是画廊的 39 种短名（「像素RPG」「HD-2D」这种混排的也走 `mixText`）。

### 3.4 三只风铃、39 块版木、翻页
- 风铃：念到问题前 0.2 s 从檐下落下来，弹两下；风铃声（拟音）晚 0.35 s，正好落定时响。第一只挂的是她那张「一句话」，所以这一幅接着上一幅。
- 版木库：3 列 × 13 行正好 39 格，竖版的柜子。「浮世绘」在右列，第一版往右抽出去出了画框，改成往左下抽，手从右边跟过来。
- 一帧一帧：「一帧一帧地剪」四个字挨得太近（每字 80 ms），挂在字上根本看不出翻了几页。改成在念这句的时间里均匀翻四页，每页一张纸从右往左翻过去，浪高一截。

### 3.5 巨浪（竖版的高潮）
- 起浪时镜头第一次大动：往上摇、拉开到 0.84，让浪头冲出画框、露出上面的裱纸；高悬时基本不动；倒下时朝浪头推近 3 倍、转一点点；碎浪用浪爪铺满屏，最后一层纸盖上去 = 白纸。
- 碎浪那一帧之后硬切到第五幅的白纸（手卷上的另一个位置），因为满屏都是纸，看不出切了。

### 3.6 小版画和黑卡
- 晾绳上三张 250×336 的小版画各自带边框和小题签：旅（山路 + 旅人，借样片的 `traveler.js`）、和（鸟居、石灯笼、樱花）、诗（月夜、桥、船、题诗「月落乌啼霜满天」）。念到哪样挂哪张，落到绳上摆两下。
- 黑卡故意不是浮世绘：黑底、青色折线、思源黑体「暗色科技发布」「下一期见 →」。被风吹进来，念到「交给」又被吹走，就是交棒。

### 3.7 封面
`?poster=1`：开场那一幅（z 0.84），左边一个大竖题签「一句话」，上面一条横题签「让 AI 印出一套浮世绘」+「39 种风格 · 20 浮世绘」，底下红色「不花钱生成视频」。横题签里的「AI」也走混排。

## 4. 声音

- **配乐**（`music/score.py`）全部现合成，照 STYLE §6 的序・破・急：
  - 三味线：`pluck.py` 的 shamisen；
  - 尺八：自己合成（基音 + 几根弱泛音 + 跟着包络的气声，每个音从下面半音滑上来，句尾 meri，起音「村息」），气声别太大，不然十几秒的长音底下一直是嘶嘶声；
  - 太鼓、締太鼓、拍子木也是现合成（§5）。
- 拍子木四击渐快印出第一幅；每落一版一记太鼓；翻页拍子木连击；起浪太鼓从 0.9 s 一下加速成滚奏，高悬到顶后 80 ms 吸一口气（全混音清零），倒下再滚，碎浪全奏，然后「間」1.8 秒绝对无声。
- **拟音**（`mix.py`）照样片的材质拟音，加了揭版（纸从版上揭起，越撕越快的细碎纸响）、写字、抽版木、翻页、风。
- **电平**：旁白 −18 dB；配乐安静处 −24 dB，说话时按分轨压（三味线 −16、尺八 −18、太鼓 −8、拍子木 −8）；拟音和环境声说话时再压 6 dB。每句 12.2–24.1 dB。

## 5. 返工记录

1. 她跪坐时袖子鼓得像个葫芦、围巾尾巴像个背包：袖子改成沿前臂垂下的宽袖，围巾尾巴改成一条窄带。
2. 马善政的「AI」认不出来（题字、名字签、「AI」章、封面）：拉丁字母换明朝体（§3.3）。
3. 云画成了一堆交叠的透明圆圈：先描所有圆、再填所有圆，只剩并集的外轮廓，底边一刀切平。
4. 抽出来的版木出了画框：改成往左下抽（§3.4）。
5. 翻页挂在字上，四页挤在 0.3 秒里（§3.4）。
6. 开场揭版时浪身淡掉了，木纹还留着一个浪形的残影（§3.2）。
7. 片尾字体那行漏了思源黑体（黑卡和封面角标用了它）。
8. 混音第一版 L08、L09、L10 不到 12 dB：
   - 黑卡飞走的风声在人声频段：改成低频的风 + 一点高频；
   - 挂小版画的纸响压小；
   - 拉远时的手卷声压小；
   - 尺八说话时从 −14 压到 −18。

## 6. 下一期能直接拿走的

- **竖版木版画引擎**（`print.js` 竖版副本 + 分版缓存 + 吃墨显现 / 揭版）：任何「印出来」的风格（木刻、孔版、半调）都能借「一版一版印 / 揭」的做法。
- **开场成片 → 揭版 → 倒卷**（§3.2）。
- **中文书法字体 + 拉丁字母混排**（`mixText` / `mixLine`、竖排里的字母）：用书法字体的风格都要这个。
- **合成尺八、太鼓、締太鼓、拍子木**（`music/score.py`）：日本题材、武侠、节庆都能用。
