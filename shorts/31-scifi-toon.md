# 31 科幻情景喜剧卡通（`scifi-toon`）做片笔记

> 这个风格是双人对话喜剧（面瘫天才 + 慌张搭档），可配音只有我一个声音。解法：
> - 「她」是旁白，嘴型对着我的配音；「助手」是 AI 编程助手——显示器脑袋、开衫，一句话不说，回话全打在头顶的终端气泡里（「在。」「不。」「就它。」「你也行。」）；
> - 开场先给成片（传送门开着、片名挂着）；**助手按一下退格，传送门把一切吸回去、合上**，这就是这一期的「清零」；
> - 问号宇宙、开源库 39 个宇宙快切（整帧换成水墨、窗花、像素的画风）、回家四只手干活、屏幕换台、把头伸进 30 期的木刻世界。

## 1. 构思

- 风格说：这一类的发动机是「很小的日常目标 + 大得离谱的科幻手段」；天才什么都能做，却拿来干小事，搭档替他付情绪的代价。
- 这一期：小目标 = 今晚要发一条视频（墙上便利贴「今晚要发！」、笔记本上一条空的「00:00」时间线）；大手段 = 传送门穿宇宙。
- 风格的语法全用上：每个宇宙一套配色、三连 → 连珠炮（开源库快切）、「反常的平静」（#31 就是自己家）、每个离谱画面后面接一个反应、冷场一秒的笑点（木刻头）、结尾回到开场。
- 三样干货：问号宇宙的三只「？」小怪举牌（配音？音乐？分镜？）；开源库读数牌「Niuxue-Films #01 … #31」；助手屏幕换三个台（搞笑短剧、科技品牌、社交短视频）。
- 交棒：她把头伸进门里 30 期的木刻世界，拔出来整颗头变成黑白木刻——最彩色的卡通交给只有黑白铜三色的版画。
- 红线：不照搬任何现成动画的角色、配色、名字、口头禅和传送枪；样片的故事和角色也不用。角色、小怪、道具都自己设计。

## 3. 关键手法

### 3.1 一个声音演两个人
- 说话的只有「她」：口型用 `lips.py` 算每 1/24 s 的张合（50 ms 窗 RMS，按句 95 分位归一）和「亮度」（频谱质心：亮 = 宽嘴，暗 = 圆嘴），按 12 fps 取样。
- 「助手」的脸是屏幕上一双半闭的眼睛，回话打在终端气泡里：深绿底、绿字、光标闪；气泡一个字一个字打出来。她打那句话的时候，气泡里的字跟着配音的逐字时间出（标点跟着前一个字）：

```js
function typedAt(t) {
  const us = WORDS.L04.u, str = [...'用科幻卡通风格，把做视频的每一步，演成一集穿越喜剧。'];
  let n = 0, ui = 0;
  for (let i = 0; i < str.length; i++) {
    if (/[，。]/.test(str[i])) { if (n === i) n = i + 1; continue; }
    if (ui < us.length && t >= VOT.L04 + us[ui][1]) { n = i + 1; ui++; } else break;
  }
  return n;
}
```

### 3.2 换宇宙 = 整帧换画风
- 开源库快切不另画三个世界：同一个家、同一个站位，画完以后对整帧做处理，一眼就是「另一个风格的宇宙」。读数牌和字幕在处理之后才画，不受影响：

```js
if (kind === 'pixel') { px.drawImage(cv, 0, 0, W / 12, H / 12); g.imageSmoothingEnabled = false; g.drawImage(PX, 0, 0, W / 12, H / 12, 0, 0, W, H); }
// 其余按像素：水墨 = 灰度 + 纸色；窗花 = 亮度过 0.5 是米白，否则是红
if (kind === 'ink') { const v = Math.pow(l, 1.35); /* 墨 → 纸 插值 */ }
else if (kind === 'paper') { const on = l > .5; d[i] = on ? 246 : 195; d[i + 1] = on ? 231 : 18; d[i + 2] = on ? 204 : 47; }
```

- 号码往上跳那一秒，每两帧换一种处理（水墨、窗花、像素、反色、换色道），配一串越来越高的「哔」。

### 3.3 只处理角色的一部分：用她自己的剪影当遮罩
- 木刻头要只刻她的头发和脸。第一版按圆形区域处理，把背景墙也刻成了一个圆。
- 改法：记下画她之前的形状计数（`S.sid`，描边抖动的种子跟着它走），在离屏画布上用同一个镜头、同一个种子再画她一遍，得到跟正片完全重合的剪影；只处理剪影里、领口以上的像素：

```js
const sid0 = S.sid; her(P); HEAD = { P, sid: sid0 };
// …整帧画完以后
init(HC); cam(...CAM); S.sid = sid; her(P); init(cv);   // 引擎的 g 是可以换的画布
```

### 3.4 竖版
- 两人中景：她在 x≈300，助手在 x≈790，脚在画面三分之二处，下面留给字幕；读数牌在左上角，气泡在助手头顶偏右，互不遮挡。
- 问号宇宙：两个人缩小放在左下角抬头看，三只小怪分三层（地面、中间的浮岛、高处的浮岛），牌子才不挤在一起。
- 助手的手要伸到画面另一边（话筒递到她嘴边）：面条手直接拉长，卡通里越长越好笑。

## 4. 声音

- **配乐**（`music/score.py`）：120 BPM，全部现合成。
  - 特雷门琴 = 正弦 + 0.22 × 二次 + 0.08 × 三次谐波，70 ms 滑音，每个音 150 ms 后才揉，弹簧混响（带 28 Hz 抖动的衰减噪声）。另有模拟贝斯、方波琶音、鼓机、铜管、电钢琴。
  - 主题是原创的 A 小调。每个宇宙一段动机，第一拍就是剪辑点：
    - 问号宇宙 = 大号「嘭嚓」+ 往上挑的滑哨（问句的语调）；
    - 水墨 = 古琴、窗花 = 锣鼓、像素 = 芯片音、#31 = 主题强奏。
  - 退格 = 整段按变速重读、磁带停转；干活时第三只手一碰电子琴，电子琴领奏就进来；木刻头之后整段真静（混响尾巴一起清零）。
- **拟音**（`mix.py`）：传送门、弹簧、黏液照样片的合成法，其余这一期自己做（键盘、回车、终端「哔」、剪刀、沙发、爆米花、换台、奶油派）。
- **电平**：
  - 旁白 −18 dB。
  - 配乐：不说话时 −25 dB；说话时按分轨压，特雷门琴 −14 dB（它就在人声那一段），中频再挖 8 dB。
  - 拟音：第一版问号宇宙那句只剩 5.6 dB。问号宇宙的「空气声」在人声频段，传送门的嗡嗡声也在。改法：
    - 空气声挪到 380 Hz 以下；
    - 拟音说话时压 10 dB、中频挖 6 dB；
    - 压在词上的笑点音往两边摆。
  - 改完每句 12.7–27.6 dB。

## 5. 返工记录

1. 翻钱包的手举到脸前，挡住了脸：伸到身体右边，钱包放大。
2. 竖一根手指像在挠头：手举到身体旁边。
3. 问号宇宙三只小怪全挤在右下角，上面大半是空天空：两只站上浮岛，拉开高低。
4. 问号小怪不像问号：
   - 问题：眼睛长在钩子里面，牌子挡住了钩子；
   - 改法：重做成真正的「？」字形（粗弧 + 竖钩 + 分开的点），眼睛放到弧顶，牌子挪到右边。
5. 助手多出来的两只手画在身子后面，看不见：改成从身体两侧长出来，画在身子前面。
6. 木刻头把背景墙也刻成了一个圆：用她自己的剪影当遮罩（3.3）。
7. 开场人物太小：镜头推近。
8. 封面承诺那行压在便利贴上：
   - 便利贴收掉；
   - 那行字下面垫一块深色圆角底；
   - 人物的脚落在底部色带上沿。
9. 开场气泡「⌫ 从头来」被画面右边裁掉：往左挪。
10. 拟音压人声：见上面「电平」。

## 6. 下一期能直接拿走的

- **一个声音演双人喜剧**：一个说（嘴型对配音）、一个只打字（终端气泡，逐字出），笑点靠反应特写和气泡里的一两个字。
- **整帧换画风**（`fx`）：引用系列里别的风格，不用真的去画那个风格。
- **用角色自己的剪影当遮罩做局部处理**（`woodHead`：同一套抖动种子再画一遍）。
- **合成特雷门琴 + 鼓机 + 铜管 + 锣鼓 + 芯片音**（`music/score.py`）、**卡通拟音**（`mix.py`）、**磁带停转**（`tapestop`）。
