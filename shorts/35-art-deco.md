# 35 装饰艺术（`art-deco`）做片笔记

> 黑漆底、雕刻感的金线、喷枪渐变的硬边几何，一切沿中轴展开；讲法是一座 1930 年代大饭店的开幕之夜。
> - 开场先给成片（塔楼竖灯牌「开幕之夜」全亮追灯、烟花）；终止和弦落下那一刻**灯牌一个字一个字「咔嗵」灭**——这就是这一期的「清零」；
> - 那句话 = 一张请柬，逐字烫出来；AI 编程助手 = 穿门童制服的黄铜机器人小门童；
> - 电梯指针表当菜单，塔楼剖面 39 层当开源库，停在 35 层；配电盘四个闸刀 = 写代码 / 配音 / 配乐 / 剪辑，拉一个亮一个字；「都交给它」屏住一拍，全乐队进来。

下文只写文件名的都在 `films/35-art-deco/` 下。

## 1. 构思

- 风格说：找门（沿中轴开合）、找钟（期限）、找一样能数着亮的东西（灯牌、楼层号），再找高潮要解锁的东西（一首歌）。
- 这一期：
  - **门**：标题拱门劈开见 AI、旋转门扫进电梯厅、35 层电梯门打开、片尾电梯门合上——转场全是开合；
  - **数着亮的东西**：竖灯牌「开幕之夜」四个字 = 四个闸刀 = 写代码 / 配音 / 配乐 / 剪辑；
  - **数字**：39 层 = 39 种风格，到站 35 层，请柬火漆也是「35」；
  - **一首歌**：样片配乐里的那首歌，只在开场露个结尾；四个闸刀各带一个音（歌的头四个音），「都交给它」之后全乐队第一次完整唱出来。
- 样片的故事（门童送信、电梯坏了、楼梯、后厨、十二声钟）不用；借它的引擎、塔楼、电梯门、指针表、灯泡灯牌、歌舞片俯拍和配乐。

## 3. 关键手法

### 3.1 中文灯泡字
- 样片的 `bulbs.js` 对任何字体都管用：字画到画布上 → Zhang–Suen 细化成单像素骨架 → 按交叉数找端点和交点、描成链 → 等距撒灯泡。
- 中文要挑字体：几何感强的站酷庆科黄油体骨架最整齐，但「幕」「夜」认不出来；**站酷小薇（ZCOOL XiaoWei，OFL）**笔画细、结构清楚，做成灯泡字一眼认得。栅格 300 px、灯距 17。
- 竖灯牌：四个字竖排，每个字一张透视卡（`cardTransform`），挂在塔楼正面中轴上；字下面一条检修小阳台，片尾机器人站在上面挥帽。

### 3.2 一个字一个字亮 / 灭
- `drawSign` 的 `lit(li, bi, gi)` 返回每颗灯泡的亮度（> 1 是点亮瞬间的过冲闪）。
  - 开场：追灯（按 `gi` 走的十六分音符）→ 终止和弦后夜、之、幕、开依次灭，灭之前闪一下；
  - 配电盘：前三个字各在一个词念完时点亮；第四个字「夜」跟着「一帧一帧地剪」六个字分六格亮（按灯泡顺序切六段）；总闸后全亮一闪，全乐队进来开始追灯。
- 窗也按时间灭：每层一个熄灯时刻，从上往下扫，每扇窗再错开一点。

### 3.3 横版样片改竖版
- 样片全是 1920×1080 写死的：夜空、塔楼、门、字幕卡这些在 `set35.js` 里按 1080×1440 重写（`makeCam` 传 `W, H`）。
- 塔楼竖着正好：仰拍时整座楼占满竖屏，灯牌放大到每个字 11.6 m 才压得住画面。
- 配电盘镜头：机位在灯牌前面、比小阳台高一点往上看，四个字整个落在配电盘上方，配电盘和小门童在画面下三分之一。
- 封面单独一个机位：整块灯牌落在大字标题和底栏之间。

### 3.4 新角色：机器人小门童
- 样片角色骨架（`chars.js`）加一种 `bot`：身体照用门童的（勃艮第红制服、V 形铜扣、白手套），头换成黄铜蛋形头盔：喷枪渐变 + 受光边金线、正中一道流线鳍、黑漆面罩横带上两只发光的杏仁眼、收音机喇叭嘴、耳朵是两枚旋钮，帽顶伸出天线，顶上一颗四角星。
- 坑：面罩一开始画成杏仁形、嘴画成五道竖槽，半身特写像一张部落面具；改成圆头横带 + 横椭圆喇叭格栅就成了友善的机器人。
- 角色一拍两格（12 fps）：只把算姿势用的时间量化到 1/12 s，镜头、灯泡、金线照样每格都动。

### 3.5 转场全是开合
- 沿中轴劈开：出画镜头冻成一帧，左右两扇门叶从中缝往外摆开（样片 `film.js` 的 `splitOpen`，竖版重写）。
- 旋转门：一扇玻璃翼从右往左扫过。
- 合门：两扇铜门从两边滑进来合上；开场清零那次，门缝的金线再收拢成一个金点，正好是下一个镜头长出放射线的地方。

## 4. 声音

- **配乐**（`music/edit35.py`）：样片原创配乐（lemo-opuscar，CC BY 4.0；钢琴采样 Salamander，CC BY 3.0）按画面重剪，落点从 `score.json` 来，七段：
  1. 开场：那首歌的后半，镲 + 管钟落在第一帧，终止和弦 = 开始熄灯；
  2. 金点 → 标题：原曲开头，单簧管滑音 → 全乐队一击 = 标题条 → 弦乐上行刷 = 拱门劈开（原曲这两下差 3.1 s，画面就按它排）；
  3. 请柬 + 菜单：狐步 vamp 6 小节（第 3–4 小节再来一遍）；
  4. 起步：军鼓「啪」那一拍，接查尔斯顿加速段第 8 拍起，26.2 那一下 = 到站；
  5. 配电盘：不放配乐，闸刀和灯丝声当节奏，四个闸刀各带一个音；
  6. 全乐队：那首歌 A + B，B 再来一遍（旁白放不下，加两小节），尾句上行 → 终止和弦 = 片名；
  7. 片尾：合门那一刻接样片尾巴。
- **重拍避开字头**：标题那一击原来对在「一行字」的「一」上，混音里压字；挪到「一行字」念完的停顿里。闸刀「咔嗵」也挪到每个词念完。
- **拟音**（`mix.py`，全部合成）：按材质分：闸刀（金属咔 + 低频嗵 + 弹簧余震）、灯丝（120 Hz 嗡，升 / 降）、铜门滑轨、金线刮擦、纸、手套、蜡封、玻璃翼、指针、电梯电机 + 楼层嘀嗒（按电梯曲线越来越快）、铃、烟花（哨音 + 闷响 + 碎屑）、掌声。
- **电平**：旁白 −18 dB；配乐不说话时 −23 dB，说话时压 8 dB、中频挖 6 dB；每句自动量「人声 − 底子」到 13 dB，再按 0.4 s 小窗局部再压（最多 6 dB）。
  - L08 句尾「电子请柬」正好压在歌里管钟（D♭5）的余音上：整句够 13.5 dB，whisper 在混音里还是把「请」听成「勤」。这句门槛提到 16 dB、加了小窗局部再压以后听对。
  - 自检：每句从成片里切出来过一遍 whisper，11 句全对。

## 5. 返工记录

1. 灯泡字体：几何体的「幕」「夜」认不出，换站酷小薇。
2. 机器人脸像面具：面罩改横带、嘴改喇叭格栅。
3. 配电盘第一版机位太近，配电盘挡住了「夜」字：机位后撤、抬高。
4. 电梯剖面开头整个下半屏是空地面：起幅把电梯笼放到画面下三分之一。
5. 结尾拉远第一版起幅太远，小门童只有几个像素：近景贴到小阳台，先停 0.45 s 再拉。
6. 封面第一版大字挡住了灯牌上半：封面单独一个机位。
7. 标题一击压字、L08「请」被管钟盖住：见 §4。

## 6. 下一期能直接拿走的

- **中文灯泡字**：`bulbs.js` + 站酷小薇；`lit(li, bi, gi)` 写成按时间亮 / 灭 / 追灯 / 一格一格亮。
- **样片配乐按画面重剪**：原曲里的两个落点间隔就是画面上两件事的间隔，画面反过来按配乐排；放不下的地方重复几小节。
- **重拍避开字头**：重拍、关门、拉闸都挪到词与词之间的停顿里。
- **成片混音过 whisper**：配音单听都对，混音里照样可能有字被乐器盖住；按句切出来过一遍。
