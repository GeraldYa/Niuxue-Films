## 1. 构思

- 样片的语法（STYLE §2、§5）：一把被偷的钥匙、一场追逐、几何碎片最后拼成片名；**钥匙的外形 = 钥匙孔**；剪辑点落在铜管强奏上；片头字幕沿 30° 斜线滑进来。这期把三样干货全塞进这套语法里：
  - 用什么：AI 编程助手是一台两只卷盘的机器（间谍片里的电传机 / 录音机），牌子上写「AI 编程助手」；免费开源库是字母当柱子的长廊 NIUXUE-FILMS，柱子下面 39 扇小保险柜门，15 号打开是「间谍片头」；
  - 怎么说：那句话就是「密令」，一条纸带盖上红章，念到哪个字打出哪个字；它先问的三件事是机器吐出的三张卡片，吐完定格一拍（配乐全停）；
  - 剩下的交给它：圆形匹配剪辑，一句词一样东西：写代码 = 打字机键，配音 = 话筒，配乐 = 小号，一帧一帧地剪 = 片盘 + 剪刀，都交给它 = 机器的卷盘；
  - 适合拍什么：画廊卡片的三个用途（Title sequences / Event openers / Trailers）就是三处追逐布景，布景本身是三行大字；不适合的（慢慢讲故事）让信使溜进「蜡笔绘本 →」那扇门。
- 她要抢回的钥匙，就是片名「一句话」的钥匙：结尾钥匙插进「句」的口里，一拧 —— 这一段你也做得出来。

## 3. 关键手法

### 3.1 竖版和四墨
- `paper.js` 的 `W, H` 改成 1080×1440 就够了：毛边剪纸 `piece()`、剪影、纸纹 `paperFinish()` 都按画布尺寸算。30° 斜切线在竖版里一样成立（`DIR = [sin 30°, −cos 30°]`，碎开、字幕滑入、网格都沿它走）。
- 四墨只有黑、奶油、红、芥末黄，**黑墨剪影放在黑底上就没了**。第一版有几场是黑底黑人，人整个不见：黑底的场里，人要么站在奶油色的大月亮前面，要么整个换成奶油色剪影（片尾卡那个）；其余的场换底色：偷钥匙是奶油底 + 红斜带，密令是红底，问问题是芥末底，「预告片」那处布景也是芥末底。

### 3.2 中文剪纸字（`hz.js`）
样片的 League Gothic 没有中文。做法：浏览器把字画到画布上，描出轮廓，变成跟 `glyph.js` 一样的结构，再交给它剪毛边。

```js
x.font = `900 ${RS}px ${font}`; x.fillText(ch, ox, base);          // RS = 220 px，思源黑体 900
// marching squares：每个 2×2 格按 16 种情况连线段 → 连成闭合轮廓 → RDP 抽稀（eps 0.7 px）
// → 换成以基线起点为原点、字号 1 的坐标：{ polys, adv, x0, x1, top }
out.push({ ch, x, w: t.adv * sc, polys: …, x0, x1, top, i, sz: 'hz' + size.toFixed(1) });
```
- `layoutHZ(str, size)` 的返回值直接给 `drawLine()`，毛边、纸影、错位跟英文字母一模一样。
- 两个坑：`glyph.js` 剪纸缓存的键原来只有种子和字，同一个字换了字号拿到的是旧尺寸的纸片（键里加上 `sz`）；全角空格描不出轮廓，`polys[0]` 是空的，`piece()` 直接报错（空白字符只占位）。
- 字形就是形状：片名「句」里面那个口，找第二个字里面积最大的内轮廓（`lockOf()`），锁板就盖在那里。

### 3.3 剪辑点 = 铜管强奏 = 念到的字
- `timeline.js` 里每个剪辑点都挂在念到的字上（`at('L07', '配', 1)`），`STABS()` 把它们列成一张表写进 `events.json`；`music/score.py` 读这张表，在每个剪辑点放一记铜管强奏，**早 8 ms**，峰值正好落在换画面那一帧。
- 改一句台词，剪辑点、强奏、拟音一起顺延，不用手对。

### 3.4 圆形匹配剪辑
- 五样东西的「圆」都放在同一个位置、同一个大小（`MC = {x 540, y 640, r 250}`）：打字机键帽、话筒网罩、小号喇叭口、片盘、机器的卷盘。每个强奏换一样，底色跟着换（红 / 芥末 / 黑 / 红 / 奶油），眼睛只看到圆在，东西变了。
- 小号正面看容易像钥匙（第一版就是）：要画出喇叭口的同心圈和旁边的活塞，身体缩到一半。

### 3.5 三处布景就是三行字
- 「片头」是屋顶（字号 500，再大两个字就出画）、「活动开场」是火车车厢、「预告片」是跑马灯。她和信使在字上跑，一处比一处短。
- 布景切换同样挂在字上（`at('L08', '活') - .15`）。

### 3.6 结尾：钥匙 = 钥匙孔，一拧
- 推进去对准锁板：`zs = lerp(1, KH.h / (lk.h * 1.6), pi)`，推完锁板占满画面中间，红钥匙孔又回到画面正中，跟开场黑底上那个钥匙孔对上。
- 钥匙飞进来，大小按钥匙孔算，外形正好填满；「一拧」= 绕自己的长轴转，正面看就是横向缩到 0.28（`g.scale(lerp(1, .28, turn), 1)`），配锁舌咔。
- 咔之后镜头继续极慢地推 7%，静场那一拍一起停（第一版咔完干停 5 秒）。

### 3.7 她
- 样片的特工剪影（`agentSide`）加一个 `opt.her`：礼帽换成外翻短发 + 一道缝，领带换成芥末黄围巾（绕脖子一圈、尾巴飘起来，`tiePoly` 多一个宽度参数）。跑、滑步、回头、起跳、够钥匙都用样片的姿势表。

### 3.8 封面
`?poster=1`：黑底，大月亮前她跃起够钥匙（开场那一格），下面黑的那块压剪纸大字：芥末黄「一句话」、奶油色「让 AI 做出一段间谍片头」、红底「不花钱生成视频」，顶上一行「39 种风格 · 15 60s 间谍片头」。

## 4. 声音

- **配音**：11 句，气声比 −24.3 ~ −34.3 dB（L11 齿音多，跟前几期同一句，留原版）。旁白过一道很轻的磁带：低切 110 Hz、一点点饱和，说话时底下一层磁带嘶声。
- **配乐**（`music/score.py`）：E 小调 132 BPM，原创间谍大乐队，全部现合成：
  - 合成铜管：锯齿波三层轻微走调，低通截止频率随包络打开（铜管「亮起来」），小号、长号叠八度，强奏和弦 Em6/9；
  - 弱音小号主题（原创）：B–A♯–A–G | E，附点节奏，不用那个有名的 E–F–F♯–F 爬行；
  - 冲浪吉他低音弦：`pluck.py` 钢弦 + 自制弹簧混响（一串色散的回声，41 ms 往返、2 秒衰减）；
  - 行走贝斯（`pluck.py` 低音提琴拨弦）、刷子鼓 + 叮叮镲、追逐段的十六分「铁轨」军鼓、邦戈；
  - 三张问号卡之后的定格、最后一拍前，配乐连混响尾巴一起清零（`score.py` 打印两段静场峰值，都是 −240 dBFS）。
- **拟音**（`mix.py`，`core/audio/sfx.py` 现合成）：纸（字母落地的啪、撕开、盖章、卡片弹出、滑动）、金属（钥匙叮当、插进锁里、锁舌咔、剪刀）、打字机、火车轰隆 + 按节拍的车轮哐当、门。
- **电平**：旁白 −18 dB；配乐 −23 dB，说话时按分轨压（主题 −16、铜管 −10、贝斯 −10、鼓 −12、吉他 −10）；拟音一开始就压低，说话时再压 10 dB。片名那一记和弦落在 L10 上，第一版这句只有 9.8 dB，和弦减轻后 13.7 dB。每句「人声 − 底子」13.7–28.3 dB。

## 6. 下一期能直接拿走的

- **中文剪纸字** `hz.js`：任何系统字体 → 轮廓多边形，跟 `glyph.js` 的 `drawLine` / `cutLetter` 通用。别的「把字当形状剪」的风格（瑞士动态排版、装饰艺术、红色窗花的字）也能用；字形里的洞（口、日、回）可以拿来当道具的位置。
- **剪辑点表**：`STABS()` 挂在字上 → `events.json` → 配乐按表放强奏（早 8 ms）。任何「音乐打点剪」的风格都能照抄。
- **圆形匹配剪辑**：同一个圆、换东西、换底色，一句词一样东西，讲「写代码、配音、配乐、剪辑」这一段特别省事。
- **合成铜管**：锯齿波走调叠层 + 随包络打开的低通，大乐队、爵士、谍战、复古游戏都能用。
