# 18 微游戏快闪（`microgame`）做片笔记

> 一档游戏节目。主场：紫色舞台、走马灯招牌、一台金色电视、讲台和大红按钮；主持人是 AI 编程助手（对话气泡头、光标鼻子），她是选手（齐耳短发、红围巾、18）。做一支视频被拍成七关，每关一种画法：打字（终端）→ 回答（蜡笔）→ 挑（像素，顶第 18 块）→ 加速！→ 写代码（蓝图）/ 配音（水墨）/ 配乐（孔版）/ 剪（瑞士）→ 都交给它 → 最后一关三张卡翻出「适合拍什么」→ 灯一暗，电视里放纸雕灯影那一期 → 全部通关。

| 项 | 数 |
|---|---|
| 成片 | 60.9 s，1080×1440，24 fps，−16 LUFS（CRF 21，颗粒 0） |
| 渲染 | 1461 帧，`core/render/video.mjs --workers 6` 约 30 秒（Canvas 2D + 五个 WebGL2 材质通道） |
| 配音 | 11 句，L01 改过一次词 |
| 状态 | 做完没发 |

下文只写文件名的都在 `films/18-microgame/` 下。

## 1. 构思

- 这个风格的本事（STYLE §2）：一关一种画法、命令词就是整场戏、两轮之间「加速」、最后一关把前面的规则混在一起。做一支视频正好拆成七个动作：打字、回答、挑、写代码、配音、配乐、剪 —— 七关。
- 三样干货全在关卡里：
  - 用什么：主持人就是 AI 编程助手（讲台上写着），她发的那句话在第 1 关的终端里一个字一个字打出来；免费开源库是像素关的 39 个问号块，顶第 18 块弹出「18 微游戏快闪」；
  - 怎么说：第 2 关蜡笔的三个问题气泡；
  - 剩下的交给它：加速以后一个词一关（写代码 / 配音 / 配乐 / 一帧一帧地剪），不回舞台，最后「都交给它！」；
  - 适合拍什么：最后一关三张卡（体育赛事 · 像素、品牌视觉 · 瑞士、活动开场 · 孔版）；不适合的：灯一暗、只剩一束光，电视里放纸雕灯影那一期（慢），这个风格里最「慢」的一下。
- 系列规矩「开头先给好看的」：开场就是通关的舞台（过关章、彩纸、她欢呼），然后主持人拍按钮，节目从头开始。
- 这期没用样片的「掉命」：系列的语气是「你也做得出来」，每关都过；紧张感交给加速和最后一关。

## 3. 关键手法

### 3.1 竖版
- 主场改成竖版：招牌在上、电视在中间、主持人和她分站两边。电视屏幕改成 3:4（432×576 = 画面的 1/2.5），这样「推进电视」正好铺满画面、每一关直接画满竖版。
- `glpass.js` 的材质通道是整幅的，画幅改成 1080×1440 就行；从样片复制的画法模块只留工具函数，场景全部按竖版重画。

### 3.2 推进 / 缩回电视
- 统一转场就是电视（STYLE §4）：舞台整体按对数放大，电视屏幕中心对到画面中心，放大 2.5 倍正好满屏（`zoomStage`）；缩回来反过来。
- 命令词、引线、过关章要**画进这一关的画面里**，缩回电视的时候一起带走。第一版画在最外层，缩回时过关章直接消失，只闪了 0.1 秒。

### 3.3 每一关的开始吸到拍子上
- 第一轮的拍子从招牌亮完算起（120 BPM），每关的推进时间往后吸，让命令词正好砸在拍子上；第二轮（140 BPM）从加速卷轴停完算起，一个词一关的切点吸到最近的八分音符。最后一关、交棒、通关、片尾都往后吸到第二轮的拍子。
- 配乐按同一套时间放铜管强奏、每关的颜色乐器和终端打字的哔哔。

### 3.4 七种画法各画一次她
- 三样一定留着：齐耳短发、红围巾、18。终端 = 手写的字符画（围巾一行反白）；蜡笔 = 排线涂出界的大头娃娃；像素 = 12×20 的小人；蓝图 = 线稿 + 引线标注「18」；水墨 = 一团浓墨的头发 + 一点朱砂的围巾 + 朱砂印「18」；孔版 = 黄衣服、粉围巾叠成橙；瑞士 = 黑圆 + 黑长方 + 红圆。
- 主持人没用样片的秒表头，自己画了一个「AI 编程助手」：对话气泡头、两只眼睛、鼻子是一根青柠色光标（每拍闪一下，当节拍器）。

### 3.5 静止的开场
- 第一版开场 12 秒（L01–L03）一直是同一个舞台。加了电视换台：从招牌亮完到 L03，电视每拍换一种画法（七关各挑一个好看的时刻），角标写「7 种画法」；她挥手，念到「你也做得出来」欢呼。
- 「都交给它」时电视里拼四种画法（2×2），最后一关先亮出三张卡背，免得出现黑屏。

### 3.6 封面
第一版直接拿通关那一帧压大字，字压在招牌上，底下还露出字幕。改成单独排：招牌上就是「一句话」，一条洋红横幅写「让 AI 把做视频变成闯关游戏」，电视里拼四种画法，底下青柠色「不花钱生成视频」，最下面「39 种风格 · 18 微游戏快闪」。

## 4. 声音

- **配音**：L01 原稿「这段快闪，是一句话做出来的」换了三个种子，4 kHz 以上的能量都偏高（中位数 −22 ~ −24 dB，听起来发虚），是「快闪」这两个字本身的问题；改成「这段闯关视频，是一句话做出来的」一次就正常（−28.0 dB，中位数 −31.3）。
- **配乐**（`music/score.py`），全部代码合成：鼓、合成拍弦贝斯、合成铜管、FM 电钢，每关一种颜色乐器（方波、木琴、脉冲琶音、弱音小号、古琴、颤音琴 + 萨克斯、响棒）；C → D → E 每轮升一个全音；交棒半速只剩电钢；通关前一拍真静，最响的一下紧跟在最长的安静后面。
- **拟音**（`mix.py`）：跟着画法走（电传、蜡笔、剪刀、卷轴、卡片），主场有弹簧按钮、电视进出的风声、过关章、合成掌声。
- **电平**：旁白 −18 dB；配乐 −24 dB，说话时按分轨压 12–14 dB；拟音说话时再压 8 dB。每句 14.6–22.1 dB。

## 5. 返工记录

1. L01 发虚：换词（§4）。
2. 过关章只闪 0.1 秒（§3.2）。
3. 开场 12 秒不动、「都交给它」电视黑屏、最后一关开头一秒全黑（§3.5）。
4. 终端顶上的标题跟「打字！」小标签叠在一起：标题往右挪。
5. 最后一关三张卡被字幕挡住：卡往上收。
6. 蜡笔气泡里的字太小（78 → 96 px）；孔版「活动开场」那块太暗（改成黄底、三色烟花）。
7. 封面叠字（§3.6）。

## 6. 下一期能直接拿走的

- **竖版主场 + 3:4 电视 + 推进 / 缩回**：任何「节目」「关卡」结构的片子都能用。
- **七种画法的竖版小场景**（`games18.js`）：终端、蜡笔、像素、蓝图、水墨、孔版、瑞士，各一两百行以内，可以当这几种风格的速写模板。
- **两轮拍子网格 + 吸拍**：`timeline.js` 的 `up()` / `near()`。
- **AI 编程助手当主持人**：对话气泡头 + 光标鼻子的角色，后面的片子要一个「AI 编程助手」角色可以直接拿。
