# 32 低多边形等距小岛（`lowpoly-island`）做片笔记

> 一座低多边形的六边形小岛，正交等距镜头，像桌上的模型；每长出一样东西就响一个音。
> - 开场先给成片（黄昏、窗户亮着、灯塔在转）；然后**整座岛由外往里一格一格沉回海里**——这就是这一期的「清零」；
> - 那句话念一个字，海里长一块地、响一个音；三面旗、39 块踏脚石、黄昏干活、灯塔在「都」字点亮；
> - 夜里光束扫到一只挂着 31 期封面的木筏（交棒），正交拉远，岛变成海上一粒光。

## 1. 构思

- 风格说：挑「媒介本身就在讲故事」的题目；五个本事至少用三个（程序化生长、正交视角、转台、平涂 × 光照方向、黑暗里的发光块）；招牌是「造岛就是作曲」。
- 这一期：做视频 = 长一座岛。「那一句话」是海里冒出来的第一块地；那句话本身就是岛的旋律（念一个字长一块地）。五个本事全用上：生长、正交拉远、转台、一天的光、夜里灯塔的光扫过房子。
- 三样干货：沙滩上三面旗（配音？音乐？分镜？）；岛外一圈 39 块踏脚石，第 32 块亮；干活的四件事各是一样东西（房子一层层落 = 写代码、钟楼 = 配音、风车 = 配乐、码头木板 = 一帧一帧地剪）。
- 样片的故事（小船走失、灯塔把它找回来）不用；只借它的做法和零件。

## 3. 关键手法

### 3.1 开场成片 + 沉回海里
- 每样东西都有两个状态：开场是「最终状态」（全岛建好、灯亮着），沉没以后按时间表一样样长回来。道具全挂在自己那块地的组里，地沉，道具跟着沉：

```js
if (fin) y = 0;                                          // 开场：成片
else if (t < T0.sink + .5 && t < T0.t0 - .5) { const u = seg(t, T0.sink, T0.sink + .45); y = -(c.h + 2.6) * u * u; }   // 沉
else { /* 按 t0 从水下升起 + 弹一下 */ }
```

- 沉的顺序由外往里（`sink = sink0 + (1 - d / 3) * 跨度`），最后沉的是灯塔山顶。

### 3.2 生长时间表跟着配音走
- 那句话的 21 个字：`WORDS.L04.u` 的每个字的时间就是一次「升起」，岛上剩下的地块按离第一块的远近分给这 21 个时刻（一个字一到两块），每次带一个五声音阶里的音。
- 三面旗落在「配 / 音 / 分」三个字上，39 块踏脚石在「三十九种风格」这几个字里升完，码头六块木板落在「一帧一帧地剪」六个字上，灯塔在「都」字点亮。

### 3.3 竖版正交相机
- 视野高 = 缩放：竖版宽度只有高度的 3/4，看整座岛要把视野高开到 17–18（横版 12–14 就够）。
- 每个特写的方位角按那样东西的位置现算（`90° − 物体方位角`，就是从外面正对着它）；码头挪到向阳的一面（太阳方位 ~110°），不然整个在影子里发暗。
- 木筏上的画每帧转向镜头：`rotation.y = atan2(-camBack.z, camBack.x)`。

### 3.4 读数和标签
- 画面上的中文都画在 2D 层上：字幕（思源黑体 + 左边一个跟着天色变色的小六边形地块）、开源库标签、第 32 块石头上的「#32 低多边形」（把石头的位置投影到屏幕上）、三块用途标签、交棒标签。
- 旗子上的字画在画布贴图里；旗面是正面贴图 + 背面素色两块，从背后看不会是反字。

## 4. 声音

- **配乐**（`music/score.py`）：事件驱动，乐器照样片的模态合成。每个生长事件在它的准确时刻合成它带的音：地块 = 马林巴、树和旗 = 卡林巴、楼层 = 木鱼、屋顶 = 卡林巴 + 马林巴、木板 = 往上走的马林巴、灯塔四环 = 往上的马林巴、点亮 = 一声「开花」+ 低音、光束扫过房子 = 卡林巴领奏。开场房子的六个音慢慢放一遍，沉没时马林巴往下滑；清晨一声浮标钟，片尾远处同一声。点亮前 0.25 秒配乐整条是零。
- **拟音**（`mix.py`，照样片跟材质走）：出水的气泡 + 水花、木头、陶瓦、石头、玻璃、低频「嗡」；这一期自己加了沉岛的水声和旗子的布声。环境：浪、白天海鸥、风车吱呀、入夜蟋蟀。
- **电平**：
  - 旁白 −18 dB。
  - 配乐：不说话时 −25 dB；说话时按分轨压，中频再挖 8 dB。
  - 那句话本身就是旋律，第一版 L04 刚好 12.0 dB：这几句底下多让 1–2 dB。
  - 改完每句 12.5–21.6 dB。

## 5. 返工记录

1. 海上那几秒浮标被挤到画面左边缘：镜头目标放在浮标和第一块地中间。
2. 开场片名压着灯塔：镜头目标抬高，岛往画面下方挪。
3. 三面旗顺序反了（配音在最右边还被裁掉一截）：旗子按方位倒过来排，镜头拉远。
4. 风车特写被前景的两面旗挡住（风车和旗子在岛的同一边）：风车换到岛的另一边。
5. 码头特写发暗：
   - 天色往后推，干活那几个特写停在金色时段；
   - 特写的雾调淡；
   - 码头挪到向阳的一面。
6. 木筏上的画侧面对着镜头，只看得到一条边：
   - 画每帧转向镜头；
   - 画放大；
   - 找到木筏以后镜头推近。
7. 从背后看旗子是反字：背面换成素色。
8. 窗户的一行多余代码算出 NaN：删掉。
