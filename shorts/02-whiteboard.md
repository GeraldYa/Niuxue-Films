## 1. 构思

- **骨架**：照搬 STYLE.md §2 的 story shape，每一拍换成这期的干货。顺序是：小东西 → 拉远见尺度 → 标题踩第一个重拍 → 三步机制 → 静场 +「但是」→ 用二重奏讲转折 → 笑点演后果 → 板擦倒带 → 同步修好 → 拉远全板 → 片尾写在标题下。
- **笑点换成平台动作**：原版是磁铁一拍漂一天、漂进海里。这期换成「观众早划走了」，磁铁「你」往上一刷飞出画面，就是刷小红书的手势。

| 干货（SHORTS.md §8） | 板上的画面 | 用到的母题 |
|---|---|---|
| 怎么说：一句话 | 开头聊天框里橙色的「一句话」，拉远是手机，再拉远是整块空板 | 小东西 → 拉远见尺度 |
| 用什么：AI 编程助手 | 笔记本加终端提示符 `>` | 一句话一张图 |

- **口吻**：讲课的口气，短句、口令式（「先准备两样东西」「然后对它说一句话」「倒回去」）。「倒回去」是旁白发的口令，板擦照做。
- **开头**：「一句话，就能让 AI 给你画出一整堂白板课。」是结果承诺，跟标题、封面同一个句式。画面同时从一句话拉远到整块板，说的和画的一起兑现。没套固定开头（SHORTS.md §8）。
- **结尾**：金句「好的白板课，每一笔都踩在点上。」配拉远全板；「先收藏，下一期，换一种画法。」配镜头回到标题。
- **「不适合」指向系列里的别的期**：情绪和风景交给水墨（01）。后来 03 皮影把「满屏数字、图表」交回给白板。

## 3. 关键手法

### 3.1 中文按笔顺手写
- **效果**：板上的中文跟英文一样，是马克笔一笔一笔写出来的。笔顺是对的，笔跟着走，每一笔都有声音。
- **怎么做**：
  - 字库取 Make Me a Hanzi 的笔画中线（medians，本来就按笔顺排），转成跟 EMS Tech 同一格式的单线字形：y 向上，基线 0，字高 880，基线下 106，字宽 900。只收脚本里出现的字。本期扫了 `film.js`、`test.js`、`poster.js`，共 269 字。
  - `text()` 按这个顺序找字：引擎自带字形和 EMS → `hanzi` 字库 → 中文标点表 `CJKP`；都找不到就 `console.warn('缺字')`，画一个「?」。全角的 `？！（）—～＝` 走 `ALIAS`，借英文字形。
  - 汉字笔画默认乘 0.8（`cjw`），比同样 `w` 的英文细一点；字距用 `cjSpacing` 调。
  - 汉字的每一笔是一个 `Stroke`，排进时间线就按笔顺写，拟音也按笔出声。
- **排版前先算宽**：`text()` 用 EMS 的 cap height 677 缩放，汉字字宽 900，所以一个汉字宽约 1.33 × h。封面上「一句话」h 250，三个字约 997 px，加上左边距就出了 1080 的画面（见 §7）。
- 改了字要重跑字库，不然缺的字会画成「?」。先在写字测试页上看粗细、字距和基线，再动正片：本期的测试页是 `films/02-whiteboard/test.js`，用 `?scene=test` 出静帧。
- **代码**：`styles/whiteboard/demo/engine/wb.js` 里的 `text()`、`CJKP`、`ALIAS`，已经在库里；`tools/build-hanzi.mjs`（SHORTS.md §4）。

### 3.2 画面挂在字上
- **效果**：每样东西都在念到那个字时落笔，在那个词念完时收笔。改一句台词，后面的画面跟着挪。
- **怎么做**：
  - 旁白起点不手填，一句接一句算：L01 从 0.8 s 起；标题重拍 `T0` = L01 结束后 0.45 s；L02 = T0 + 3.35 s，这段留给标题写完；之后每句 = 上一句结束 + `GAP[id]`。静场 `HUSH` 也由 GAP 算出来。
  - `at(id, '某几个字', k, 's'|'e')`：把这句的逐字单元拼成字符串，找第 k 次出现的位置，换回单元，取开始或结束的时刻。逐字表的格式见 SHORTS.md §3。
  - 所有画都用 `tl.draw(pen, shapes, 起, { by: 止 })`，引擎自己解手速，保证在 `by` 写完（STYLE.md §4）。本期包成 `D(pen, shapes, a, b)`。
  - 框这类「容器」比词早一点：流程框 `t − .32 → t − .02`，框里的字 `t → t + .36`。
- **代码**：`films/02-whiteboard/film.js`
```js
const GAP = { L03a: .5, L03b: .1, L04: .45, L05: .35, L06: 1.85, L07: .3, L08: .2, L09: .45, L10: .9, L11: .4, L12: .3, L13: .7, L14: .9 };
const VO = {}, END_OF = id => VO[id] + words[id].dur;
VO.L01 = .8; const T0 = END_OF('L01') + .45; VO.L02 = T0 + 3.35;
let prev = 'L02';
for (const [id] of LINES.slice(2)) { VO[id] = END_OF(prev) + GAP[id]; prev = id; }
const HUSH = [END_OF('L05') + .25, VO.L06];
const at = (id, sub, k = 0, which = 's') => {       // 第 k 次出现的 sub 在 id 句里的开始（'s'）或结束（'e'）时刻
  const U = words[id].u, str = U.map(u => u[0]).join('');
  let idx = -1, from = 0;
  for (let n = 0; n <= k; n++) { idx = str.indexOf(sub, from); if (idx < 0) throw new Error(`${sub} 不在 ${id}`); from = idx + 1; }
  const unitOf = ci => { let c = 0; for (let i = 0; i < U.length; i++) { c += U[i][0].length; if (c > ci) return i; } return U.length - 1; };
  return which === 's' ? VO[id] + U[unitOf(idx)][1] : VO[id] + U[unitOf(idx + sub.length - 1)][2];
};
```

### 3.3 坑演成剧情①：两把尺
- **效果**：「嘴上讲到第三步，笔还在画第一步」不靠嘴说，让人看出来。蓝色「声音」尺每拍长一格，黑色「画笔」尺三拍才长一格。念到「第三步」时，声音尺正好走到圈号 3，画笔尺才到圈号 1 那一格的高度。
- **怎么做**：
  - 两把尺竖着往下长（x=1450 和 x=2450，格距 280）。
  - 从结果倒推起点：`duet0 = at('L08', '第三') − 9 拍`，声音尺的第 9 格就落在「第三」上。
  - 声音尺每 3 格加一个圈号，当「第 N 步」。
  - 每格都 `tl.cue()` 一下，配乐拿来打木鱼：声音尺打高音，画笔尺打低音。配乐里同一段琶音分一快一慢两层（见 §4）。
- **代码**：`film.js` 的「E · 坑」段
```js
const RV = 1450, RP = 2450, R0 = 4180, RS = 280, NT = 9, tickY = i => R0 + i * RS;
// …
const duet0 = at('L08', '第三') - NT * BEAT;           // 声音第 9 格正好落在「第三步」
for (let i = 0; i <= NT; i++) {
  const t = duet0 + i * BEAT; tickV.push(t);
  D(B, W.line(RV - 50, tickY(i), RV + 50, tickY(i), { w: 8, bow: 0 }), t - .07, t + .04);
  tl.cue(t, 'tickV', { i });
  if (i && i % 3 === 0) D(B, [W.circle(1296, tickY(i), 40, { w: 6 }), ...T(String(i / 3), 1296, tickY(i) + 24, { h: 50, w: 7, align: 'center' })], t + .06, t + .38);
}
for (let j = 0; j <= 4; j++) {                        // 画笔慢 3 倍：声音讲到第 3 步，笔才到第 1 步
  const t = duet0 + j * 3 * BEAT; tickP.push(t);
  D(K, W.line(RP - 50, tickY(j), RP + 50, tickY(j), { w: 8, bow: 0 }), t - .07, t + .06);
  tl.cue(t, 'tickP', { j });
}
```

### 3.4 坑演成剧情②：磁铁「你」被划走，板擦倒带
- **效果**：磁铁「你」落在尺子右边，念到「划」时抖了抖、往上飞出画面。「倒回去」之后，板擦顺着画笔尺从下往上擦；最后 0.5 s 磁铁从上面掉回原位，落定是一声重的磁铁声。
- **怎么做**：
  - 磁铁不是笔画，是 `board.objs` 里的道具。`pinPath(t)` 按时间分段，返回位置、抬起高度和旋转，再用 `W.drawPinMagnet` 画出来。这是原版的做法。
  - 板擦用 `tl.erase(path, t, 1.5, { width: 170, strength: .92 })`，擦完留 8% 残影。
  - 擦完重画画笔尺。引擎按代码里的调用顺序记 `epoch`：写在 `tl.erase` 之后的 `draw` 不会被这块板擦擦掉，写在前面的会被擦，跟时间先后无关。
  - 板擦圆头的半径 = width / 2 = 85，路径端点离要留的字得超过这个距离（STYLE.md §8）。
  - **02 自己就栽在这条上**（09-29 复查才发现）：路径上端停在 y=4120，把尺子上方「画笔」两个字的下半截也擦了，重画只补了尺子，48 s 以后这两个字一直是残的。修法：路径上端停在字下沿 85 px 以外，或者擦完连字一起重画。
  - 刷走的时候镜头跟一点（往右上，微歪 0.01），倒带时回来。
- **代码**：`film.js`
```js
const rw0 = VO.L09 + .25, rwDur = 1.5;
tl.erase([[RP, tickY(4) + 90], [RP, 4120]], rw0, rwDur, { width: 170, strength: .92 });
D(K, penRuler(), rw0 + rwDur + .1, at('L10', '每') - .12);
// …
const pinPath = t => {
  // …落下、停住
  if (t < swipe) { const u = (t - swipe + .25) / .25; return { x: PIN[0] + Math.sin(u * 9) * 6 * u, y: PIN[1] - u * 30, lift: u * .5, vis: true }; }
  if (t < swipe + .32) { const u = (t - swipe) / .32; return { x: PIN[0] + u * 60, y: PIN[1] - 30 - u * u * 2600, lift: .6 + u * .4, rot: u * .4, vis: true }; }
  if (t < rw0 + rwDur - .5) return { vis: false };
  if (t < rw0 + rwDur) { const u = (t - (rw0 + rwDur - .5)) / .5; return { x: PIN[0], y: PIN[1] - (1 - u) ** 2 * 2600, lift: 1 - u, vis: true }; }
  return { x: PIN[0], y: PIN[1], lift: 0, vis: true };
};
```

### 3.5 修好：一个字一格，两支黑笔轮流画
- **效果**：「每一笔都挂在一个字上」这 10 个字，每念一个，画笔尺就补上一格，补完跟声音尺一样密。每格一个钟琴音，一路往上走。
- **怎么做**：直接取逐字单元的开始时刻，从「每」字所在的单元往后数 i 个。
- **两支笔**：字与字之间只隔 0.08 s，一支笔跳不过来，第一次排出来每格的窗口只有 0.03 s。所以用两支黑笔 K、K2 轮流画。
- **代码**：`film.js`
```js
const fixChars = [...'每一笔都挂在一个字上'], fixT = [];
fixChars.forEach((_, i) => {
  const t = VO.L10 + words.L10.u[words.L10.u.findIndex(u => u[0] === '每') + i][1];
  fixT[i] = t;
  D(i % 2 ? K2 : K, W.line(RP - 50, tickY(i), RP + 50, tickY(i), { w: 8, bow: 0 }), t - .04, t + .04);
  tl.cue(t, 'tickFix', { i });
});
```

### 3.7 静场，然后甩镜
- **效果**：流程画完打 ✓，接着 1.6 s 只剩挂钟，镜头慢慢推近「出片 ✓」，微微歪（roll −0.018）。「有个坑」的「有」字上来一记 b 小调，加全片最强的一口风声（v=1.0），镜头 0.5 s 甩到两把尺。
- **怎么做**：
  - `HUSH = [L05 结束 + .25, VO.L06]`。GAP.L06 是 1.85 s，里面有 1.6 s 是静场。
  - 用 `tl.cue(HUSH[0], 'hush', { t1 })` 导出去。`score.py` 和 `mix.py` 都把这一段清零，前面留 0.35 s 淡出。

**配乐**（`music/score.py`，全合成）

**拟音**（`mix.py`，改自原版 demo 的 `mix.py`）
- **马克笔**：1,247 笔，每笔一个声音。
