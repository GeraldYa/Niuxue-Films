# 39 象形运动图形（`pictogram-motion`）做片笔记

> 整行错位的方格图案、几何象形人、遮罩上滑的双语大字、角落的等宽小字 + 进度刻度、每一刀都落在鼓点上。讲法是一场运动会：**「一句话运动会 ONE-LINE GAMES」**，做视频的每一步都是一个比赛项目。
> - 开场先给成品（结尾卡），**清零 = 三张倒数卡**（会画画 → 0、生成视频的钱 → ¥0、一句话 0 → 1）；
> - 起点 = 起跑线（「各就各位」时起跑线下打出那一行字，「预备」后半拍静音，砰）；那句话 = 跑道长镜头三个站；先问一轮 = 三张两拍快切卡；开源库 = 39 格图标墙，第 39 格放大；
> - 写代码 / 配音 / 配乐 / 剪辑 = EVENT 01–04，「都交给它」= 章节卡；收尾：12 个项目翻成一面墙、收成一颗太阳、「你也做得出来」。

## 1. 构思

- 风格说：这是「目录片」——N 个项目一张卡一张卡卡着拍子过，项目分章、每章一种颜色，数量本身就是钩子（ALL 43 SPORTS）。每个项目要有一个 1.6 秒读得懂的动作（动词）。
- 这一期把系列每期都讲的那几步办成一场运动会：比赛项目 = 写代码、配音、配乐、剪辑；系列的那句话 = 起跑线上的那一行字；开源库的 39 种风格 = 收尾那种图标墙；「都交给它」= 章节卡。
- **样片是一部真实赛事的粉丝宣传片**：赛事名、口号、会徽、五色和色名都是主办方的（STYLE.md §10.6 写明新片要全换）。这一期名字、会标、五色都是自己的；方格图案的纹样是通用几何形，照用。

## 3. 关键手法

### 3.1 横版引擎改竖版
- `engine.js` 只改画布尺寸（1080×1440 = 180 px 方格 6 列 × 8 行）和五色；图案、骨架、文字工具都不用动。整行错位的转场改成 8 行、整列的改成 6 列 180 px、翻牌 6×8。
- 版式重排：A = 太阳盘 + 人形在上半（圆心 y 520），文字块在下半（大标题基线 1050），空心大编号右上；B = 英文大字铺满做底、太阳盘和人形压在字上、底下一条中文 + 英文 + 编号。人形层在文字区前 80 px 淡掉（样片 `stageFigure` 的遮罩）。
- 字幕（这一期有旁白，样片没有）：墨色底条 + 左边一道珊瑚色，放在 y 1252；版式里所有字都在 1200 以上，进度刻度在 1400。

### 3.2 切点落在拍上，台词照样跟得上
- 风格要「每一刀都落在鼓点上」，旁白又是自己的节奏：卡片切在「念到那个词之前最近的一拍」（晚 50 ms 以内也算这一拍），段落从拍点换、不必在小节线上；鼓按 16 分音符逐格排，律动始终锁在全片的小节网格上。配乐的自检把 24 个切点的起音都对上了（±15 ms）。
- 五个大鼓（片名、起跑、章节卡、收尾、结尾卡）前空半拍：鼓、低音、三味线停，留样片的反向混响吸进去。

### 3.3 新动作先出检查表
- 新加 11 个动作，每个先在 `lab/` 的检查表里看 4–6 个时刻。踩到的坑：**手臂在躯干坐标系里**——躯干前倾 70° 时，手臂写 −70 是往后上方举，要写 +70 才是竖直撑地；剪刀第一版横着贴在胶片上看不出来，改成胶片从上往下送、剪刀横着端、剪下的格子亮着往下掉，「一帧一帧地剪」六个字对六刀。
- 写代码借样片的电竞台子（`Object.assign` 一份，`back` 里先画样片的，再把屏幕盖成一行行代码）。

### 3.4 收尾用自己这一场的项目
- 样片的收尾墙是 43 个大项；这一期是片里出现过的 12 个动作（3×4），从中间往外变成珊瑚色、往中心收成一颗太阳，太阳就是会标的那颗，接口号「你也做得出来」。

## 4. 声音

- 配乐和音效全部现合成：借样片 `music.py` 编曲之前、合成和混响那两段（`exec` 进来），编曲按 38 个小节重写；段落鼓型照样片（起点只留大鼓 + 沙锤、跑道是主律动、快切卡 ball / rackets、四个项目 combat、章节卡滚奏、收尾 finale）。
- **三味线主题只放在没台词的空档**（片名、章节卡、收尾的图标墙），正好是这三个「会标时刻」；说话的地方只垫很轻的古筝琶音，碎拍（镲、沙锤）也收三成。
- 混音照 37、38 期：最后每句「人声 − 底子」17.1–21.6 dB，whisper 在成片里 11 句全听对。

## 5. 返工记录

1. 起跑的手臂往后上方举（坐标系弄反）：躯干前倾 70°，手臂写 +70。
2. 剪刀看不出来：改成竖着送片、横着剪、剪下的格子往下掉。
3. 开场卡的会标压到大字：会标上移、整块往下排。
4. 图标墙第一排压到右上角的等宽小字：墙整体下移到 y 104。
5. 「一帧一帧地剪」小字压到字幕条：挪到「剪辑」右边。
6. 进图标墙的翻牌转场露出一大片黑（墙一开始是墨色底）：换成整列落下。
7. 交付后（10-04）才发现：「写代码 → 配音」的翻牌转场整屏黑了约 0.2 秒。原因是转场里的黑色写成三位的 `rgba('#000', …)`，引擎的 `G.rgba` 只认六位色值，颜色失效，画布沿用上一个填充色（不透明黑）把整屏刷黑。改成 `#000000` 重出。样片 `scenes.js` 的转场里也是这么写的，照抄就会带上。
