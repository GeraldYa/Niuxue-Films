# 33 钢笔淡彩（`urban-sketch`）做片笔记

> 一页竖版速写本：钢笔线先画，淡彩后铺，颜色像水一样从一个点漫开。
> - 开场先给成片（彩色的街角、电车在走）；然后**整页的颜色退回调色盒第 33 格，墨线按笔顺收回去**——这就是这一期的「清零」，最后整页只剩一格橙色；
> - AI 钢笔念一个字写一个字，写下那句话；三个问题小图；39 格调色盒圈第 33 格；
> - 整条街按笔顺长出来，念到「都交给它」，颜色从第 33 格漫满整页，被颜色碰到的人才开始走。

## 1. 构思

- 风格说：线先色后、颜色是「到达」的（每个像素有自己的到达时间）、全页只有一样东西有颜色、最后拉远看整页。四个招式全用上。
- 这一期：做视频 = 画一页速写。
  - 「那一句话」是钢笔写在页眉的一行字，跟着配音一个字一个字写；
  - 「唯一彩色」是调色盒的第 33 格：开场的成片倒流时，整页的颜色都退回这一格，后面「它挑了第三十三种」就是把这一格圈起来；
  - 「都交给它」就是颜色从这一格漫出去，把整页画满。
- 三样干货：页眉右边三个问题小图（话筒 / 音符 / 分镜）；39 格调色盒 = 39 种风格；干活的四件事各对一样东西（街景按笔顺长 = 写代码、咖啡馆门口唱歌的人 = 配音、梧桐下拉手风琴的人 = 配乐、电车侧面六扇窗 = 一帧一帧地剪）。
- AI 编程助手画成一支钢笔：笔杆上写着 AI，橙色的环跟第 33 格一个颜色。
- 样片的故事（风吹走草帽、颜色跟着帽子走）不用；只借它的引擎和招式。

## 3. 关键手法

### 3.1 「页面时间」：成片 → 倒流 → 正着画
- 静态层的每一笔、每块颜色都带「哪一刻出现」；合成器按传进去的时间显影。片子里传的不是片子时间，而是「页面时间」：
  - 开场 = 一个比所有事件都晚的时刻（成片）；
  - 倒流时往回走；
  - 之后 = 片子时间。
- 倒流要**分段映射**，不能匀速：页面时间要从 58 秒退到 8 秒，匀速 3 秒退完的话，颜色漫开那 3 秒只占 0.2 秒，一闪就没了。按要看的东西分配：后画的东西 0.35 秒擦掉、颜色退回去 1 秒、街景收回 0.8 秒、调色盒和小图 0.45 秒、手写字 0.5 秒。

```js
const K = [[rev0, END], [rev0 + .35, flood + floodDur], [rev0 + 1.35, flood], [rev0 + 2.15, street0], [rev0 + 2.6, L05], [rev2, rev2]];
```

### 3.2 会动的东西：「颜色在才动」
- 人和电车每帧画（knock 纸色 + 淡彩 + 墨线），颜色量 = 页面时间减去这个人锚点的到达时间。锚点按第一帧的位置取（样片的坑：按当前位置取，人走进没上色的地方会掉色）。
- 走路、开车用「活着的秒数」驱动：从 0 到 t，颜色在的总秒数。开场里在走，倒流时颜色退走就停住，漫色以后接着走。这个数能直接算（二分找颜色退走的时刻），每帧独立渲也对得上。
- 走到头的人要换成站姿，不然原地踏步。

### 3.3 竖版街景的透视
- 眼高 1.6 m：街上所有行人的头都在地平线上（速写的老规矩），按 Z 一缩放就站对了。
- 近处的楼顶一定在画面外：上沿做成中间高两边低的不规则边，墨线停在不同的高度，颜色碎成色点，像画到那儿就停了。
- 屋檐阴影这种窄条，要整条都在画面里才画，否则被压到上沿会变成一块奇怪的灰方块。
- 颜色要按真实轮廓擦，不能按包围盒（样片的坑）。

### 3.4 手写：汉字按笔顺写
- Make Me a Hanzi 的笔画中线 → 钢笔线（抖、出头），一笔一笔写；标点自己画几笔，拉丁字母用 Caveat 从左往右写（`hz.js`）。
- 那句话按配音的逐字时间分配：一个字的笔画按长度分时间，笔与笔之间抬一下笔。
- 钢笔跟着笔尖走：取过去 0.12 秒笔尖位置的平均，平滑又是确定的，逐帧并行渲也一样。

### 3.5 读数和标签
- 页面上的字全是手写（日期、那句话、问题标签、调色盒标题、33、用途标签、交棒、页名、署名）；字幕用手写感的黑体，墨色加纸色描边；整页视图时字幕挪到页面下面。

## 4. 声音

- **配乐**（`music/score.py`）：F 大调街头圆舞曲，3/4、138 BPM，全部现合成，乐器从前几期借：手风琴、钢琴、钟琴、颤音琴、刷子、单簧管、拨弦贝斯、竖琴。
  - 开场成片里是主题前四小节，倒流时像磁带一样慢下来、沉下去；
  - 写字那段没有乐队：笔进场一声钟琴；三个问题各一声往上问的颤音琴；39 格颜料一格一个音；圈第 33 格一个 F6/9 和弦；
  - 画街：拨弦贝斯先走，刷子跟上；「配音」单簧管、「配乐」手风琴各一句，放在词后 0.3 秒，别跟字撞；六扇窗六个钢琴音；
  - 「都」字前 0.3 秒全停，「都交给它」全奏进来。
- **拟音**（`mix.py`）：
  - 每一笔一声笔尖擦纸（照样片 foley.py）：写字时一笔一笔听得清；画街时几百笔叠成一片沙沙；
  - 倒流一阵倒带；颜色漫开一阵湿笔刷；
  - 「一帧一帧」六声放映机咔嗒；电车开着时有低鸣和轨缝声，到站叮叮两声；
  - 颜色在的时候才有鸟叫和街上的人声。
- **电平**：旁白 −18 dB；配乐不说话时 −25 dB，说话时按分轨压，中频再挖 8 dB；拟音说话时压 10 dB、中频再挖 5 dB。每句「人声 − 底子」13.0–28.1 dB。

## 5. 返工记录

1. 路面石块画成了几百像素的大褐斑：近处的半径公式乘反了。改成按米算（0.05–0.15 m × 每米像素），再封个顶。
2. 鸽子画成半米长的灰叶子：同一个比例错误。改成 0.3 m，加小圆头和尾巴。
3. 左边近楼顶上有一块灰方块：是被压到上沿的屋檐阴影。改成整条都在画面里才画。
4. 问题小图的标签压到街景上沿：小图往上挪 100 px，标签收近。
5. 咖啡馆和小店的一层窗太黑太重：改成暖色浅底 + 一点玻璃色。
6. 倒流太快，颜色退回去只占 0.2 秒：改成分段映射（§3.1）。
7. 写日期时镜头太靠右，开头几个字出画：镜头左移。
8. 漫色时一开始拉到整页，街太小：留在街景景别，下面的调色盒本来就在画里，看颜色从第 33 格往上流。
9. 混音 L07 只高 7.6 dB：
   - 画街的几百笔叠起来太响：压轻、频带推到 4 kHz 以上；
   - 真正盖住最后几个字的是刚起来的湿笔刷：第一层压轻、晚 0.12 秒起；
   - 「配音」「配乐」两句乐器挪到词后 0.3 秒。
10. 封面第一版文字带挡住了楼和电车，中间全是空路面：镜头往上挪，楼和电车放进文字和底条之间。

## 6. 下一期能直接拿走的

- **页面时间 + 分段倒流**：开场成片、倒回空白、再正着画，任何「按时间显影」的风格都能用。
- **颜色在才动**：「活着的秒数」驱动动画，倒流时停住、回来接着动。
- **汉字按笔顺手写** + 跟配音逐字对齐 + 跟着笔尖的笔（`hz.js`）。
- **竖版街景透视**：眼高 1.6 m、头在地平线上；近处楼顶出画用不规则上沿收住。
- **配音每句多种子挑一版**：见 `SHORTS.md` §3，工具 `tools/vo_pick.py`。
