# 16 油画厚涂（`impasto`）做片笔记

> 调色刀厚涂：夕阳下的向日葵田，她（钴蓝裙子、红围巾）站在小路上的背影。一把调色刀斜着刮过去，颜色一路被刮成灰，只剩她有颜色 → 她往前走 → 调色刀飞进来（刀柄上写「AI 编程助手」），在灰色的天上一个字一个字抹出那句话 → 弹出三张卡「配音？」「音乐？」「分镜？」→ 钢琴停在没解决的音上，静一拍 → 调色板铺上来，圆舞曲起：中间写 Niuxue-Films，一圈 39 团颜料，刀挑走 16 号那团金色 → 代码、话筒、音符三张整幅 → 回到田里，刀一刀一刀把金色铺回来，天从太阳那里亮回夕阳 → 舞台、画廊、窗台三张整幅 → 刀在田边抹出路牌「实机录屏 →」→ 拉开看全景，太阳压低，每一道颜料脊都亮起来 → 真静 → 最后一个和弦。

## 1. 构思

- 这个风格自带四样本事（STYLE §2）：颜色被刀重新铺上（每一笔都存着灰和彩两种颜色）、编舞在地上画出画、斜光（高潮时光压到贴地，每一道颜料脊都亮）、刮刀转场（下一个镜头的笔触扫着盖上来）。样片讲的是「灰 → 彩」，这期也讲「灰 → 金」，但换成自己的故事：她要的就是「一片灰色的向日葵田，慢慢变成金色」。
- 三样干货全用这个风格自己的东西演：
  - 用什么：AI 编程助手就是那把调色刀，刀柄上写字；免费开源库是一块木头调色板，中间写 Niuxue-Films，一圈 39 团颜料，16 号是金色；
  - 怎么说：刀在灰色的天上一个字一个字抹出那句话（念到哪个字抹到哪个字）；它先问的三件事是刀甩出来的三张颜料卡；
  - 剩下的交给它：一个词一张整幅（代码 / 话筒 / 音符，都用刮刀转场盖上来），然后回到田里，刀一刀一刀把金色铺回来——「一刀一刀地画」就是这个风格本来的样子；
  - 适合拍什么：画廊卡片的三个用途（Music videos / Art & culture / Emotional ads）各一张整幅；不适合的（演示软件）由刀抹出一块路牌交给实机录屏那一期。
- 系列规矩「开头先给最好看的样子」跟风格的「灰 → 彩」合在一起：开场是画好的金色，刀先把它刮成灰，整支片子再一刀一刀涂回来；结尾跟开场同一个机位。
- 灰的世界里只有她一个人有颜色（STYLE §10「只有一种颜色」的用法：世界 `grey: 1`，她 `grey: 0`）。

## 3. 关键手法

### 3.1 竖版和引擎的三处改动
- `new Impasto(canvas, { W: 1080, H: 1440, ss: 2 })`。样片的合成着色器里暗角写死了 16:9（`q.x *= 1.78`），改成按画幅比例。
- 揭示波（灰 → 彩）原来只能烘进每一笔（`rev`），一套笔触只有一种扩散方式。改成笔触着色器拿到自己的局部坐标，`draw` 时给 `o.revC = [x, y, 每秒多少像素]`，波从哪儿扩散每一次画都能换：

```glsl
float rt = uReveal + vP.z + (uRevC.z > 0. ? length(vPos - uRevC.xy) / uRevC.z : 0.);
float g = uGrey * mix(1. - swept, swept, uInv);   // uInv = 1：反过来，颜色被刮成灰
```
- `o.inv` 反过来用：开场那一刀把颜色刮成灰，波的中心放在刀的起点，速度 = 刀的速度，灰色正好跟在刀后面。

### 3.2 一片田、两批笔触
- 田只画一张参考插画、跑一次 `paintRef`，再按位置拆成天、地两批（`splitStrokes`，y 在地平线以上的算天）。铺金色时地从刀那里扩散（速度跟刀一样），「都交给它」时天从太阳那里扩散，两个波互不干扰。
- 坑：底色层（`E.under`，模糊的参考图，防止笔缝露出画布）要**先**画。第一版先画天的笔触再铺底色，底色把整片天盖成了平滑的渐变，只剩地平线上一条白块。

### 3.3 天上一个字一个字抹出来
- 那句话是一张参考插画（思源宋体 900，四行，底下垫一圈压暗的影子，亮的天边也看得清）。`paintRef` 的 `app(x, y, level)` 给每一笔一个出现时间：先按位置找到它属于第几个字，再换成念到那个字的时间，字里面从左到右再错开一点。画的时候 `appear` = 这句话的起点，每一笔到点才沿着自己的长度铺开。
- 刀尖跟着当前的字走（`charBox` 按同样的排法量出每个字的位置）。
- 竖版的田只比画面高 160 像素，镜头往上摇的余地很小：字要放在天的上半截，第一版第一行被画面顶边切掉。

### 3.4 刀是一块会动的板子
- 调色刀画成一张小参考插画（2 倍精度，刀柄上的字才利落），整块用仿射矩阵摆：`knifeM(x, y, 角度, 缩放)` 把刀尖放到 (x, y)。
- 刀柄朝右或右上，字才是正的。第一版刮的时候刀柄在前、字倒过来了，挑颜料时刀柄伸出了画面。

### 3.5 圆舞曲的拍子管剪辑点
- 调色板那一下（POP）是圆舞曲的第 0 小节。之后的剪辑点都吸到最近的拍子上（`snap`），每个剪辑点一声钟琴，音一级级往上；最后一个和弦落在小节第一拍，前面真静 0.45 秒（圆舞曲停在「嘭-嚓-」）。
- 前半段灰的世界是钢琴自由地弹，剪辑点挂在念到的字上，不吸拍子。

### 3.6 整幅卡片和刮刀转场
- 代码、话筒、音符、舞台、画廊、窗台都是整幅参考插画，`app` 烘成对角扫过去 0.22 秒；换镜头时先画上一个镜头，再让新镜头的笔触扫着盖上来（样片的 `EDIT` 做法），配一声刮刀。
- 同一片田的两个机位之间别用刮刀转场：新镜头的她是一下子画上的，旧镜头的她还在，会同时出现两个她。改成直接切。
- 「适合拍什么」三张的题字放在画面上面（底下会被字幕挡住）。

### 3.7 她、花瓣、光
- 她是每帧重铺的笔触（`herBack`）：背影、逆光（裙子两边、头顶一道淡金）、齐耳短发、红围巾两条尾巴在风里飘；会走（抬起的那条腿短一点，往远处走）、抬头、点头、举手。
- 结尾第一版干停 8 秒：加上从她身上往后拉开、再推向太阳的镜头，风里飘的金色花瓣（真静时停在半空，和弦落下被风卷起来），斜光从左边贴着画面扫到右前方（`norm` 到 9）。

### 3.8 封面
`?poster=1`：高潮那一格（斜光下的金色田、她的背影），天上压刀画的大字：金色「一句话」、奶白「让 AI 画一幅会动的油画」；红章「不花钱生成视频」放在下面的花田上，太阳露出来；顶上一行 DOM 小字「39 种风格 · 16 油画厚涂」。第一版红章挡住了太阳，小字压到大字。

## 4. 声音

- **配音**：11 句，气声比 −24.3 ~ −34.3 dB（L11 齿音多，跟前几期同一句，留原版）。
- **配乐**（`music/score.py`），全部代码合成：
  - 开场：手风琴 D 大调和弦 + 竖琴上行 + 钟琴；刀刮下去时这一段像磁带一样变速慢下来、沉下去（按时间减慢的重采样）。
  - 灰的世界：钢琴独奏（13 期的现合成立式琴，三根弦调准一点），D 小调 3/4，9 小节正好走到「要不要先看分镜」之后，停在导音 C# 上，真静 0.75 秒。
  - POP：钟琴 + 竖琴上行 → 原创街头圆舞曲，D 大调 3/4、132 BPM。手风琴是三片簧加法合成：一片低 12 音分、一片高 14 音分（musette 调音，拍频就是那种「颤」），1.5 kHz 一个共鸣峰，风箱一点点起伏；嘭-嚓-嚓 + 拨弦贝斯 + 沙锤；主题 F#5 A5 B5 A5 | F#5 E5 D5 …。
  - 铺金色时竖琴从低刮到高，「都交给它」一片亮（镲滚上来 + 钟琴）；最后一个和弦时钢琴把开头断在 C# 的那句解决到 D。
- **拟音**（`mix.py`）：调色刀刮画布（一顿一顿的颗粒噪声 + 一点钢的余音）、颜料「啵」、挑颜料、土路脚步、刀飞过的风声、写字时每个字一下；环境：灰的世界只有风，彩色的田里加傍晚的鸟。最后一拍的真静连环境一起清零。
- **电平**：旁白 −18 dB；配乐 −23 dB，说话时按分轨压（主题 −16、手风琴和竖琴 −12、贝斯 −10、鼓 −12、钢琴 −6）；拟音说话时再压 10 dB。第一版钢琴太轻，灰的那几句「人声 − 底子」到了 30 dB（底下太空），钢琴抬 10 dB、少压 3 dB 以后每句 14.0–22.0 dB。

## 6. 下一期能直接拿走的

- **引擎的三处改动**（§3.1）：揭示波任意点扩散、反过来刮成灰、暗角按画幅。所有「颜色被重新铺上」的风格都用得上。
- **一张参考插画拆成两批笔触**（`splitStrokes`）：同一个画面里两处颜色各自铺开。
- **按字出现的刀画字**：`paintRef` 的 `app` 按字的位置查念到的时间，任何「写字」「抹字」的场面都能用。
- **手风琴（musette）合成**、**磁带变速刹停**：欧洲街头、复古、法式题材都能用。
- **圆舞曲吸拍**：剪辑点吸到拍子上、最后一个和弦前真静。
