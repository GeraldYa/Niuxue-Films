# 37 复古半调案卷（`halftone-dossier`）做片笔记

> 奶油档案纸、四色平涂、叠印的半调网点、错版大标题、啪一下落下的橡皮章。讲法是一份案卷：**被告 = AI 编程助手，罪状 = 做视频的每一步**。
> - 开场先给成片（结案的卷宗 + 红章「结案」）；**揭章就是这一期的「清零」**：章被撕起飞走、卷宗弹开、纸页倒飞出去；
> - 那句话 = 立案的「一行字」和起诉书，先问一轮 = 档案照里的三个问句气泡，开源库 = 证物墙 39 张卡（圈出 37）；
> - 写代码 / 配音 / 配乐 / 剪辑 = 罪状 01–04，「都交给它」后空半小节，红章「全部属实」单独落下；宣判：无罪释放，理由：你也做得出来。

## 1. 构思

- 风格说：任何题目都能变成「对 X 的指控」：一个讨人喜欢的被告 + 三条具体、能画出来的罪状 + 一个跟证据唱反调的判决（「全部属实 → 无罪释放：太可爱了」）。
- 这一期：被告是 AI 编程助手（新画的圆滚滚小机器人），罪状就是系列每期都讲的四步：写代码、配音、配乐、剪辑；「全部属实」之后反转「无罪释放」，理由正好是系列的那句「你也做得出来」。
- 样片的猫和三条罪状（测试重力、深夜跑酷、代写周报）不用；借它的整套语法：卷宗 HUD、档案照身高尺、巨型网点数字、印章、证物卡、网点转场、放射光 + 彩纸。

## 3. 关键手法

### 3.1 单文件样片拆成模块、改竖版
- 样片是一个 1087 行的 `index.html`。拆成 `lib37.js`（工具、网点、字、印章、吉祥物）、`story37.js`（时间线）、`film37.js`（场景）、`main37.js`（纸纹、颗粒、逐帧渲染），交给仓库的 `core/render` 渲（`window.render(t)` + `window.READY`）。
- 竖版：舞台 1080×1440；纸张折痕改成横的（在高度中间）；`edge()` 的中心改到画布中心；字幕条放在 y = 1292（底下留出平台按钮）。
- 版面：大标题左上（x ≈ 80）、主角正中、证物从下往上弹入、印章别盖住标题字（立案章第一版盖住了「字」）。

### 3.2 小节网格排旁白
- 每场从小节线开始，旁白在小节线后 0.2 s 起；一场至少 2–3 小节，旁白长了就往后顺延到下一个小节线。这样换场、转场、鼓点都卡在拍子上，旁白照样完整。
- 重拍和印章都避开字头：立案章在 L03 念完后 0.1 s；「全部属实」在 L07 念完后、小节后半单独落下（前半小节音乐全停）。

### 3.3 跟着配音的逐字弹入
- 样片的 `charsPop` 是匀速错开；加了 `charsAt(c, t, ts)`：每个字用自己的出现时刻（配音逐字时间），起诉书上的字就是一个字一个字跟着念出来的；笔尖跟着最新的那个字。
- 关键词：字幕条按标点断块，关键词表（配音、音乐、第三十七种……）标黄。

### 3.4 新吉祥物：AI 编程助手
- 照样片的配方：7 px 深蓝描边、平涂、奶白肚子、粉腮、10 fps 的线条抖动；头换成圆角方的蓝色机壳 + 奶白屏幕脸，眼睛用样片同一套（可以眨、眯、开心变弯），天线顶上一颗黄球，肚子屏上「>_」。
- 蓝色机器人别放在蓝色网点光圈前：档案照的光圈改成黄色 + 粉色叠印。

## 4. 声音

- 配乐和音效全部现合成：借样片 `music.py` 编曲之前那段（乐器 + 音效函数，`exec` 进来），PLAN 按 31 个小节重写；说话多的小节用 light 模式（鼓、贝斯、铺底，不唱旋律）；清零那小节加了一个「倒带」：一串往下掉的拨弦 + 下滑扫频；证物墙走 sneak（拨弦 + 响指）；罪状 build → drop。
- 音效从 events.json 读（跟画面同源）；小机器人的声音用两声短促的方波「嘀」，问句一句比一句高。
- 坑：成片混音复检时 whisper 把 L08「萌宠」听成「蒙重」、L09「一盘」听成「一排」。单句干声是对的；拿三个种子过一遍「处理 + AAC」再听，换成最稳的种子，人声压缩也调轻（阈值 .5、比 2）。最后每句 15.9–21.2 dB，11 句全对。

## 5. 返工记录

1. 卷宗上的小机器人挡住卷宗标签：挪到卷宗右上角坐着。
2. 立案章盖住「一行字」的「字」：挪到纸条上方。
3. 起诉书荧光笔范围差一个字：按字的下标重标。
4. 证物墙 7 排卡到了字幕条：卡片缩小，选中的 37 号飞到正中放大。
5. 综上第三张卡、移交的标签压到字幕条：往上挪。
6. 结案气泡挡住小机器人：气泡缩窄、尾巴改朝右。
7. 每帧都在变的纸纹颗粒让文件很大（CRF 22 有 75 MB）：CRF 28，30 MB。
8. 封面第一版大字挡住机器人的头：档案照整体下移、标题区垫满纸色。

## 6. 下一期能直接拿走的

- **单文件样片拆模块**：工具库 + 时间线 + 场景 + 渲染四个文件，交给 `core/render`。
- **小节网格排旁白**：换场卡在小节线上、旁白顺延、印章放在念完以后。
- **成片混音过 whisper，听错就换种子**：先把三个种子都过一遍「混音处理 + AAC」，挑最稳的。
