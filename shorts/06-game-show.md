## 1. 构思

- 这个风格的看家本事（STYLE §2）：分关卡、一问一答、判定词（Perfect!）、数字当游戏界面（价签被锤）、成绩单。原片是没有旁白的节奏游戏，这期加了我当主持人。
- 定位（09-29 定）：吸引观看，让小白觉得「不花钱生成视频，你也可以做出这种视频」。
  - 开场第一句「这种综艺动画，你也做得出来！」；
  - 第一关就把「不花钱」演出来：价签锤成 ¥0；
  - 成绩单最后一行「视频生成花费 ¥0」。

| 关 | 画面 | 干货 |
|---|---|---|
| 标题 | 黄底放射线，「一句话 闯三关」逐字弹出；五个角色一拍落一个，最后一小节数「1 2 3 4」 | 钩子 |

## 3. 关键手法

### 3.1 竖版：只抽 demo 引擎的前 428 行
- demo 的 `main.js` 是 `assemble.py` 拼出来的：前 428 行是库（调色板 `K`、节拍 `at/ev/punch`、`bean()`、`human()`、`card()`、`burst()`、`judge()`、`banner()`……），后面是原片的全部镜头。
- 这期把前 428 行抽成 `lib.js`，逐条改竖版：
  - 条纹的旋转中心 540/720；圆点铺满范围（y < 1540、x < 1160）；
  - 关卡卡片面板 1240×460 → 940×540，片名居中，图标挪到片名上方；
  - 镜头打拍的缩放中心 540/720。
- `head.html` 是 demo 的 `frame_head.html` 改成 1080×1440（svg viewBox、裁切、闪白、淡出、`bg()`）。`build.py` 拼成 `index.html`：`head.html` 里的内联脚本收尾，再用两个普通 `<script src>` 引 `lib.js`、`film.js`。
- 普通脚本（非 module）顶层的 `const` 在同一页面里互相看得见，所以拆成三个文件不用改一行引用。

### 3.2 旁白排时间，画面踩拍子
- 节奏风格的命根子是「所有打点都在拍上」，旁白的长短又由配音定。做法：
  - 每句起点 = 上一句结尾 + 间隙，再往上取整到拍（`beatUp`）；
  - 关卡卡、价签落下这些「段落点」取整到小节（`barUp`）；
  - 念到的词（「AI」「开源库」「配音」「科技大事记」……）取到半拍（`q2`），画面在那一刻落地、叮、砸。跟字差不到 0.1 s，听起来是踩着字，也踩着拍。

```js
VO.L03 = at(S.g1 + 1) + .1;
S.ai = q2(at_('L03', 'AI') - .05); S.lib = q2(at_('L03', '开源库') - .05);
S.tag = barUp(END('L03') + .05);                // 价签从天而降
VO.L04 = at(S.tag, 1);
S.slam1 = beatUp(END('L04') + .05);             // 锤子砸下：¥0 + Perfect!
```

### 3.3 价签锤成 ¥0
- 价签是一组 SVG：黑色错位影 + 米色标签 + 孔 + 两段价格（`¥?? / 秒` 和 `¥0`），砸之前显示前一段，砸的那一帧换成后一段，同时 `hitSq` 让标签压扁回弹。
- 锤子绕握把末端转：砸前 1.5 拍抬起，前 1 拍扬到最高，拍上砸下（`E.in`），之后弹回。
- 同一拍上叠：`hammer` + `slam` 音效、镜头打拍 0.05、星爆、「Perfect!」判定词、全员举手。

### 3.4 气泡按念的字逐字打出
- 气泡里两行字用 `chars()` 拆成单字，每个字的出现时刻 = `L06` 起点 + 这个字在逐字单元里的开始时间；标点跟前一个字同时出现。
- 每个字弹一下（0.6 → 1 的回弹缩放），每个字一声键盘声。这期字多，键盘声调轻到 0.2，不然这段会比别处响 3 dB。

### 3.5 抢答卡一张张往上推
- 三张卡按出现顺序排成一列：新卡落在最下面，旧卡往上推一格（每格 132 px），每张后面一拍冒绿勾，「你」跟着点头。
- 卡片放在「你」和 AI 豆子中间（x 560），不然会挡住 AI 豆子，或者压到气泡。

### 3.6 封面模式
- `?poster=1` 时 `init()` 只建封面（`buildPoster()`），`render` 换成空函数，直接 `READY`。
- 构图：「一句话」250 px、「让 AI 做一台闯关综艺」、红标「不花钱生成视频」、价签 ¥0 + 锤子、三个角色、底部系列小字。「Perfect!」放上去会压住红标，拿掉了。

## 4. 声音

- **配音**：10 句，白板工具的期「2026-09-29 风格片06 综艺配音」。第一轮 L04、L05、L07、L09 语速偏慢被标异常，工具自动换种子重配过。
- **气声复查**（这期起的规矩，SHORTS.md §3）：L02 −18.9 dB、L04 −19.1 dB（其他句 −25 到 −34 dB），是耳语；L09 −22.3 dB 也偏高。`SEED_OFFSET=3/5/7` 各配一版：L02、L04 用 3 号（−32.3 / −31.0 dB），L09 用 7 号（−26.7 dB）。L10 三版都在 −25 dB，是擦音多，保留原版。
- **配乐**（`music.py` + `synth_lib.py`，照搬 demo）：150 BPM，王道进行 F–G–Em–Am，合成鼓、拍弦贝斯、铜管、方波主旋律、马林巴、八音盒。编曲按小节：标题 main → 数拍 count → 第一关 funk → 第二关 quiz → 第三关 pop → 每关砸完那一小节 popBig → 成绩单 calm → 片尾 fanfare → end。关卡卡上一段铜管 jingle（这期卡上没旁白，调响了）。
- **音效**：照 demo 的映射，从 `events.json` 来：落地 land、音高泡 pip、数拍 tick、叮 ding、蜂鸣 buzz、锤 hammer、砸 slam、打字 type、欢呼 cheer、星 bigslam。
- **混音**：demo 的人声总线本来装的是英文喊声，这期拆成三路：旁白 −18 dB（说话段 RMS）；音乐整体 −27 dB，说话时压 5 dB；音效跟音乐同增益，说话时压 3 dB。每句「人声 − 底子」12.3–16.0 dB。短时响度 −13 到 −19 LUFS，LRA 10.5 LU。

## 7. 下一期能直接拿走的

- **竖版综艺套件**：`head.html` + `lib.js` + `build.py`，换片子只写 `film.js`。
- **`plan()` 的排法**：旁白起点取整到拍、段落取整到小节、关键词取到半拍。任何「节奏为王」的风格（微游戏快闪、像素 RPG 的战斗）都能照搬。
- **小件**：`nameTag()`（黑底白字名牌）、`sticker()`（带错位影的贴纸）、`popIn()`、价签 + 锤子、逐字打出的气泡、往上推的抢答卡、成绩单。
- **`music.py`**：编曲按 `cues` 里的小节自动排，旁白单独一路。换片子只改 `PLAN` 那几行。
