## 1. 构思

骨架借 `styles/ink-wash/STYLE.md` §2 的情绪线，砍掉「轻快」「阻碍」两拍：空纸 → 一滴墨 → 大片空白里一个小人 → 静 → 一笔 → 拉远 → 盖印。干货塞进这条线里，不另起一套。§2 的六个母题用了五个（一笔成山、留白即物、飞白、墨晕转场、收成一卷），没用「笔即动作」。

| 要讲的 | 画面 |
|---|---|
| 钩子 | 空宣纸，一滴墨落下晕开成山；右侧竖写「不说一句话」，盖印 |
| 用什么：AI 编程助手 | 一支毛笔，旁题「AI 编程助手」，下挂小字 Claude Opus 5.5 |
| 用什么：免费开源库 | 一方砚，砚池落墨吞掉笔尖；题「开源库 lemo-opuscar」「免费 · 39 种风格」 |
| 怎么说 | 需求原句写成右起三列竖排书法：用水墨风格 / 做一支竖屏片 / 讲一首唐诗，盖印 |
| 讲究①：留白 | 需求说「讲一首唐诗」，就真画一首：柳宗元《江雪》。顶上一线远山、一叶孤舟、蓑笠翁垂钓、右上题两句诗，其余全是空白 |
| 讲究②：先静后动 | 数字静音 2 s，一笔飞白从左下斜贯到右上出画，溅墨 |
| 适合拍什么 | 顺着飞白的斜势写大字「武侠」「诗词」「国风」；「数字」淡墨小字，被朱砂一笔划掉 |
| 讲究③：收尾拉远 | 整张纸拉远成挂轴，右下盖印，出片尾卡 |

- 24.0 s 以后一直画在同一张纸上：孤舟、题诗、飞白、三个词、划掉的「数字」、印，一样样加上去。最后拉远，这一整幅就是本期的总结卡。
- 画里的朱红只有三方印和划掉「数字」那一笔（字幕句首的小朱方块是原片字幕的做法）。
- 口吻是题画短句，每句说眼前这幅画，不解释画：
  - 先演后说：静音和飞白先发生，33.3 s 才说「高潮之前先静，然后一笔」。
  - 库名只题在画上，旁白说「名字题在画上了」，不念。
- 开头没有口号，靠画面抓人：0.7 s 墨滴落纸，之后 3 s 开出一整片山。首句「不说一句话，也能画出一幅水墨」，跟 L3「对它说一句话」一反一正。
- 结尾先落一句水墨本身的话「水墨最值钱的，是那片没画的白」，再接系列结尾（SHORTS.md §8）。
- 「开工前它会先问一轮」只写进了发布正文，片里没演。

## 3. 关键手法

### 3.1 书法字：引擎笔触扫字格，字形裁边
- 想要：中文书法带笔毫、飞白、湿边，又不用给每个字手描笔顺中线（原片 `glyph.js` 只描了一个「水」）。
- 做法：`films/01-ink-wash/text.js` 的 `writeChar()`。
  - 每个字一张 1.2S 见方的小画布（S = 字号），wet、dry 两层。
  - 用引擎的 `mk()` / `draw()` 自上而下扫四道宽笔，按进度依次落笔。
  - 马善政字形 `fillText`，再加一圈细 `strokeText` 外扩（给飞白毛边留余地），`destination-in` 裁出字。
  - 写完按「字、字号、墨色、干湿、seed、字体」缓存，之后每帧直接贴。
  - `writeLine()` 把进度均分给每个字，`vertical: true` 竖排。
- 代价：字是从上往下扫出来的，不按笔顺。

```js
// films/01-ink-wash/text.js · writeChar()
    for (let k = 0; k < R; k++) {                        // 自上而下四道斜扫，按进度依次落笔
      const q = clamp(p * R - k); if (q <= 0) break;
      const yy = n * (.1 + (k + .5) * .8 / R), tilt = (rnd() - .5) * S * .08;
      const s = mk([[n * .02, yy - tilt, .85], [n * .5, yy + (rnd() - .5) * S * .05, 1.05], [n * .98, yy + tilt, .9]],
        { w: S * .8 / R * 1.55, tone: o.tone ?? TONE.jiao, dry: o.dry ?? .2, wet: .3, prof: 'even', rough: .07, nb: 36, solid: true, seed: (o.seed || 1) * 10 + k });
      draw(L.ink, s, q, 1);
    }
    const m = glyphCanvas(ch, S, o.font || 'MaShanZheng');
    for (const c of [L.ink.wet, L.ink.dry]) { c.globalCompositeOperation = 'destination-in'; c.drawImage(m, 0, 0); c.globalCompositeOperation = 'source-over'; }
    cv = L; if (p >= 1) done.set(key, L);
```

### 3.3 一滴墨开出整片山：用合成器的 `rev`
- 三层山（远、中、近，加皴和一棵松）在 `init()` 里一次画进缓存层 `M1`。`mountainLayer()` 是逐像素生成的，只做这一次。
- `s1()` 每帧把 `M1` 整张贴上，交给 `comp.js` 的 `rev`（A 画面的墨晕显现：中心、半径、开关），从落点 (390, 700) 往外开，0.8–3.8 s 半径 40 → 2340。
  - 原片没用过 `rev`，它的 `world.js` 自己算低分辨率蒙版（`blitReveal()`）。一张不动的画用 `rev` 最省事。
- 墨滴：0.35–0.7 s 从画外落下（竖向拉长的 `blot`），落纸后 1.9 s 内变大变淡直到没有。画在 `M1` 之后，压在山前。

```js
// films/01-ink-wash/shots.js · s1()
  if (t >= T.bloomA) blit(A, M1);
  if (t >= T.drop) { const u = clamp((t - T.drop) / 1.9), a = .85 * Math.pow(1 - u, 1.6); if (a > .01) blot(A.cw, DROP[0], DROP[1], 14 + 46 * eo(u), a, 0, 1, 7); }   // 墨滴压在山前，慢慢化开
  const R = t < T.bloomA ? 0 : 40 + 2300 * eio(clamp((t - T.bloomA) / (T.bloomB - T.bloomA)));
  // …
  return { bleed: 6, rim: .8, paper: [0, 0, 1], rev: [DROP[0], DROP[1], R, t >= T.bloomA && R < 2300 ? 1 : 0] };
```

### 3.4 墨晕转场 `tr()`
- 换幅不硬切。旧画面画进 A 套层，新画面画进 B 套层，`comp.js` 的 `trans` 让新画面从一团扩散的墨里长出来，前沿一圈深色水线。半径公式照原片 `shots.js`。
- 三次转场分别 0.7 / 0.7 / 0.8 s。第三次的中心放在下一幅小舟的位置，舟从墨里长出来。

```js
const tr = (oa, ob, c, u) => ({ ...oa, paperB: ob.paper, bleedB: ob.bleed, rimB: ob.rim, trans: [c[0], c[1], 20 + 2300 * ss(u), 1] });
// …
  if (t < T.x34[1]) return tr(s3a(A, t), s3b(B, t), BOAT, (t - T.x34[0]) / (T.x34[1] - T.x34[0]));
```

### 3.5 一张纸画到底，拉远成挂轴
- `s3b()` 用 `A.xf(z, tx, ty)` 把整张纸缩小：45.3–47.6 s，z 1 → 0.56，中心 y 720 → 600（往上提，下面留给片尾卡）。
- 卷外清墨：wet、dry 两层在卷外做 `destination-out`。不清的话，出画的飞白、溅墨和湿墨晕染会渗到墙上。
- 颜色层画墙 `#2f2b27`、绫边 `#cdc3aa`（宽 60·z）、天杆地杆 `#5a4634`，外加一圈细边。
- `paper: [-tx, -ty, z]` 让纸纹跟着卷一起缩；`bleed: 6·z` 晕染半径一起缩；`vig` 从 .22 加到 .37。

```js
// films/01-ink-wash/shots.js · s3b()
  const u = eio(clamp((t - T.pull[0]) / (T.pull[1] - T.pull[0])));
  const z = lerp(1, .56, u), cy = lerp(720, 600, u), tx = 540 - 540 * z, ty = cy - 720 * z;
  A.xf(z, tx, ty); const L = A.ink;
  // …
  const rx = tx, ry = ty, rw = W * z, rh = H * z;
  if (u > 0) for (const c of [A.cw, A.cd]) {       // 卷外不留墨
    c.save(); c.setTransform(1, 0, 0, 1, 0, 0); c.globalCompositeOperation = 'destination-out';
    c.beginPath(); c.rect(0, 0, W, H); c.rect(rx, ry, rw, rh); c.fill('evenodd'); c.restore();
  }
  // …
  return { bleed: 6 * z, rim: .8, paper: [-tx, -ty, z], vig: .22 + .15 * ma, fade: clamp((t - T.fade[0]) / (T.fade[1] - T.fade[0])), shake: [Math.sin(t * 190) * 6 * sk, Math.cos(t * 150) * 4 * sk] };
```

### 3.6 静 → 一笔
- 飞白笔 `CUTS` 在 `init()` 里 `mk()` 一次，笔毫和断墨是固定的，不会逐帧抖。
  - 参数照原片 `glyph.js` 的 `cutStroke()`：焦墨、`dry .62`、`nb 64`、`solid`、seed 777。
  - 路径改成 (−80, 1210) → (1160, 600)，两头都出画，宽 34。
- 30.1–32.1 s 画面一动不动，声音全零。32.1 s 起 `draw(L, CUTS, eo(cp))`，0.6 s 扫完，先快后慢。
- 32.65 s 在出笔那头落 26 个墨点（0.25 s 长大），同时合成器 `shake` 震 0.4 s（6 / 4 px，按 e^(−t/0.1) 衰减）。
- 之后的三个词顺着飞白的斜势排在它上方，「数字」在它下方。

### 3.7 几笔成人、成器
- 蓑笠翁 `fisher()`：船身两道 `tip` 笔；蓑衣一块 `mass` 加 5 道干笔草纹；斗笠一块扁 `mass` 画进 dry 层（边硬）；钓竿 `nail`，钓线 1.1 px；按船 → 人 → 竿三段出。远景小人用不着 `hero.js` 那套骨骼。
- 笔砚在 `s2()`：
  - 笔 = 笔杆 + 笔斗 + 一笔 `cone` 笔头（`solid`，焦墨）；砚 = 椭圆沿 + 下移 34 px 的厚度 + 淡墨砚堂 + 内沿 + 砚池浓墨。
  - 砚池最后画、从小长大，正好盖住伸进去的笔尖。椭圆点列用 `EL()`，可带逐点笔压，砚沿的粗细起伏就是这么来的。

## 4. 声音

**配音**（导入做法以 SHORTS.md §3 为准，01 早于 `tools/vo_import.py`）
- 白板工具的期「2026-09-27 风格片01 水墨配音」，一句一场。9 句：L1 3.52 / L2 7.20 / L3 1.60 / L4 4.80 / L5 4.64 / L6 4.48 / L7 6.40 / L8 3.20 / L9 3.36 s。
- L9 头一遍 5.0 s、2.2 字/秒，工具标「异常」后自动换种子重配，第二遍正常。
- 只拷了 WAV 进 `voices/`。逐字时间是当时从 build 里的 `L*.json`（`wordList`）读出来，手填进 `story.js` 的。
- wb 出的 WAV 是 44.1 kHz 双声道。01 的 `mix.py` 先 `if y.ndim > 1: y = y.mean(1)` 并成单声道，再用 soxr 转 48 kHz，原片 `mix.py` 没有这一步。之后照原片：峰值归一到 .8，`compress(thr=.22, ratio=3.2)`，全体人声 RMS 定到 .16（−15.9 dB）。

**配乐**（`music/score.py`：只用 `core/audio/pluck.py` 的古琴，加一记合成低频，不下采样包）
- F 宫五声（F G A C D），按段落写，不循环：
  - 虚白：0.70 墨滴 = 低音 F2 散音（vel .92、gain 1.25）；1.9 / 2.8 / 3.7 泛音 C5 / F5 / A5 托题名；4.2 印落 F2；5.4 D3 下滑两个半音进下一幅。
  - 笔砚：旁白底下只留 7 个稀疏的音。9.45 F3 带吟猱对「AI」，11.3 A2 对砚池落墨，12.9 泛音 F5 对库名。
  - 一句话：三列字各一音，A3 / C4 / D4（17.1 / 18.75 / 20.75）；22.0 盖印落主音 F3，加泛音 F5。
  - 江雪：24.2 起低音轮指，F2 C3 F3 C3 G2 D3 G3 D3 循环，72 BPM 八分音；1.2 s 渐入，28.3 起渐隐，一路收进静默。
  - 一笔（高点）：32.1 七弦扫弦 C2 D2 F2 G2 A2 C3 D3（`P.strum`，相邻弦隔 11 ms，gain 1.35），加 F2，32.12 再加一记 90 → 40 Hz 下扫的正弦低频（2.4 s）。
  - 适合：33.4–37.4 主题回来；三个词各一音 F3 / A3 / C4；42.84 G2 对「数字」，43.64 D3 下滑对「划掉」。
  - 收卷：47.9 印落泛音 F3 加 F2；55.3 落主音 F3；最后 1.2 s 淡出。
- 混响 `S.room`（纯算法，不要采样）：古琴 size .5、mix .22；低频 size .3、mix .08。
- 静默前后分开混响再相加：前半段的混响尾巴在 30.1 s 前 0.25 s 内淡完，之后清零；最后再把 30.1–32.1 整段置零。`score.json` 里 `hush_max_abs: 0.0`。

```python
# films/01-ink-wash/music/score.py
pre = verb(st)
for k in pre:                                                             # 静默前连混响尾巴一起收干净
    ia, nf = int(HUSH[0] * SR), int(.25 * SR)
    pre[k][ia - nf:ia] *= np.linspace(1, 0, nf, dtype=np.float32)[:, None]; pre[k][ia:] = 0
st = new()
# …
st = verb(st)
st = {k: st[k] + pre[k] for k in st}
```

**拟音**（`shots.js` 的 `events()` → `events.json`，共 42 条；函数照原片 `mix.py`，新加 `boom`）
- drip：0.7 墨滴落纸，11.3 砚池落墨。
- brush 共 21 声，时长跟那一笔走：题名每字一声，笔杆 / 笔头 / 砚沿，三列字，小舟，题诗（gain .2，很轻），飞白（gain 1.4），三个词，「数字」和划掉。
- seal：4.2 / 22.0 / 47.9 三方印（木印闷响 + 纸声）。
- 一笔：32.1 brush；32.14 `boom`（300–2500 Hz 带通噪声，1.4 s，「扫过纸面的气流」）；32.65 splatter（70 个小湿点）。
- 环境：风 0–7.0；江水 23.2–30.1 和 32.7–46.3；风 45.3–57.4。30.1–32.1 是 `silence` 窗口。

**电平**（`mix.py`）
- 人声闪避照原片：配乐最多压 8.4 dB，环境跟着压，最多 10.5 dB。
- 配乐总增益 ×1.8（原片 ×1.35，约 +2.5 dB）。只有 32.0–33.3 s 那记扫弦保持 ×1.35，33.3–35.5 s 渐回 ×1.8。
- `mix = vo + mus + fx·.9 + amb·.7`；静默窗口前 20 ms 淡出，窗口内全零；窗口后不淡入（原片有 20 ms 淡入），扫弦直接满幅进来；每声道 `limit(.95)`。
- 实测（`mix.py` 打印，mux 归一之前）：
  - 人声 −15.9 dB，人声下的配乐 −35.3 dB，句间配乐 −22.2 dB；
  - 分段：虚白 −16.9 / 笔砚 −15.9 / 一句话 −16.4 / 江雪 −17.0 / 一笔 −12.3 / 适合 −16.2 / 收卷 −18.8 dB，静默段全零；
  - `mix.wav` 峰值 −0.45 dBFS。
- `LUFS=-16` mux（SHORTS.md §1）后，成片 −15.8 LUFS、LRA 5.5 LU。成片 30.2–32.0 s 用 `astats` 量过，峰值和 RMS 都是 −inf。

## 5. 竖版改造

原引擎写死 1920×1080 的地方：
- `comp.js` 的 `layerSet(W = 1920, H = 1080)` 默认值。`makeComp()` 读 canvas 尺寸，不用改。
- `glyph.js` 的 `glyphMask()` 按整屏 1920×1080 做蒙版。
- 镜头和片尾都写在各镜头文件里：`world.js` 的 `camXf` 以 960/540 为中心；`climax.js`、`cross.js`、`frames.js` 里是 1920/1080/960 常数；`passage.js` 的片尾卡按 1920×1080 清屏，标题 `fillText(…, 960, 870)`。

01 的办法：只用跟尺寸无关的零件，写死尺寸的镜头文件一个不碰。
- 用了：`ink.js`（`mk` `draw` `blot` `mass` `TONE`）、`land.js`（`ridgeFn` `mountainLayer` `cun` `pine` `ripple`，都吃 W/H 或坐标）、`seal.js`、`comp.js`；`hero.js` 只拿了朱砂色 `VERM`。
- 镜头、书法、挂轴、字幕全在片子目录里重写。
- 尺寸：`index.html` 的 canvas 写 1080×1440；三套层 `layerSet(W, H)` 显式传尺寸；自己的缓存层和 `mountainLayer({ W, H, … })` 都用 `story.js` 的 `W, H`；渲染器读 `size.json`（SHORTS.md §1）。
- 书法不用整屏蒙版：`text.js` 每个字一张小画布，跟画幅无关。
- 版面：
  - 山压在下半（三层山脊基线 y = 880 / 1010 / 1190），上面留给竖排题名；
  - 题名、需求、题诗全是中文竖排，不用原片把英文转 90° 的办法；
  - 手卷改挂轴：原片是横卷、两端有轴；01 是竖挂轴，天杆地杆在上下。
- 镜头不横移。原片一路右 → 左展卷；01 每幅就是一张竖纸，换幅靠墨晕转场，全片只有结尾一次拉远。镜头公式 `tx = 540 − 540·z`、`ty = cy − 720·z`。
