# 38 玻璃质感产品（`glass-product`）做片笔记

> 暗场影棚、条形柔光箱、一道光扫过玻璃、黑色亮面地板上的焦散和声波环、慢动作爆炸视图、屏息半拍后合拢接 808。讲法是一支新品发布片：**产品 = 一颗虚构的「玻璃回车键」**。
> - 开场先给成品（亮着的键），**光一点点熄掉就是这一期的「清零」**；暗场两道光扫、片名「一句话」；
> - 那句话 = 键面下的「↵」导光（一道光沿它走进去）和磨砂玻璃输入条（逐字打出来，念完按下回车）；先问一轮 = 三颗图标小键；开源库 = 39 颗小键，第 38 颗升起来；
> - 写代码 / 配音 / 配乐 / 剪辑 = 爆炸视图里的电路板、话筒、振膜、胶片盘，念到哪个亮哪个；「都交给它」后屏息半小节，合拢接 808 drop。

| 项 | 数 |
|---|---|
| 成片 | 60.0 s，1080×1440，24 fps，−16 LUFS（CRF 20，颗粒 0，18.7 MB） |
| 渲染 | 1440 帧，three.js（透射玻璃 + 每帧重烘环境贴图 + 镜面地板 + 景深），`--workers 4` 约 1 分钟 |
| 配音 | 11 句，每句三个种子挑一版 |
| 状态 | 做完没发 |

下文只写文件名的都在 `films/38-glass-product/` 下。

## 1. 构思

- 风格说：产品是主角，光是第二主角；暗场、慢、精确，零件「一览无余」，配乐先行、剪辑和光都卡拍。题目换成任何东西都要先找到一个「产品」。
- 这一期的产品：**一颗玻璃回车键**。系列每期的起点都是「发给 AI 编程助手的一句话」，句子敲完按回车，正好是开工那一下；键里面装着后面的四步（电路板、话筒、振膜、胶片盘），爆炸视图一拆就是「写代码、配音、配乐、剪辑」。
- 样片的耳机和充电盒不用；借它的整套语法：暗场光扫开场、磁吸浮起、微距拉焦、慢动作爆炸视图 → 屏息 → 合拢 drop、光纹跟 808、俯拍焦散 + 声波环、最后一道光扫收束。

## 3. 关键手法

### 3.1 玻璃回车键（`product38.js`）
- 键帽 = 收腰的圆角方块：`RoundedBoxGeometry` 生成后按高度把 x、z 缩到顶面 0.76。**法线要按变形的逆转置一起改**（n' = (nx/k, −x·c/k·nx + ny − z·c/k·nz, nz/k)，再归一化），不然侧面按竖直的折射，玻璃看着发假。
- 一看就是回车键靠两样：**收腰的键帽轮廓 + 键面下的「↵」**。第一版是直上直下的厚玻璃块 + 46 mm 大底座，正面低机位看像一颗玻璃药片；改成收腰、底座缩到 32 mm（比键帽小，键帽悬出来）、机位都抬到 3/4 俯角，键面上的「↵」露出来，才读得出是什么。
- 「↵」导光 = 样片的 `guideMat`（暗色亚克力 + 沿 uv.x 跑的彗星脉冲）：管子（`TubeGeometry`，uv.x 从入口到箭头）+ 单独一块材质的箭头（锥体的 uv 不顺着走，光走到头时整块亮）。键帽底边一圈超椭圆导光环，uv.x = 0.25 是键的正前方，鼓点时两道光从这里分头绕环。
- 电路板「写代码」时走线亮起来：同一套随机走线画两张贴图，底色版（石墨 + 金线）当 `map`，发光版（黑底 + 白线）当 `emissiveMap`，改 `emissive` 颜色就行。
- 爆炸视图 `explode(k, e, spin, press)`：零件沿本地 Y 展开；`press` 是按下的毫米数，键帽和里面的零件一起下去，弹簧 `scale.y` 跟着压缩、底座不动。

### 3.2 竖版影棚
- 样片 `studio.js` 原样拷，改三处：背景径向渐变按竖版画（16:9 的贴图拉到 3:4 会变成竖着的椭圆）、地面反射贴图 1080×1440、地面 shader 里屏幕坐标用的分辨率 `uRes` = 画布像素（2160×2880）。
- **平面玻璃 + 满宽光扫灯条 = 整面打白**：样片的耳机是弧面，灯条反射出来是一道高光；回车键的顶面和侧面是平的，反射面大，片名那道光扫第一版把整面键帽打成白板。灯条加了宽度倍数 `w`，片名那道用 0.3 倍宽、强度 5，成了一道走过去的高光。
- 竖版机位：键放在画面下半，上面留给字（片名、输入条、库名、用途）；暗场片名的机位看向键上方 15 mm，键落在 2/3 处。

### 3.3 跟着字走的光
- 键的光五种状态写成一个函数 `lightKey(t, st)`：熄灭 / 呼吸 / 常亮巡游 / 跟 808 / 回车灌满，外加两种叠加：「↵」彗星（念到「一行字」「一句话」各一道，走到箭头时箭头亮、给一点点光）和打字闪（L04 每个字让导光环和「↵」入口轻轻亮一下）。
- 爆炸视图里零件亮起的时间都挂在字上：写代码 / 配音 / 配乐各一个字头，「一帧一帧地剪」六个字对六格胶片；「都交给它」所有零件一起亮、一道光走进「↵」；屏息前 0.3 s 全灭。
- 回车落在 L04 念完后的下一拍（21.5 s），合拢落在「都交给它」之后的下一个小节线（40.0 s），前面半小节配乐全切。

### 3.4 2D 叠层
- 磨砂玻璃（样片字幕条的做法）拿来做所有底板：把 3D 画布模糊后裁进圆角块，1 px 高光边 + 顶边一冰蓝一淡紫的色散线。输入条、字幕条、「No.38」标签都用它。
- 零件标注：零件位置投影到屏幕，左右交替，文字高度跟着零件走但彼此至少隔 150 px；屏息前收掉，让那半拍干干净净。
- 字用思源黑体的细字重（200 / 300，可变字体）加宽字距，英文小字用样片的 Inter Tight。

## 4. 声音

- 配乐和音效全部现合成：借样片 `score.py` 编曲之前那段（808、软 kick、拍手、闭镲、FM 玻璃拨弦、玻璃铃、去谐锯齿铺底、光扫 shimmer），拟音照样片 `mix.py`（光扫、磁吸 click、玻璃叮、气流）；编曲按这一期 30 个小节重排，时间全从 events.json 读。
- 清零 = 琶音的滤波一路关上 + 一声往下滑的「断电」；回车 = 磁吸 click + 808 + 玻璃叮；风格库「三十九种」= 一串上行的细碎玻璃音；屏息半小节配乐 5 ms 硬切到全静，只留反向吸气，成片里那半拍 −32 dB，drop 第一拍 −13 dB。
- drop 四小节压着 L08、L09 两句：混音逐句量「人声 − 底子」，这两句最低（15.1、14.7 dB），还在 13 dB 线以上。whisper 在成片里 11 句全听对。

## 5. 返工记录

1. 键帽像玻璃药片、读不出回车键：键帽收腰、底座缩小、低机位全抬成 3/4 俯角。
2. 三个选项第一版是竖着漂的三颗小深色胶囊：改成三颗正对镜头的大键帽，键面里放发光图标（话筒 / 音符 / 分镜格），念到哪颗按下去、图标亮。
3. 爆炸视图机位太低（俯 6°）：圆盘零件全成了侧面一条线，抬到俯 24°，电路板的走线和胶片盘的六格才看得见。
4. 正面英雄镜头太近，键帽两边出画：拉远。
5. 片名光扫把整面键帽打白：灯条变窄（见 3.2）。
6. 俯拍焦散那场键在画面上方，压到「美妆广告」：看点往远处挪 22 mm，键落到画面中间。
7. 移交那场的「上一期」小字压在 37 期封面的大字上：展示板往下放、机位拉远。
8. 封面：先试了收束那一帧（键偏小偏暗），再试近景（键出画、「↵」读不出来），最后用正前上方的机位，键面上的「↵」最清楚。

## 6. 下一期能直接拿走的

- **产品片先找「产品」**：把讲的东西做成一件虚构产品，爆炸视图里的零件就是要讲的几件事。
- **改几何就改法线**：缩放、收腰这类变形，法线按逆转置一起改，玻璃的折射才对。
- **平面玻璃配窄灯条**：光扫灯条按反射面的大小调宽度，平面用窄的。
