## 1. 构思

**这期的要求**（09-29 定）：「内容记得还是要有区别度，主要的作用是吸引观看，小白也会觉得『不花钱生成视频，你也可以做出这种视频』的感觉。」所以这期先定了两头：
- **开头给结果**：第一句就是承诺「不会剪纸，也不用花钱买视频生成，一句话，就能剪出这样一支片子」。念到「一句话」，剪刀剪下的那张纸揭走，下面就是成片最亮的样子（背光窗花 + 烟花）。
- **结尾落到「你」**：整个村子缩进一部手机，「这样一支片子，你也做得出来」。
- 口径：「不花钱」只说视频生成（没用付费的视频模型，代码在本机渲），AI 编程助手的订阅另算，不说「全程免费」。

**剪纸的看家本事**（STYLE §2 五样用了四样）对上干货：

| 要讲的 | 画面 | 用到的本事 |

| 钩子 | 剪刀没人拿，自己在红纸上一刀刀剪；纸揭走露出背光窗花 | 刀口、镂空透光 |
| 用什么：AI 编程助手 | 一把大剪刀「啪」地亮相，挂一条「AI 编程助手」横批 | — |
| 用什么：免费开源库 | 一张红纸滑进来，剪刀飞过去把库名一个字母一个字母剪成镂空（09-29 起是 Niuxue-Films，也是 12 个字符，节拍不用动） | 镂空 = 字 |
| 怎么说 | 需求原句写成一副对联（右上联「用红色窗花剪纸风格」、左下联「给我剪一支拜年的小片子」），横批「一句话」 | 贴春联 |

- 口吻：像民间顺口溜，短句带节奏（「折三折，剪一刀」「打开，一刀就是八个」），跟 01 的题画、02 的讲课、03 的说书、04 的产品旁白都不一样。
- 片尾对联是这期自己编的，上联「折三折剪一刀」对下联「说一句拍一支」，把工艺和用法对上。
- 没用 demo 的小女孩和年兽：故事换成「一句话怎么变成一支片子」，只借剪刀。

## 3. 关键手法

### 3.1 时间线全从配音推，`story.js` 用顶层 await
- `fold.js` 在模块加载时就用 `T.folds` 等建镜头轨（`camK`），所以 `T` 必须在被 import 前算好。`story.js` 顶层 `await fetch('voices/words.json')`，ES 模块会等它算完再往下跑。
- 每句起点从上一句结尾或上一个动作链出来；折纸要对上字，就反过来定旁白起点：

```js
const f1 = at('L06', '折') - .05;
VO.L07 = f1 + .62 - U0('L07', '折', 0);   // 第一个「折」落在第二折上
T.folds = [f1, f1 + .62, f1 + 1.24];
T.cut0 = Math.max(T.folds[2] + .62, at('L07', '剪') - .1);
```
- `U0(id, sub)` = 这个字在句内的偏移（先把 `VO[id]` 设成 0 再调 `at()`）。

### 3.2 字幕：逐字单元里没有标点，拿原句对回去
- `vo_import.py` 出的 `words.json` 只有字，没有标点，按标点断句得有原句。`story.js` 存了一份 `LINES`，逐字对：非空格、非标点的字依次对应单元里的字（「AI」是两个单元）。
- 断句后贪心并到 ≤15 字，**冒号、句号、分号后面不并**（不然会出「开工前，它会先问你一轮：配音、」这种半截）；句末的「，。：、」去掉。

### 3.3 竖版：改了哪几个文件
- `fold.js`：离屏画布、镜头中心 `VW / 2, VH / 2`、桌面底和暖晕、展开时的光晕中心。
- `hud.js`：字幕纸条字体改思源宋体（`SUBFONT`），位置 `540 − w/2`、离底 96 px。
- `light.js`、`world.js`：`W, H` 改 1080×1440（光照图、自发光、辉光的画布都跟着变）。
- 村子本来是横的一条（地面 y 905，雪只有 320 高）。竖版拉远时上面是大片夜空，正好放烟花和横批；下面在 `front` 回调里补一块雪地，免得露出天空纸：

```js
gg.save(); gg.setTransform(...C); gg.fillStyle = '#6f7db0'; gg.fillRect(-2000, GROUND + 300, 7000, 2200); gg.restore();
```

### 3.4 剪出库名：先铺米纸，再贴带洞的纸
- 做两张同样的红纸：一张没洞（`TOOL.full`），一张把「lemo-opuscar」挖空（`destination-out` 写字）。
- 每个字母的格子事先用 `measureText` 量好（italic 要多留边、给 p 的下伸留高）。已剪的字母：裁到这些格子里，先铺一层桌面米纸，再贴带洞的那张，洞里就透出米纸。
- 剪刀按当前字母的格子位置移动，刃每 0.085 s 开合一次，字母心作为纸屑掉下去。

### 3.5 团花贴窗 + 八盏灯笼
- 贴窗：村子镜头一开始就推到 z 3.0、对准那扇圆窗（窗半径 120 → 屏上 360 px，接近折纸镜头结尾团花的 456 px）。团花从画面中心缩进窗里，0.6 s 后贴上，窗子亮起（`heroI` 0 → 1.3 → 1）。
- 八户一开始全黑：`HOUSES` 的 `out` 设成 −1，`relit` 设成八个灯笼时刻，近的先亮（顺序 `[6, 7, 5, 4, 3, 2, 1, 0]`）。灯笼的飞行路径照 demo 的 `flightPos()`。

### 3.6 尺度揭示：手机要真的像手机
- 第一版把 3:4 的画面直接装进圆角框，看着像平板。改成屏幕宽 = 画面宽、屏幕高 = 宽 × 2.1（接近 9:19.5），片子居中，上下是黑边，加刘海和底部横条。
- `k` 从 1 缩到 0.45。k = 1 时画面正好铺满竖屏、手机壳在画外，接得上前一个镜头，没有跳。

```js
const vw = W * k, vh = H * k, sw = vw, sh = vw * 2.1, x0 = 540 - sw / 2, y0 = cy - sh / 2;
ctx.save(); phonePath(ctx, x0, y0, sw, sh, 90 * k); ctx.clip(); ctx.fillStyle = '#080a18'; ctx.fillRect(x0, y0, sw, sh);
ctx.drawImage(SCc, 540 - vw / 2, cy - vh / 2, vw, vh); ctx.restore();   // SCc = 同一时刻的村子镜头
```

### 3.7 「一刀就是八个」的闪光
- 八盏灯笼在团花半径 0.535·TR、角度 22.5° + k·45° 上（楔形里灯笼在 `Q * .5`，镜像 8 次）。
- 在「八个」这个字上，每隔 0.09 s 闪一个：暖色光晕 + 米白四角星。用 `source-over` 画，不用 `lighter`：红纸上加色看不出来。

## 4. 声音

- **配音**：12 句，白板工具的期「2026-09-28 风格片05 剪纸配音」。L07「折三折，剪一刀」重配 3 轮都被标异常（2.3 字/秒），看逐字时间是「折三折」和「剪一刀」中间停了 0.5 s，照用。
- **配乐**（`music/score.py`，全合成）：琵琶（pipa）、筝（koto 预设，同是弹拨的筝类）、木鱼、小锣、大锣、铙钹、手鼓，D 宫五声，4 小节主题（16 个八分音符）。
  - 冷开场：每一剪一个筝音往上走，琵琶轮指托底。
  - 揭纸：筝刮奏 + 小锣，主题起；片名大锣。
  - 剪名字：12 个字母 12 个筝音。三问：三个琵琶音。对联落下各一声小锣。
  - 剪：筝的八分音符越爬越高，手鼓跟拍；**剪完屏住的 0.5 s 全部清零**；三下展开三段刮奏；强拍大锣 + 铙钹 + 琵琶和弦。
  - 八盏灯笼八个筝音一路往上；最后一盏一记铙钹（不用大锣，紧接着就是旁白）。
  - 结尾：乐器一件件退，片尾署名前一声大锣，筝和弦收在 D 上。
- **拟音**（`mix.py`）：函数照搬 demo（剪刀、纸、翻页、折、展开、贴、灯笼、爆竹、烟花、风）；新加 `paperpop`（冒出）、`slide`（抽纸）、`paste`（贴春联）、`sparkle`（八个闪）。
- **电平**：人声说话段 RMS −18 dB；配乐整体 −27 dB，说话时再压 8 dB（这期强拍多，6 dB 不够）；最后 mux 到 −16 LUFS。每句「人声 − 底子」：9.8–38.9 dB，最低的是 L08。

## 5. 封面

- `?poster=1` 走 `poster()`：米纸上大字「一句话」（思源宋体 900，250 px）、「让 AI 剪出窗花动画」、红条「不花钱生成视频」；中间一扇背光圆窗花，右下剪刀、左下纸屑；底部「39 种风格 · 05 红色窗花剪纸」。

## 6. 返工记录

1. **第一轮静帧（38 张）**：
   - 冷开场剪刀跑出画：竖版左右窄，镜头跟刀尖的比例从 0.38 提到 0.72 / 0.62。
   - 片名的印章压在「纸」上、团花压住小字：重新排位。
   - 「八个」的闪光看不见：放大到 70 px，改 `source-over` + 暖晕（§3.7）。
   - 手机像平板：改成真手机比例（§3.6）。
2. **混音第一版**：「打开，一刀就是八个」撞上强拍的大锣和全奏，只比底子高 2.3 dB。
   - 改法：L08 挪到大锣之后（`VO.L08 = T.bloom + .3`）；强拍后不再接主题，只留轻轻的筝；大锣减到 0.5；配乐闪避从 6 dB 加到 8 dB。L10 底下的主题也撤了，只留分解和弦。
   - 教训：高潮的强拍后面紧跟旁白时，要么让旁白等锣声落下，要么强拍后撤乐器。
3. **整片抽帧（每 1.5 s 一帧）**：
   - 讲工具那段剪刀刀尖出画：缩到 8 倍、下移。
   - 对联那段开场空了一秒多：横批改成一进场就落。
4. **字幕半截**：「……先问你一轮：配音、」→ 冒号后不并（§3.2）。
5. **对联那句像耳语**（我 09-29 看完指出）：
   - 量法：每句算 4 kHz 以上和 80 Hz–4 kHz 的能量比。L04 是 −22.8 dB，其他句子在 −27 到 −30 dB，就是它气声重。浊音概率、自相关这些量不出区别，这个最灵。
   - 重配：白板工具每次重配都从同一个种子起步，重配出来还是同一版。给工具加了 `SEED_OFFSET` 环境变量（默认 0，照旧），`SEED_OFFSET=3/5/7 FORCE_TTS=1 wb tts <期> L04` 各配一版，挑能量比最低、语速跟前后句最接近的（第 3 版，−30.2 dB）。
   - 这句短了 1.4 s，时间线全是推出来的，后面自动顺延，重跑 events → score → mix → video 就行。成片盘上的旧版照规矩改名留着。
   - 教训：配完先把每句的能量比过一遍，哪句高出其他句 3 dB 以上，先听一耳朵。
6. **09-29 重出**：剪出来的库名和片尾署名换成本仓库 Niuxue-Films，片尾写「风格来自 lemo-opuscar」。两个名字都是 12 个字符，一字一剪的节拍、音效都不用动，只重渲画面。
