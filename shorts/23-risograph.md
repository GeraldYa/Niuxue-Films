# 23 丝网印刷（`risograph`）做片笔记

> 一版一版印出来的片子：暖白纸上三块半透明的专色版（蓝、黄、荧光粉），网点、墨粒、套不准。**版就是剧情**：
> - 开场先给成片（三版叠满：大太阳、地平线、坡顶上小小的她举着刚印好的那张），念完，出纸口滑下一张白纸盖住它；
> - 蓝版上机：黎明的单蓝版片名 → 书桌：她和一台印刷机（AI 编程助手），纸条上逐字写那句话，塞进机器；
> - 黄版上机：机器的眼灯、她的围巾、台灯一起亮，三个问题气泡念到哪个冒哪个；
> - 开源库：一面墙 39 桶墨，挑中的第 23 桶只有粉——是一片纸白，粉版一刷，它亮成荧光粉；
> - 机器一张张吐出写代码、配音、配乐、剪；最后一张的太阳长成粉色圆吞满画面，真静一小节，套准，全乐队；
> - 适合拍什么：三张印品落下；黑纸交棒；拉远，这一张落在前几期的纸堆上；片尾卡两版各印一次。

## 1. 构思

- 风格的六样本事（STYLE §2）用了五样：
  - 一次一版 = 剧情：成片 → 白纸 → 蓝版（一句话）→ 黄版（先问一轮）→ 粉版（挑中的那一桶墨）→ 三版叠满（成片）；
  - 叠印混色当转场：粉色圆从最后一张纸的太阳里长出来吞满画面，再缩回成成片的大太阳；
  - 套不准当节奏：每次上版、每出一张纸，版跳一下；真静那一小节三块版漂开，「咔」地套准；
  - 网点和墨粒：天空分四档网点（20 / 38 / 62%），墨粒每印一张沸腾 35%；
  - 它就是一张纸：开场一张白纸盖上来，结尾拉远，这一张落在纸堆上。
- 三样干货各落在一个画面里：
  - 用什么：印刷机的铭牌「AI 编程助手」；开源库「NIUXUE-FILMS · 免费」「39 种风格」、39 桶墨；
  - 怎么说：纸条「INPUT · 一句话」，那句话逐字写；三个问题气泡；
  - 适合拍什么：三张印品（独立品牌的帆布袋、小众刊物的 ZINE、生活方式的咖啡和绿植），交棒是一张三版叠满的黑纸（17 暗色科技发布）。

## 3. 关键手法

### 3.1 竖版
- `draw.js` 的 `W, H` 改成 1080×1440；`riso.js` 按画布尺寸走，不用改。网点周期照样片 7 px（竖版宽 1080，网点在手机上看得见，正好）。
- 字幕是纸白挖空条 + 蓝版字（STYLE §7），放在离底 112–188 px；一条一张，不淡入淡出（印刷品是切的）。

### 3.2 颜色先按「版」设计
每个颜色都是三版浓度 `[蓝, 黄, 粉]`，先想好单蓝版时它长什么样：

```js
skin: [0, .26, 0],        // 黄网点：单蓝版时是纸白
hair: [1, 0, .22], sweater: [.4, 0, 1], trousers: [.75, 1, 0], shoe: [1, 0, .4],   // 都带蓝：单蓝版时是完整剪影
scarf: [0, 1, 1],         // 只有黄 + 粉：黄版上机前是纸白，黄版一来第一个亮
drumColor(22) = [0, 0, 1] // 挑中的那桶墨只有粉：粉版上机前是一个纸白的空桶
machine: [1, 0, .45],     // 蓝实地 + 粉网点：粉版一来整台机器变成紫
```
- 「每一块最多两版、最多一版网点」照 STYLE §3，39 桶墨的颜色从 13 种两版组合里轮。
- 机器的眼灯是黄实地：黄版上机 = 机器醒了。

### 3.3 版就是时间线
```js
gate:  [fin0 || t >= T.blue, fin0 || t >= T.yellow, fin0 || t >= T.pink]   // 成片阶段三版都开
sweep: 每一版上机时滚筒从左往右刷 0.55 s（riso.js 的 uSweep，推进边缘有一道偏浓的墨带）
```
- 上版落在 120 BPM 的拍上（`snapB`）：配乐的新乐器从这一拍进来。
- 白纸盖上来：在分版画布上画一整张纸色（`[0, 0, 0]` = 不上墨）的矩形，从上往下滑，下边一道细蓝线当纸边。

### 3.4 套色：固定错位 + 拍点上跳 + 真静里漂开
- 每个镜头一套固定错位（±1–3 px），只在拍点上跳（8–14 px，0.25 s 带点回弹）：上版、每个问题、挑、每出一张纸、套准。
- 真静那一小节：三块版慢慢漂开到 25 px，套准那一拍「咔」地弹回来。别每帧抖，会闪、码率翻倍（STYLE §8）。

### 3.5 纸条逐字、手握笔
- 纸条特写俯拍，龙藏体念到哪个字写出哪个字（按字宽裁剪揭开），笔尖跟着正在写的那个字。
- 手：握笔的拳头 + 压在笔上的拇指，描一圈蓝边（单蓝版里皮肤是纸白，不描边就没了）。

### 3.6 叠印转场：粉色圆吞满画面
- 最后一张纸放大到 3.2 倍，粉色圆从它的太阳的位置（纸心往上 100 × 缩放）用 `over()` 叠印长到 1900 px：底下所有颜色都变成混色。
- 圆吞满那一拍切到成片构图，圆再缩回成大太阳（r 300）。这一拍配乐硬停，真静一小节。

### 3.7 纸堆：前几期的封面分色重印
```js
// 蓝墨吃红光、粉墨吃绿光、黄墨吃蓝光；三版都多的地方减掉一点（别糊成泥）
let b = 1 - R / 255, p = 1 - G / 255, y = 1 - B / 255; const k = Math.min(b, p, y) * .35; b -= k; p -= k; y -= k;
plateRGB = [b * 1.1, y * 1.1, p * 1.1]   // 分版画布：R 蓝、G 黄、B 粉
```
拉远那一镜：新印的这张一开始就铺满画面、一直在最上面，拉远时从出纸口下面落到纸堆上。

### 3.8 渲染和码率
- 用样片的 `tools/video_png.mjs`：PNG 截图（JPEG 4:2:0 会吃掉粉、蓝网点的颜色）→ yuv444 无损中间片（410 MB），最后只压一次。
- 网点很吃码率：CRF 22 是 49.7 MiB、24 是 38.2 MiB、26 是 29.0 MiB。放大到 100% 比，24 和 26 看不出差别，用 CRF 26。

### 3.9 封面
- `?poster=1`：成片构图；片名「一句话」印成纸白挖空、下面垫一层错开的粉版；「让 AI 印出一张丝网印刷画」纸白；底下一个黄 + 粉实地（红橙）的胶囊「不花钱生成视频」。

## 4. 声音

- **配乐**（`music/score.py`）全部现合成，波萨诺瓦，120 BPM，D 大调，**跟版一起叠**（STYLE §6）：
  - 蓝版：尼龙吉他独奏（拇指弹一、三拍低音，和弦切分）；
  - 黄版：+ 沙锤（十六分）、木鱼边击（两小节的波萨 clave）、鼓刷（二、四拍）；
  - 粉版：+ 低音提琴（粉版那一拍先走三个音的引子，下一个强拍正式进）+ 口哨（正弦 + 揉音 + 气声）；
  - 粉色圆长出来：颤音琴（加法合成 1 : 3.98 : 10.2 + 马达颤音）往上一串 → 硬停，真静一小节 → 套准那一拍全乐队 + 颤音琴，配乐从这一拍重新起小节；
  - 拉远时一件件撤：颤音琴 → 口哨和打击乐 → 低音，片尾只剩吉他落 Dmaj9。
- 各段都铺在同一个小节格子上（`band(t0, t1, parts, origin)` 只铺完整开始的小节），上版的时刻对到拍上，不然换段时律动会错半小节。
- **拟音**（`mix.py`）：印刷机的走纸「嚓」+ 滚筒「咔嗒」是招牌声（每上一版、每出一张纸），纸落下、纸沙沙、笔写字、气泡「啵」、编号的印章轻点、墨桶滑出来和落下、黑纸滑进滑出、马达。
- **电平**：旁白 −18 dB；配乐安静处 −24 dB，说话时按分轨压（吉他 −17、打击乐 −16、低音 −14、口哨 −21、颤音琴 −18：口哨正在人声频段）；拟音说话时再压 6 dB。第一版每句就都过了 12 dB（13.9–25.4）。

## 5. 返工记录

1. 写字的手画成一个圆接一截粗管，像根管子：改成握笔的拳头（蓝边 + 三道指缝）+ 压在笔上的拇指。
2. 台灯灯罩画成三角，像个箭头：改成半圆灯罩 + 灯泡（黄版上机时亮）。
3. 进纸托盘只剩一根线：画成斜伸出去的一块板 + 一叠纸。
4. 挑中的第 23 桶，粉版刚刷完就切走了：粉版上机后多停 0.6 s 再切。
5. 拉远那一镜开头铺满画面的是上一期的封面（纸堆最上面那张）：新印的这张一开始就在最上面。
6. 真静那一小节对到小节强拍上，高潮前白等了 2 秒：改成对到拍上，配乐在套准那一拍重新起小节。
7. 粉色圆从纸心长出来，不在太阳上：按那张纸的缩放算太阳的位置（§3.6）。
8. 「最适合拍」开头 1 秒是一片空蓝底：成片多停一会儿，念到「独立品牌」才切，印品在念到的那一刻落下。

## 6. 下一期能直接拿走的

- **按版设计颜色**（§3.2）和**版就是时间线**（§3.3）：任何「一步一步加上去」的题都能用。
- **叠印转场**（§3.6）：一个颜色的大形吞满画面、再缩回成下一场的主形。
- **封面分色重印**（§3.7）：把任何彩色图变成三版印刷品。
- **PNG → 无损中间片 → 只压一次**（§3.8）：网点、细颗粒的风格都该这么渲。
- **合成波萨诺瓦一家**（尼龙吉他、低音提琴、口哨、颤音琴、沙锤、clave、鼓刷，`music/score.py`）。
