# 36 后室（`backrooms`）做片笔记

> 一盘 90 年代摄像机录像带：空无一人的黄色办公层、日光灯嗡嗡响、墙上的守则。讲法：**做视频的每一步 = 夜班守则的每一条**。
> - 开场先放带子中段（走廊尽头对上焦，一个过高的人影在挥手）；**倒带就是这一期的「清零」**：画面倒着飞回去，蓝屏 STOP，从头 PLAY；
> - 那句话 = 工单，先问一轮 = 自己打勾的入职问卷，开源库 = 一排门（36 号自己开）；
> - 写代码 / 配音 / 配乐 = 灯闪三下（照守则低头看鞋），一帧一帧地剪 = 磁带撕裂（时间码跳三小时），都交给它 = 推变焦，尽头那个「它」只在对上焦的半秒里在。

## 1. 构思

- 风格说：把题目变成一份「入职须知 / 操作规程」，写 5–6 条守则，让录像带这个媒介去出卖守则；五个原生招式（自动对焦找焦、磁带撕裂、屏显就是剧情、守则写在画面里、空和重复）至少用三个。
- 这一期正好：我们的系列每期都在讲「一句话 → AI 做完」的步骤，步骤本来就是一份守则：
  1. 只发一句话；2. 它会先问你一轮；3. 三十九扇门，只开第三十六扇；4. 灯闪三下，不要抬头；5. 剩下的，都交给它；6. 适用于……；7. 先收藏。下一期，换一种风格。
- 「都交给它」的「它」= 走廊尽头那个东西，中文一语双关。
- 片子里的东西全是原创：不出现后室的社区设定、层级编号、实体名字；风格名只出现在那句话（工单）和片尾。

## 3. 关键手法

### 3.1 横版 4:3 录像带改竖版
- 样片是 4:3 画面加左右黑边。竖版直接让磁带画面铺满 3:4：three.js 渲 540×720，`vhs.js` 里画面宽度改成画布宽、桶形畸变和暗角按 3:4 算（`src.x / src.y`）。
- 竖着拿的摄像机：同样 52° 水平视角，竖向视角有 66°，地面和天花板都进画。低头看鞋要少低一点（−1.0 rad，样片 −1.25），不然整双鞋从正上方入画，像两颗黑豆。
- 读告示的距离要比横版近：竖版磁带画面只有 540 宽，告示纸里的字按 70–90 px（纸 1020 px 宽）写才看得清，摄像机推到 0.55–0.6 m。

### 3.2 「带子时间」：开头放中段、倒带、再从头播放
- 所有机位、灯、对焦、门都按「带子时间」写关键帧。片子时间 → 带子时间一个函数 `tapeT(t)`：开头是中段慢放，倒带那几秒带子时间按 smoothstep 往回飞，播放以后带子时间 = 片子时间。渲染时先换算，再拿带子时间去算所有东西，倒带的画面就自然是全程倒放。
- 倒带的样子：噪声带一直在（跟踪值 0.55–0.9 每帧随机）、画面上下轻微滚动、计数器往回走、「◀◀ REW」一闪一闪；声音是马达升到高速 + 一串串倒着跑的「吱吱」。
- 停：录像机的蓝屏「■ STOP」0.3 s，再黑底「▶ PLAY」，带子滚入接样片原来的开机效果。

### 3.3 中文守则、问卷、门牌、出口
- 告示纸照样片的复印纸做法（偏黄、边缘更黄、灰点、折痕），字换成思源黑体。
- 入职问卷做四张贴图（0–3 个红勾），按念到的词换贴图，勾像是自己出现的。
- 门牌 33–39 挂在门上方（竖版机位靠近时门牌在画面上沿）；36 号是真门洞，门后放一间亮着灯的空办公室。
- 出口标志：红字「出口」+「EXIT」，发光 ×9（红色的亮度低，到不了辉光阈值）。

### 3.4 中文点阵字幕机
- 样片的 5×7 点阵只有英文。中文：思源黑体按 4 倍超采样画到 14×14 格，每格求覆盖率，过 0.34 记一个点；描一圈黑边跟样片一样。
- 字幕机一个字一个字打（每秒 5 个），配一个很小的按键声。

## 4. 声音

- 没有配乐；照样片的声音设计改：日光灯嗡鸣床、带子底噪、隔墙的电梯音乐（越放越慢、撕裂后走调、屏息时消失）、撕裂后升起的低频底噪、脚步、呼吸、衣服摩擦、灯闪、头顶经过、门、撕裂、1 秒数字静音。
- 新加：录像机的按键、倒带、停、再播放；红笔打勾；字幕机按键。
- 旁白当作拿摄像机的人：机身话筒的近讲低频 + 跟着人声包络的气流声 + 90 Hz–9 kHz + 压缩。
- 坑：倒带声（马达 + 吱吱）一开始盖过 L02（「人声 − 底子」−7.8 dB）。倒带单独一轨、马达高通 400 Hz、说话时压 16 dB，再加逐句自动压（13 dB）和 0.4 s 小窗局部压，最后每句 13.3–18.3 dB。
- 撕裂时只切碎底子，人声不切；1 秒静音放在两句之间。

## 5. 返工记录

1. 开头第一版的慢放窗口落在低头看鞋那几秒：窗口挪到抬头以后（推变焦到底 → 对上焦 → 滑焦 → 再对上焦）。
2. 工单字太小：机位推近到 0.57 m、正文加到 80 px。
3. 门牌放在门边，机位靠近时出画：挪到门上方。
4. 低头看鞋整双鞋像两颗黑豆：少低一点，只露鞋尖。
5. 推变焦只到 27° 时尽头人影太小：推到 21°。
6. VCR 屏显和 REC 叠在一起：VCR 屏显往下挪。
7. VHS 噪点让文件很大（CRF 24 有 60 MB）：VHS 本身很糊，CRF 28 肉眼看不出差别，26.6 MB。

## 6. 下一期能直接拿走的

- **带子时间**：任何「先放结尾 → 倒回去 → 从头放」的开场，都可以把关键帧写在一条时间上，用一个换算函数决定片子这一刻放带子的哪里。
- **中文点阵字**：14×14 超采样点阵，字幕机、像素屏显都能用。
- **守则 = 步骤**：题目改写成一份须知，每一步一条，最后一条转向观众。
