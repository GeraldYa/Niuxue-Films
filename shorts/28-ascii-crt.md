# 28 ASCII / CRT 终端（`ascii-crt`）做片笔记

> 一台琥珀磷光的老显示器，画面上的一切都是字符格子上的真字；汉字是 24×24 点阵，像老中文 DOS。
> - 开场先给成片：老屏幕上亮着的「海上日出」；关机收成一个点，继电器、消磁、再开机——CRT 自己的「清零」；
> - 片名是一个文件名「一句话.LOG」，缩成终端第一行；自检里写着「花费 ¥0」「摄像机 不需要」；
> - 推近提示符，那句话一个字一个字打进去（打字 = 念字）；回车，它先问一轮（Y / Y / N）；`ls` 出 39 种风格，第 28 种反白；四条进度条；
> - 清屏按 ↑ 调回那句话，静一秒多，这句话的字掉下来拼成海和日出，太阳从海平线后面升起，变色那一拍海和天换成蓝白；
> - 推进太阳里的一个「步」：它的每个点都是一行做片日志；27 期的封面一行一行「下载」成字符画交棒；关机收成一个点。

## 1. 构思

- 风格说：挑一个「只能用字说话」的故事，找出那条要发出去的消息，让消息自己变成画。这个系列的那条消息就是发给 AI 编程助手的那一句话——所以这期的高潮是：你打的那句话，每个字掉下来，拼成一幅画。
- 画什么：琥珀色的屏幕上最好看的是太阳。海上日出 = 「天亮了」= 一支片子做出来了；海和天在变色那一拍换成蓝白，太阳还是琥珀，全片唯一的第二种颜色。
- 风格的五个本事用上四个：画就是字（日出只用那句话的字）、字号 = 镜头（片名缩成第一行、推近提示符、推进「步」）、打字节奏 = 剪辑节奏（人打字跟着念、机器输出一行一行刷）、CRT 物理（开场关机成点当重置，片尾再关一次）。
- 尺度揭示用谐音：推进太阳里的「步」字，它的每个点都是做片日志里的一步（一句话、先问一轮、挑第二十八种、写代码、配音十二句、配乐、剪辑、第几帧）——「每一步」。
- 三样干货：用什么（`ls Niuxue-Films/styles` + 旁白「对 AI 编程助手」）；怎么说（那句话打在屏幕正中 + 三个 Y/n 问题）；适合做什么（一个字符画的窗口）。
- 交棒：27 期的水彩封面用 `open` 打开，像拨号上网那样一行一行「下载」成字符画——最湿的风格被最干的风格转述一遍。

## 3. 关键手法

### 3.1 点阵汉字
- VT323 只有拉丁字母。汉字另做一套：思源黑体 500 在 96 px 上画，每 4×4 取覆盖率，过 0.36 记一个点 → 24×24 点阵；每个点在图集里画成 8 px 的方块（略微出血），相邻的连成笔画，跟 VT323 一样是「像素字」而不是一颗颗圆点（`term28.js`）。
- 全角字和标点占两格（2cw × 2cw 的正方形），四周留 8% 的缝，不然行与行的汉字粘成一片。
- 同一套点阵既是终端文字、字幕，也是字符画的「颜料」，还是分形推进时的取样位图。

### 3.2 字符画只用那句话的字
- 密度表 = 那句话里的字按点阵墨量排序 × 暗 / 常 / 亮三级，去掉亮度几乎重复的级别；推进要找的「步」用 `keep` 保住不被去重。
- 字符画用正方形格子（16 px，全角铺满、半角居中占一半），底片按格子严格对齐（每格 3×3 个取样点）。
- 天和海的底子要够暗才能留白：第一版天空每格都有一个暗字，整幅画糊成一片；改成天只在海平线附近有一层光，上面只留星。

### 3.3 太阳升起来
- 跟样片的地球一样：太阳（连同一圈光晕）的字先全部落进海平线后面，再按从下往上的顺序升到自己的位置——太阳真的是「升」起来的。光晕要跟太阳一起升，不然光晕先落好，中间留一个黑洞。
- 变色放在小节线上：海和天的亮度从 R 通道（琥珀）换到 G 通道（蓝白），太阳留在 R。

### 3.4 分形推进
- 推进的格子从 16 px 推到 300 px（整个「步」看得清，停 0.6 s），再推到 660 px；这时「步」的 24×24 个点每个是一个小字，亮的点连起来就是「步」的笔画，读下去是做片日志。邻居的字（每、成、格、把、视……）保持大号点阵字——一眼就看出「这幅画里每个字都是那句话」。

### 3.5 CRT 当重置
- 开场成片 → 关机收成一个点 → 继电器、消磁、开机，这一段就是系列的「清零」；片尾再关一次，首尾呼应。
- 开关机都在 `crt.js` 的 `power` / `off` 参数里；关机后曝光按 0.18 s 衰减，开机前曝光为 0。

### 3.6 旧图下载
- 27 期的封面转字符画：浅色的纸按亮度会变成一整块亮，改成「颜色饱和度 + 深色的墨」取亮度——花、太阳、朱红那一笔、标题字亮，纸是黑的（`art28.js` 的 `paintImage`）。
- 一行一行出来（最新那一行半亮），配一点点电话线调制解调器的声音。

## 4. 声音

- **配乐**（`music/score.py`）：Carpenter 式模拟合成器，D 小调 100 BPM，音色内核照搬样片（PolyBLEP 锯齿 / 方波 + ladder 低通 + 磁带 wow + 长混响 / 门限混响），编曲按这一期的时间线重写（所有时间点读 `events.json`）：
  - 开场 B♭maj7 很轻；关机那一下数字归零；片名起低 D 持续音，缩成第一行时进方波音序和贝斯；打那句话时只留持续音和很轻的 Dm；
  - 回车以后一路往上推；调回那句话时连混响尾巴一起清零；字掉下来时锯齿琶音从闷到亮；变色开成 B♭maj7，接 F/A → Gm9 → E♭maj7 → A7sus4 → A7；
  - 「你也打得出来」正好落在全片唯一的大三和弦 D 上（变色那一拍往后正好六小节）。
- **拟音**（`mix.py`，全部合成）：继电器、消磁、显像管收点、弹簧机械键盘、电传滴答、自检数据啾、进度条、方波「嘟」、1 kHz 铃、字母落位的细响、推拉气流、调制解调器；底下风扇 + 120 Hz + 极轻的行输出啸叫。
- **电平**：旁白 −18 dB（没加机器声处理：讲的人不是机器）；配乐安静处 −24 dB，说话时按分轨压（音序 −12、琶音 −12、长音 −10、持续音 −6、贝斯 −6、鼓 −6），推进「步」那句再多让 3 dB；拟音说话时再压 6 dB。每句 12.1–20.5 dB。

## 5. 返工记录

1. 字形图集在模块顶层建密度表，那时图集还没建好（`ATLAS` 是空的）：密度表挪到 `initTerm` 之后。
2. 改补充字符那一行时替换错了地方，把 ASCII 字母那一行循环换掉了：改动前先看准行。
3. 天空每格都有一个暗字、海的底子也满：字符画糊成一片，按「留白」重调底片。
4. 光晕先落好、太阳还在海平线后面，中间一个黑洞：光晕跟太阳一起升。
5. 汉字上下行粘在一起：全角字四周留 8% 的缝。
6. 问答、进度条在 40 列的字太小，下半屏空着：换成大一号（32 列）的网格。
7. 帧计数和「完成」叠在一起：计数去掉空格。
8. 27 期封面按亮度转成了一整块亮：改成饱和度 + 深墨。
9. 「下载」图片的调制解调器声把「想要湿润的手绘感」压到 2.9 dB：压到只剩一点意思；机械键盘整体降一点（那句话是边打边念的）。
10. 署名打完只剩 0.2 s 就关机：署名提前到跟「先收藏」一起打，打字声也放轻。

## 6. 下一期能直接拿走的

- **点阵汉字引擎**（`term28.js`）：任何「屏幕 / 终端 / 老电脑 / 电子显示牌」类的风格都能直接用，中文字幕也能用它排。
- **一句话变成画**（`main28.js` 的 `buildFall` / `partPos`）：密度表只用那句话的字、从源字里随机一点出发、先落进地平线后面再升起。
- **日志栏字幕**：字幕跟着配音一个字一个字打出来，长句按列宽和标点自动折两行（`wrapSub` / `strip`）。
- **CRT 开关机当转场**：成片 → 关机成点 → 开机，是一个很干净的「重置」。
