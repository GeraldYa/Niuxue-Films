# 22 蓝图（`blueprint`）做片笔记

> 一张竖版晒图纸，画一台「一句话成片机」：漏斗进一句话 → AI 编程助手机箱 → 三个问题拨杆 → 四个模块（写代码、配音、配乐、剪）→ 胶片 → 出片屏，左上是 39 格的开源库抽屉柜。
> - 开场先给成片：整张图画完、屏幕在放片子、盖着「已完成」；念完，所有线按制图顺序倒着收回去，回到一张白纸。
> - 手影画机箱、写铭牌、画漏斗和纸条，纸条上那句话念到哪个字写出哪个字；纸条滑进漏斗，整台机器按制图顺序自己画出来。
> - 三个问题写一个拨一个；39 个抽屉挨个编号，抽出第 22 个；FIG. 1 改成 FIG. 2 · 运转中，机器转起来。
> - 真静之后，播放符号吸两口气，长成真的片子（全片唯一离开制图语言的东西）；注释栏写上适合拍什么；拉远盖章，推到标题栏署名。

## 1. 构思

- 风格的「机器就是角色」：这期的机器就是做视频这件事本身。三样干货都画成机器上的零件：
  - 用什么：机箱铭牌「AI 编程助手」；抽屉柜铭牌「开源库 · NIUXUE-FILMS · 免费」，39 个抽屉；
  - 怎么说：漏斗上面那张纸条（INPUT · 一句话），那句话逐字写上去；面板上「先问一轮：」三个拨杆；
  - 适合拍什么：左栏「一般注释」第 3–6 条（STYLE §7：每句旁白也写进注释栏）。
- 风格的四样本事这期用了四样：
  - 制图顺序：中心线 → 轮廓 → 细节 → 剖面线 → 尺寸 → 零件号 → FIG. 1，每层落在拍上；
  - 活的标注：抽屉抽出来时尺寸线跟着量（0 → 100）；
  - FIG. 编号当转场：FIG. 1 划掉改写「FIG. 2 · 运转中」，同时投影从 0 转到 0.32，线稿「转」出厚度；
  - 一个制图符号变成真的：播放符号 ▶ 长成真的片子（19、20、21 期的静帧），有辉光、有落在纸上的影子。
- 印章是全片唯一的红，放在结尾「这一张，你也画得出来」前面落下，成片开场也看得到。

## 3. 关键手法

### 3.1 竖版
- `draw.js` 只把 `W, H` 改成 1080×1440；`paper.js`（纸面在纸面坐标里生成）不用改。
- 图纸从样片的 3200×2200 横纸改成 2200×3200 竖纸。全景 z = 0.45 正好整张入画，左右露一点桌面。
- 版面（纸面坐标）：页眉左上；机器中轴 x = 1260，从漏斗 y 560 到地面 2580；左栏从上到下是抽屉柜、一般注释、零件表；右下是标题栏；印章在右上的空白处。
- 字幕是注释框（NOTE + 编号），固定在离底 112 px。所以底部的东西会被挡：
  - 印章一开始放在左下，开场全景被字幕盖住，挪到了右上；
  - 注释栏原来在纸的最下面，讲「适合拍什么」时正好在字幕底下，挪到左栏中间。

### 3.2 开场成片 → 倒着擦
每一层的画出进度都走同一个函数：成片阶段是 1，倒擦时按 `order` 先后收回（越小越先擦），之后按自己的时间画：

```js
const RW = (t, order, span = .32) => t < T.rw[0] ? 1 : 1 - clamp((eio(seg(t, T.rw[0], T.rw[1])) - order * (1 - span)) / span);
const L = (t, a, b, order) => t < T.rw[1] ? RW(t, order) : seg(t, a, b);
// 章 0 → 片子 .05 → 标题栏最后一行 .1 → 注释 .12 → 零件号 .15 → 尺寸 .2 → 字 .25 → 零件表 .3
// → 剖面线 .35 → 细节 .45 → 投影 .5 → 轮廓 .6 → 标题栏框 .7 → 中心线 .75 → 页眉 .8 → 图框 .9
```
线的 `u` 从 1 退到 0，就是笔尖沿原路往回收，发光的笔尖也跟着走，不用另写倒放。

### 3.3 手影：笔尖跟着正在画的那一笔
手影画的几样东西各是一段 `[t0, t1, u => 笔尖位置]`：轮廓用 `trunc()` 求折线画到 u 处的点（跟 `line()` 画出来的是同一个点），写字按字宽往右走，纸条上的字按逐字时间跳到下一个字。段和段之间抬笔过去（位置插值，往上拱 40）。

```js
const P = (pts, closed = true) => u => { const [, nib] = trunc(closed ? [...pts, pts[0]] : pts, Math.min(u, .999)); return nib || pts[0]; };
HAND.push([T.house[0], T.house[1], P(rect(...HOUSE))]);
```
画面是逐帧并行渲的，别用「上一帧的笔尖位置」，每一帧都要能从 t 直接算出来。

### 3.4 纸条滑进漏斗
纸条画在漏斗前面，用一个裁剪只留漏斗口以上：往下滑的时候，过了口沿的部分就「进去了」。

```js
g.save(); g.setTransform(1, 0, 0, 1, 0, 0);
const [, ry] = S(0, HOP_RIM - 2); g.beginPath(); g.rect(0, -10, W, ry + 10); g.clip();
// …画纸条（knock 填纸色 + 描边 + 逐字）…
g.restore();
```

### 3.5 ▶ 长成真的片子
- 三角形补一个重复的尖（4 个点），跟屏幕内框的 4 个角一一插值：三角形慢慢撑成矩形，片子在里面显出来。
- 片子画在最后合成的 ov 画布上（不被纸面的影子压暗）。辉光是同形状模糊填充，影子画在 fx 的 R 通道，往右下偏。

```js
const tri = [[cx - s * .6, cy - s], [cx + s, cy], [cx + s, cy], [cx - s * .6, cy + s]];
const rc = [[x0, y0], [x1, y0], [x1, y1], [x0, y1]];
const poly = tri.map((p, i) => [lerp(p[0], rc[i][0], k), lerp(p[1], rc[i][1], k)]);
```
- 片子依次放 19、20、21 期的静帧（每 1.15 s 换一张，最后 0.2 s 交叉淡），念到「彩色玻璃窗」停在 21。
- 这一段别的都不动：齿轮滴答、放映机声都在它前面停掉（STYLE §6：只有纸「噗」两声和一阵气流）。

### 3.6 齿轮咬合
主动轮转 a1，从动轮的转角要让齿正好卡进齿槽（φ = 两轮心连线的方向）：

```js
const mesh = (a1, T1, T2, phi) => -(T1 / T2) * a1 + phi + Math.PI - Math.PI / T2 + (T1 / T2) * phi;
```
运转时八分音符走半个齿（缓出 0.35 拍），跟配乐的八分音符对齐。

### 3.7 遮挡顺序
引擎是画家算法：实体先填纸色再描边，后画的盖住先画的。
- 胶片原来先画、模块框后画，结果铡刀那一格里的胶片被模块框填掉了；改成先画模块框再画胶片，最后画刀片。
- 声波、音符这类出了模块框的东西，放在模块里面画，别伸到隔壁模块里。

### 3.8 中文字
- 思源黑体（game-show 素材包的 `fonts.css`）只有 500 和 900 两个字重，写 700 会用 900。
- 工程图的中文要端正，页眉、铭牌、注释、字幕全用黑体；英文字段照样片用 B612、手写数字用 Architects Daughter。

### 3.9 封面
- `?poster=1&cam=1120,1880,.63`：上面一块注释框写「39 种风格 · 22 蓝图 / 一句话 / 让 AI 画出一张工程图纸」，中间是四个模块和在放片子的屏幕，底下一个红章「不花钱生成视频」（章本来就是这个风格唯一的红）。
- 章跟标题栏的字叠在一起很乱：封面不画标题栏。

## 4. 声音

- **配乐**（`music/score.py`）全部现合成，二声部巴洛克创意曲，G 大调 108 BPM（STYLE §6）：
  - 羽管键琴：`pluck.py` 的弦模型，自加预设（拨片位置 0.07、很亮、衰减快），8′ 上叠一层弱的 4′，起音加一点拨片噪声；
  - 大管：加法合成，470 Hz 和 1180 Hz 两个共振峰、基音减半、吐音噪声，断奏；
  - 弦乐：锯齿加法 + 琴体共鸣，三层走调 ±7 音分当一组；跳弓 0.07 s，长音可以挂包络（Dsus4 那两口气）。
- 倒着擦的配乐：把刚才那 1.4 s 的分轨原样倒过来放，键琴倒放就是一口一口往回吸的声音，跟画面上线往回收对得上。
- 真静两处：倒擦完的白纸（配乐清零，只剩画图框的笔声）、变身前 0.2 s（整个底子清零）。
- 挂在拍上的：画机器每一层、运转的齿轮都在 108 BPM 的八分音符格子上；三刀是全体重音；变身 = Dsus4 涨两口气，片子长满那一拍解决到 G；章 = 一个完整终止（ii6–V7–I）的 I。
- **拟音**（`mix.py`）照样片的纸、笔、黄铜，本期新加：笔画倒放（倒擦）、纸条滑、拨杆、抽屉、铡刀（嚓一声 + 金属余音 + 闷响）、放映机片齿（每秒 18 下）。
- **电平**：旁白 −18 dB；配乐安静处 −24 dB，说话时按分轨压（键琴 −17、大管 −16、弦乐 −18）；拟音说话时再压 6 dB。第一版每句就都过了 12 dB（13.1–19.1）。
