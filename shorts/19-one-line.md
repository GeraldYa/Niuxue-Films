# 19 一笔画（`one-line`）做片笔记

> 整片只有一根线，画的是一台朝右的老式电影摄影机，架在三脚架上。做一支视频的每一步都是它的一个零件：
> - 机身方框 = 一张空白的纸，「一句话」= 机身上的牌子，对话框的尾巴 = 机身下的把手；
> - 打字 = 一行连笔的小圈，三个问号 = 三个表盘；
> - 开源库 = 左片盘，39 道刻度，第 19 道是一个小圈；
> - 写代码 = 取景器「</>」，配音 = 镜头，配乐 = 右片盘，剪 = 胶片；
> - 三条腿 = 适合拍的三样，红色录制灯 = 停笔；
> - 遮光罩是最后一笔，一路拉远见全貌。
>
> 开场先给成片，整根线倒着收回笔里，再从白纸重新落笔。

## 1. 构思

- 这个风格的五样本事（STYLE §2）这期全用上了：
  - 笔不离纸：整片一个点列；
  - 线就是时间：最后那根新线换成更细、更抖的「下一期」；
  - 变形：机身方框先是一张白纸，加上尾巴成了对话框，最后是机身；
  - 停笔是事件：录制灯；
  - 反向设计的拉远：原来是一台摄影机。
- 最后那一幅画选摄影机：做视频的每一步本来就是摄影机的零件，三样干货都能长在它身上：
  - 用什么：对话框（AI 编程助手）+ 左片盘（开源库，39 道刻度）；
  - 怎么说：「一句话」牌子 + 三个问号表盘；
  - 适合拍什么：三脚架三条腿。
- 「不适合拍什么」交给地面：地面一口气拉过去（热闹），旁白说「想要热闹一点的，交给微游戏快闪那一期」。
- 唯一的颜色给录制灯：笔停在红灯正中，红墨洇开，真静 1.8 秒，这就是「开始录了」。样片把红色给了初恋，这里给「开拍」。
- 系列规矩「开头先给成片」：开场整台摄影机已经画好。念完 L01，整根线倒着收回笔里，再从白纸重新落笔。一笔画的开头本来就是「白纸上第一笔」，倒收正好把两件事接上。

## 3. 关键手法

### 3.1 反向设计：先画好最后那幅画
- `draw19.js` 先写整台摄影机，再按旁白切成 16 段（段表 `SEGS`：时间窗、线的样子、卡点、停笔）。
- 每段从上一段的终点接着画。要去别处，就沿已经画过的线描回去，描回去看不出来。比如：
  - 片盘画完沿支柱描回机身；
  - 地面拉完原路描回，再沿腿、机身底边、右边一路描到录制灯。
- 每次改完都渲一张整幅（`?all=1&nopen=1&nosub=1`），看有没有多出来的连线。

### 3.2 中文写进一根线里
- 「一句话」是一个手写的点列（`HZ`，局部坐标约 340×100），一笔连写：「一」的末尾往上连成「句」的撇，「句」的钩连到「话」的点。
- 第一版认不出来，重画了点列：
  - 句 = 撇 + 口 + 横折钩（带钩）；
  - 话 = 讠（点 + 横折提）+ 舌（撇、横、竖、口）。
- 每改一次都拉到整幅大小看一眼认不认得。
- 「一」接在从左边框进来的连线上，远看像一根线穿进「句」。没改，旁白和字幕都说了「一句话」。

### 3.3 开场先给成片，再倒着收回笔里
`main.js` 里多一层「现在画到哪」：

```js
const HOOD_END = P.range[P.segs.findIndex(s => s.id === 'hood')][1];   // 最后一笔（遮光罩）的末点
const ease = u => u < .5 ? 2 * u * u : 1 - 2 * (1 - u) * (1 - u);
function headFor(t) {
  if (t < K.rw0) return HOOD_END;                                        // 成片摆着
  if (t < K.rw1) return HOOD_END * (1 - ease((t - K.rw0) / (K.rw1 - K.rw0)));   // 按弧长倒收（点是等弧长采样的）
  return headAt(P, t);                                                   // 之后照常按时间画
}
const inkT = (t, head) => t < K.rw0 ? K.hood1 + 5 : t < K.rw1 ? P.T[Math.floor(head)] : t;   // 红墨跟着倒放
```

- 按弧长倒收，不按时间：按时间倒，停笔那 1.8 秒会原地卡住，长线和短细节快慢也不一样。
- 倒收时笔一直贴着纸；收完抬一下，再落下去，就是第一笔的「嗒」。
- 镜头在倒收的 1.5 秒里从全景扎到第一笔落下的微距。成片那几秒不跟笔（f = 0），不然会被还没开始画的笔尖拽走。
- 给配乐的笔速表里，倒收那段单独标成 `rew`，混音另做一声「嗞」。

### 3.4 一根线挂在字上
- `story19.js` 的 `at(id, '字')` 定每段的时间窗，段里再用卡点对齐。卡点可以写比例，也可以写位置 `at: [x, y]`（第 n 次经过那里）：
  - 三个表盘 = 念到「配」「音」「分」；
  - 三条腿的脚 = 念到「品」「人」「极」；
  - 第 19 道刻度 = 念到「挑」。
- 第 19 道刻度的卡点第一次找不到（`mark not found`）：卡点要放在笔真的会经过的地方，改成刻度内端的小圈顶上。

### 3.5 竖版
- `cam.js` 的 `BASE` 改成 1.05：z = 1 时整台摄影机（连三脚架、地面）正好入竖版画面。
- 字幕在画面下方，拉近以后常压在机身的线上：
  - 光晕加宽成 26 + 14 px 两层；
  - 下一条字幕开始写之前，上一条淡完。第一版交接时两条叠成「她发给也做得出来」。
- 片尾卡写在画面下方的空白纸上，最后一行署名要在最后一句字幕上面：片尾卡上移，结尾的镜头也往下挪。

### 3.6 封面
- `?poster=1&cam=0,2,0.84`：整幅画缩到中间，上面写三行：
  - 「39 种风格 · 19 一笔画」；
  - 大字「一句话」；
  - 「让 AI 一笔画完一支视频」。
- 底下一条红色的「不花钱生成视频」，跟录制灯同一个红。

## 4. 声音

- **配乐**（`music/score.py`）是独奏大提琴，全部代码合成（§5 有做法），一把琴一条线：
  - 方框四个角、「一」「句」「话」起笔（`events.json` 的 `pts`）各落一个音；
  - 打字那一行是拨奏，一个小圈一个音；三个问号各一个往上挑的问句；
  - 39 道刻度时颤弓，第 19 道一声泛音；
  - 写代码跳弓、配音连弓、配乐绕着唱片走琶音、剪是拨奏；
  - 三条腿 G–A–D（IV–V–I）；地面是全曲最热闹的一串跳弓；
  - 录制灯是全曲最高的 B4 → A4，笔一停 A4 淡到无，接着真静；
  - 开场的「整幅画」动机 D–F#–A–D，在拉远见全貌时原样回来。
- **笔声**（`mix.py`）照样片：带通噪声，快 = 亮、慢 = 闷，纸纤维颗粒密度跟笔速走，声像跟笔尖走。倒收是一声越拉越快又收住的「嗞」（亮噪声 + 一根往上滑的细音）。
- **真静**：停笔那 1.8 秒配乐连混响尾巴清零，笔速本来就是零，室内底噪降到 15 %，只剩几乎听不到的洇墨声（整个混音峰值 −46 dBFS）。
- **电平**：旁白 −18 dB；大提琴安静处 −24 dB，说话时压 17 dB；笔声说话时压 11 dB。每句「人声 − 底子」13.0–17.6 dB。

## 5. 返工记录

1. 「一句话」认不出来：重写连笔的字形（§3.2）。
2. 录制灯离「一句话」太近：挪到机身右上角（y −15）。
3. 三脚架中间那条腿跟地面交叉：脚点改到 (10, 571)。
4. 第 19 道刻度卡点找不到（§3.4）。
5. 开场从白纸第一笔开始，不合系列「开头先给成片」：改成成片 → 倒收 → 重新落笔（§3.3）。整片往后顺延 1.4 秒。
6. 字幕交接叠字、字幕压在线上看着乱（§3.5）。
7. 龙藏体的「闪」画成了「铩」：字体自己的字形错了，`unicode-range` 让这一个字借马善政（SHORTS.md §4）。
8. 片尾署名最后一行跟最后一句字幕叠在一起（§3.5）。
9. 混音第一版每句只有 5–10 dB：琴的泛音全在人声频段，说话时压 17 dB；笔声 11 dB。
10. 大提琴换音处咔哒：换弓的「顿」原来从音头算起，一换音就跳一下。改成按离最近一次换音的距离，两边对称地顿；揉弦深度也平滑收掉。

## 6. 下一期能直接拿走的

- **合成独奏大提琴**（`music/score.py` 的 `bowed()`）：一口气拉下来的连奏、滑音、换弓、延迟揉弦、颤弓、泛音、跳弓，泛音逐根过琴体共鸣。任何要一件弦乐独奏的片子都能用。
- **开场成片 → 倒收**（§3.3）：凡是「一笔一笔画出来」的风格（一笔画、白板、水墨），先亮成片再倒着收回去，都能照抄 `headFor`。
- **反向设计的一幅画 + 段表**（`draw19.js`）：「一个东西由几个零件组成」的题都能照这个做，比如产品、建筑、人脸。
- **中文连笔字**：手写点列一笔写完一个词（§3.2）。
